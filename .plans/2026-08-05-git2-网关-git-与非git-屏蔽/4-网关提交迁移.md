# 任务 4: 网关提交迁移

批次：【批次 2】依赖批次：批次 1

状态：未开始

目的：将 `/v1/git/commit` 的全量、文件、hunk 与行级暂存及提交迁移到 git2。

来源任务：无

预计会话范围：只改提交 handler 与相邻测试；保留请求/响应 DTO、路径校验和选择算法，不处理分支合并或通用 Git command。

## 文件

- 修改：`crates/vw-agent/src/gateway/api/handlers/git.rs`
- 修改：`crates/vw-agent/src/gateway/api/handlers/git_tests.rs`

## 上下文

- 选择内容算法已在 Rust 中，外部 Git 只负责 index reset/add/cacheinfo/hash-object/commit/rev-parse。
- git2 可写 blob、IndexEntry、tree 与 commit；提交签名继续要求仓库/用户配置，不新增伪造身份。
- git2 commit 不执行 Git hooks，这是选定的无外部 Git 语义，必须在测试和错误信息中保持明确。

## 测试计划

- 行为：无 Git PATH 时，全量提交、文件提交、hunk/新旧行选择、删除和初始提交均产生正确 tree 与 SHA；无变更保持 `created: false`。
- 失败验证测试：新增 `gateway_git2_commit_works_without_git_executable` 与 `gateway_git2_partial_commit_preserves_unselected_changes`。
- 失败验证命令：`cargo test -p vw-agent gateway_git2_commit_works_without_git_executable`
- 预期失败原因：当前 stage、hash-object、update-index 与 commit 依赖外部 Git。
- 通过验证命令：`cargo test -p vw-agent gateway_git2_commit_ && cargo test -p vw-agent git_commit_v1_`
- 模拟策略：真实 git2 临时仓库、索引和提交；不模拟 index 或 object database；PATH 只用于证明没有 CLI 依赖。

## 步骤

1. 编写全量与部分提交失败测试，断言 commit tree 而非内部调用。
2. 运行失败验证，确认外部 Git 缺失。
3. 用 git2 重置/更新 index、写 blob 与 tree，处理删除和缺失旧 index entry。
4. 用 HEAD 父提交或空父列表创建 commit，并返回真实 OID；保持无 staged change 的响应。
5. 删除提交路径中不再使用的 tempfile、Stdio 与 `run_git*` 辅助函数，但保留合并任务仍需的代码到任务 5。
6. 运行聚焦提交测试与全目标 Clippy。

## 验证

- 运行：`cargo test -p vw-agent gateway_git2_commit_ && cargo test -p vw-agent git_commit_v1_ && cargo clippy --all-targets --all-features -- -D warnings`
- 预期：提交选择行为、SHA、初始提交和无变更响应均通过；Clippy 退出码为 0。
- 所需证据：实现前失败、实现后 commit tree 中选中/未选中内容断言、无 Git PATH 证据、Clippy 成功输出。

## 完成

完成时 `/v1/git/commit` 全路径使用 git2，公开协议不变，签名缺失返回明确错误，且不声称执行 hooks。
