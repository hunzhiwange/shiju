# 任务 1: 修复默认代理浏览器指纹

批次：【批次 1】 无

状态：未开始

目的：让所有经 `BrowserTool` 启动的 `agent-browser` 会话默认关闭 Blink 自动化标记，同时保留用户已有启动参数。

来源任务：用户要求修复浏览器访问网页总被反爬拦截，并参考其他 AI agent 的浏览器行为。

预计会话范围：仅修改默认 `agent-browser` 命令构造和相邻单元测试，不改变动作映射、URL 安全校验、配置结构或其他后端。

## 文件

- 修改：`crates/vw-agent/src/tools/browser/agent_browser.rs`
- 测试：`crates/vw-agent/src/tools/browser/agent_browser_tests.rs`

## 上下文

- `run_command` 是所有 `agent-browser` 动作的统一入口，当前只传会话、动作参数和 `--json`。
- 已安装的 `agent-browser 0.31.1` 支持 `AGENT_BROWSER_ARGS` 与 `--args`；Browser Use 当前浏览器配置同样使用 `--disable-blink-features=AutomationControlled`。
- 必须保留 `--session`、JSON 输出、用户已有 `AGENT_BROWSER_ARGS` 和现有命令日志脱敏边界。

## 测试计划

- 行为：命令构造会保留已有 Chrome 参数，并恰好一次加入 `--disable-blink-features=AutomationControlled`。
- 失败验证测试：在 `agent_browser_tests.rs` 新增 `agent_browser_launch_args_preserve_existing_and_add_automation_evasion`。
- 失败验证命令：`cargo test -p vw-agent --lib agent_browser_launch_args_preserve_existing_and_add_automation_evasion`
- 预期失败原因：当前没有启动参数合并逻辑，生成的命令不会包含自动化规避参数。
- 通过验证命令：`cargo test -p vw-agent --lib agent_browser_launch_args_preserve_existing_and_add_automation_evasion`
- 模拟策略：只对纯参数合并函数做单元测试；另用本机真实 `agent-browser` 会话检查 `navigator.webdriver`，不模拟浏览器。

## 步骤

1. 为现有参数为空、已有其他参数、已有目标参数三种输入编写失败验证测试。
2. 运行失败验证命令并确认缺少自动化规避参数。
3. 提取小型纯函数合并 `AGENT_BROWSER_ARGS`，并在 `run_command` 创建子进程时设置合并后的值。
4. 保持用户参数顺序，不重复追加目标参数，不把参数内容提升到普通日志级别。
5. 运行聚焦测试、真实浏览器信号检查和仓库 clippy。

## 验证

- 运行：`cargo test -p vw-agent --lib agent_browser_launch_args_preserve_existing_and_add_automation_evasion`
- 运行：`agent-browser --session vw-antibot-verification --args "--disable-blink-features=AutomationControlled" open about:blank --json && agent-browser --session vw-antibot-verification --args "--disable-blink-features=AutomationControlled" eval "navigator.webdriver" --json && agent-browser --session vw-antibot-verification --args "--disable-blink-features=AutomationControlled" close --json`
- 运行：`cargo clippy --all-targets --all-features -- -D warnings`
- 预期：聚焦测试通过；真实浏览器返回 `navigator.webdriver` 为 `false` 或未定义；clippy 无本次变更引入的问题。
- 所需证据：失败测试输出、通过测试退出码、真实浏览器 JSON 值、clippy 退出码和已审查差异。

## 完成

完成后，`agent_browser.rs::run_command` 启动的默认浏览器会话会在保留用户参数的前提下关闭 Blink 自动化标记；动作协议和安全边界保持不变。
