# 新建会话防重复创建计划

目标：新建会话请求进行中时禁用并灰显创建入口，成功或失败后恢复，避免重复点击创建空会话。

范围：工作模式“新建任务”、空间行新建任务、新建会话按钮及 worktree 创建流程；增加瞬时创建状态、消息层重复请求保护和相邻测试。

范围外：不改变网关创建协议、会话持久化格式、任务看板创建逻辑或现有 worktree 选择规则。

假设：所有用户触发的新会话创建最终经过 `ProjectCreateSession`、`ProjectCreateSessionPicked` 或 `ProjectCreateSessionWorktree`，并以 `SessionCreated` 或 `SessionCreateFailed` 收敛。

## 设计决策

- 使用应用内单一布尔状态表示创建进行中；当前产品一次只应创建一个前台新会话，全局锁能覆盖不同入口的快速连点。
- UI 禁用用于即时反馈，消息处理器守卫用于阻止已排队或来自其它入口的重复消息。

## 架构说明

- 状态归属 `App`；创建入口设置状态，成功和失败消息统一清理。
- 沿用 Iced 无 `on_press` 即禁用按钮的模式，并为禁用状态提供暗黑/明亮主题都清晰的低透明度样式。

## 开发策略

- 对会改变行为的代码，使用失败验证-通过验证-重构。
- 在实施步骤前规划失败验证命令和预期失败。
- 将实施步骤限制在失败测试所证明的行为范围内。
- 测试真实行为，不验证模拟对象或实现细节。
