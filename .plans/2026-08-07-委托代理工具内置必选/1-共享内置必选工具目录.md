## 上下文

- desktop 与 agent 都依赖 `vw-config-types`，不宜把目录只写在 desktop。
- 用户给定内置必选集合（主 ID，匹配时含别名）：`file_read`/`file_write`/`ls`/`glob`/`grep`/`apply_patch`/`bash`(含 `shell`)/`http_request`/`image_info`/`screenshot`/`AgentTool`/`skill`/`schedule`/`plan_enter`/`plan_exit`/`memory_forget`/`memory_recall`/`memory_store`/`batch`/`AskUserQuestion`(含 `question`；需求笔误 AskUseQuestion)/`Browser`(含 `browser`)/`BrowserOpen`(含 `browser_open`)/`Config`/`TodoRead`(含 `todoread`)/`TodoWrite`(含 `todowrite`)/`WebSearch`(含 `web_search`/`websearch`/`web_search_tool`)/`file_edit`(含 `edit` 若作为别名出现)/`image_asset_read`/`tool_search`/`verify_plan_execution`。
- MCP 动态工具 ID 形如 `mcp__{server}__{tool}`。

## 测试计划

- 行为：给定工具 ID 能判定是否内置必选；`mcp__rustcodegraph__search` 判定为 MCP 动态工具且非内置。
- 失败验证测试：`crates/vw-config-types/src/tools_tests.rs` 中新增 `builtin_required_tool_catalog_matches_expected_ids_and_aliases`、`is_mcp_dynamic_tool_id_detects_prefix`
- 失败验证命令：`cargo test -p vw-config-types builtin_required_tool_catalog_matches_expected_ids_and_aliases is_mcp_dynamic_tool_id_detects_prefix -- --exact`

- 通过验证命令：同上命令退出码 0。
- 模拟策略：纯函数，无 mock。
