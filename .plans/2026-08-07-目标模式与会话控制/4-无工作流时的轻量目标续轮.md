# 任务 4: 无工作流时的轻量目标续轮

批次：【批次 4】 依赖批次 3

状态：未开始

目的：在未开启工作流但开启目标模式时，普通聊天每轮结束后用独立评估器判断完成条件；未达成则自动续轮，对齐 Claude/Codex「不达目的不罢休」。

来源任务：无

预计会话范围：实现轻量评估/续轮契约与桌面或网关接线；不扩展 pause/resume/budget UI。

## 上下文

- Claude `/goal`：每轮结束后由独立小模型对照完成条件评估；否→带 reason 续轮；是→清除目标。
- Codex Goals：完成契约 + 证据驱动继续；可与 `/plan` 并存，本身不是 plan。
- 本仓库已有 `GoalEvaluation { achieved, reason }` 与 plan-run Goal 循环；轻量路径：
  - 完成条件 = 本轮用户原始查询（可附带「请以可验证证据证明完成」）
  - 评估输入 = 最近执行 transcript/助手输出摘要，不要求编号任务文件删除
  - 阻塞：显式需要用户输入、或连续三次相同基础设施错误时停止（对齐现有 goal runner）
- 工作流+目标继续走现有 `TaskPlanRunMode::Goal`，本任务不改其任务文件契约。
- 安全：评估器不执行工具；不记录密钥；不静默扩大权限。

## 测试计划

- 行为：goal-only 在评估 `achieved=false` 后发起续轮；`achieved=true` 结束；明确阻塞不再续轮。
- 失败验证测试：`lightweight_goal_continues_until_evaluation_passes`、`lightweight_goal_stops_on_explicit_blocker`、`build_lightweight_goal_evaluation_prompt_omits_task_file_gate`
- 失败验证命令：`cargo test -p vw-agent --lib lightweight_goal -- --nocapture` 与 `cargo test -p vw-desktop --lib lightweight_goal -- --nocapture`
- 预期失败原因：尚无轻量续轮路径。
- 通过验证命令：同上。
- 模拟策略：对评估解析与续轮决策用假 runner/事件；桌面侧断言续轮触发条件，不启真模型。

## 步骤

1. 编写轻量评估提示与续轮决策失败验证测试。
2. 运行失败验证命令并确认预期失败。
3. 实现无任务文件门闸的评估/续轮提示，并在 goal-only 聊天路径接线。
4. 运行通过验证与 clippy。
5. 确认 workflow+goal 的既有 plan-run Goal 测试不受影响。
