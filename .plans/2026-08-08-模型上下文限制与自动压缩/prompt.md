# 执行提示

执行任何任务前，先阅读 `AGENTS.md`，并按 `./skills/do-task-plans/SKILL.md` 的流程工作。当前计划只允许按批次顺序执行；不要直接跳过前置任务，不要把本计划改成一次性大重构。

## 任务 1 提示

你正在执行 `1-模型目录补齐与限制兜底.md`。先按任务文件列出的清单阅读代码和资产，再先写会失败的限制解析、默认值和资产审计测试。然后以阿里云官方文档优先、`models.dev` 为目录基线补齐 `shiju.json` 与 `api.json`，同时统一 `vw-provider-resolver`、`vw-agent` 的默认限制解析。不要修改桌面模型编辑 UI，也不要删除其它工作区改动。完成后运行任务文件中的聚焦验证和 `cargo clippy --all-targets --all-features -- -D warnings`，把模型 ID、来源和默认值清单写入交接；所有证据齐全后才可删除任务文件。

## 任务 2 提示

你正在执行 `2-自定义兼容模型能力配置.md`。先确认任务 1 已完成并阅读现有自定义 provider 的状态、消息、弹窗和 patch 流程。先写失败测试，再让添加/编辑模型可以设置限制、能力、模态和家族，并按既有 JSON 结构保存；空限制必须明确回退到默认值，非法数字、重复 ID 和超出关系要报错。同步修改桌面 resolver 与 agent resolver 的显式覆盖解析，保留自动发现的现有行为。遵守 Iced 暗色主题、4px 滚动条和中文非等宽字体规则。完成聚焦验证与 clippy 后才可删除任务文件。

## 任务 3 提示

你正在执行 `3-90百分比上下文自动压缩.md`。先确认前置任务完成，阅读活跃 `session/processor` 链路和孤立 `session/compaction`。先写 89%/90% 边界、默认限制、真实 usage、协议配对和有限重试测试，再在下一次 `llm_runner` 请求前接入统一压缩预检。优先复用已有工具结果清理与历史治理，不产生额外远程请求，不记录敏感载荷；删除或改造 70% 重复判断。完成测试、日志时序检查和 clippy 后才可删除任务文件。

## 任务 4 提示

你正在执行 `4-联调验证与数据审计.md`。先确认前三个任务完成，先写跨层 fixture 与资产遗漏的失败审计，再核对设置保存、resolver、agent、使用率展示和自动压缩使用同一限制。保留已有 `/ui` 413 修复及其他用户改动，不 reset、不 checkout、不全量格式化。执行任务文件中的聚焦验证和最终 clippy；若只剩无关既有错误，记录证据并交接，不扩大范围。全部完成后才可删除任务文件。
