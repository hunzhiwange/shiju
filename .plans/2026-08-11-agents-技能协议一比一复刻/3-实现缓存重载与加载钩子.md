## 上下文

- 当前 `State` 只按消息记录已声明路径；Claude Code 会缓存解析结果，在 clear、目录切换、文件变更和压缩后失效，并携带加载原因触发钩子。
- 钩子只做可观察通知，不能修改或放宽最终指令集合。

## 测试计划

- 行为：同一文件稳定命中缓存，内容变化和压缩后重新读取，钩子收到来源、原因和文件列表。
- 失败验证测试：新增 `instructions_loaded_cache_reloads_after_change_and_compaction` 与 `instructions_loaded_hook_receives_resolved_sources`。
- 失败验证命令：`cargo test -p vw-agent instructions_loaded_ -- --nocapture`
- 预期失败原因：当前没有文件状态缓存、重载原因或 InstructionsLoaded 事件。
- 通过验证命令：`cargo test -p vw-agent instructions_loaded_ -- --nocapture`
- 模拟策略：真实文件状态；插件命令执行器用现有测试替身，只验证事件载荷。

## 步骤

1. 编写缓存命中、内容修改、清理、压缩重载和钩子载荷的失败测试。
2. 运行失败验证确认缺失行为。
3. 实现按工作区和会话隔离的文件状态缓存及明确失效入口。
4. 为现有插件钩子增加 `instructions_loaded` 事件和只读载荷。
5. 运行聚焦测试，确认钩子失败不改变指令结果。
