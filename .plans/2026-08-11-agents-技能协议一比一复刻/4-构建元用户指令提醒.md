# 任务 4: 构建元用户指令提醒

批次：【批次 4】 依赖批次 3

状态：已完成，待回归验证

目的：把完整 AGENTS 上下文包装成 Claude Code 同构的不可见元用户 `<system-reminder>`，不再塞入基础 system prompt。

来源任务：用户要求系统始终遵循 AGENTS.md。

预计会话范围：建立统一的临时消息装配器和纯函数测试；具体运行时接入留给后续任务。

- 修改：`crates/vw-agent/src/session/prompt.rs`

## 上下文

- 当前 `SystemPrompt.project_protocol` 仍作为后置 system 消息发送；Claude Code 使用带覆盖声明的 meta user reminder，并在每次请求装配时重新生成。
- 提醒必须临时加入 provider 上下文，不写入可见聊天记录，不污染用户消息，也不能因 system prompt 缓存而丢失。

## 测试计划

- 行为：基础 system 不含 AGENTS；装配结果在历史前包含一个 user 角色 reminder，来源顺序与解析器一致且空集合不注入。
- 失败验证测试：新增 `agents_context_injection_prepends_meta_user_reminder` 与 `agents_context_base_system_excludes_instruction_content`。
- 失败验证命令：`cargo test -p vw-agent agents_context_ -- --nocapture`
- 预期失败原因：当前项目协议仍属于 system prompt 的 runtime parts。
- 通过验证命令：`cargo test -p vw-agent agents_context_ -- --nocapture`
- 模拟策略：使用真实 `Resolved` 数据和内存消息，不模拟 provider。

## 步骤

1. 编写精确验证角色、位置、标签、覆盖声明、来源和不可见属性的失败测试。
2. 运行失败验证确认现有 system 注入行为。
3. 定义临时上下文消息类型和纯装配函数，使用 Claude Code 的覆盖语义文本。
4. 从 `SystemPrompt` 删除 `project_protocol` 及对应技能预加载路径，仅保留基础系统内容和展示路径。
5. 运行聚焦测试并确认用户原始消息字节不变。
