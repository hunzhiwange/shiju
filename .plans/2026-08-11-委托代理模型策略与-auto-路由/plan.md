# 委托代理模型策略与 Auto 路由计划

目标：允许委托代理清空模型绑定、按需强制完整模型引用，并让 Auto 在主会话、任务与子智能体中真正选择合适模型。

范围：扩展代理配置契约和桌面设置页；统一显式选择、强制绑定、偏好绑定与 Auto 的决策顺序；基于已启用模型的能力、成本、上下文、角色和请求特征做确定性选择；覆盖 Gateway、Session Processor、AgentTool、任务执行及旧 Agent 路径。

范围外：不改变 Embedding、OCR、重排模型或 ACP 自身的模型协商；不引入额外 LLM 分类请求；不自动启用模型、扩大 provider 权限或迁移无关配置。

假设：运行时 `provider::list()` 只暴露 active 模型；模型元数据已有 toolcall、reasoning、attachment、输入模态、成本和限制；桌面 Auto 以空 `model` 表达；项目任务的 `auto` 已归一化为空模型。

## 设计决策

- 新增 `force_model_selection: bool`，默认 `false`；仅 provider 和 model 都非空时生效，不完整绑定不报错、不阻断 Auto。
- 决策优先级固定为：ACP 专用路由 > 完整强制绑定 > 显式手选模型 > 配置规则路由 > Auto 评分 > 明确错误。强制绑定必须覆盖父会话继承和普通显式模型。
- 未强制的代理模型是 Auto 的软偏好，只参与同等适配候选的排序；不会伪装成硬绑定。
- Auto 先应用现有 `query_classification` 与 `model_routes`；没有命中时使用纯本地确定性画像与评分，不产生额外网络请求。
- Auto 画像至少区分轻量、通用、推理、工具/代码、视觉和长上下文；先按必需能力与上下文过滤，再按画像适配度、配置偏好、成本、发布日期和完整模型引用稳定排序。
- 规则命中但目标模型无效时返回配置错误；没有满足硬能力的候选时返回包含需求摘要的错误，不静默使用不兼容模型。
- 每轮请求只选择一次模型，并把真实 `provider/model` 贯穿上下文限制、工具可见性、Step 事件、消息持久化和子智能体继承。
- 设置页使用显式“清除”操作；清除 provider 同时清除 model，清除 model 保留 provider。Main 的默认字段清除通过 JSON `null` 删除旧值。

## 架构说明

- 配置源在 `vw-config-types::agent::AgentDefinitionConfig`，桌面编辑状态在 `DelegateAgentSettingsEntry`，保存采用 Gateway merge patch。
- 统一选择器放在 `vw-agent/src/session/llm/`，纯评分与目录加载分离，便于不依赖网络的确定性测试。
- `session/processor/runner.rs` 必须在创建模型相关工具上下文和计算限制前完成选择；Gateway 与 AgentTool 只传递策略输入，不各自复制选择算法。
- 旧 `Agent::classify_model` 复用同一画像/规则语义，避免桌面聊天与通道运行出现两套 Auto 行为。
- 当前工作树存在其他未提交改动；执行者只修改任务列出的文件，不 reset、checkout 或格式化无关文件。

## 开发策略

- 对会改变行为的代码，使用失败验证-通过验证-重构。
- 仓库禁止未经明确授权执行 `cargo test`；失败阶段用新测试引用尚未实现契约造成的 Clippy 编译失败，完成阶段编译全部测试目标并执行规定的 Clippy。
- 将选择器设计成纯函数并编写行为断言；若维护者随后授权执行测试，再运行对应聚焦测试，不扩大到全量测试。
- 每项实现只覆盖任务文件中的行为，最终统一执行 `cargo clippy --all-targets --all-features -- -D warnings`。

## 批次与依赖

- 批次 1：任务 1，定义配置契约与决策语义。
- 批次 2：任务 2，完成桌面清除和强制选择交互，依赖批次 1。
- 批次 3：任务 3，实现 Auto 纯选择器，依赖批次 1。
- 批次 4：任务 4，接入 Session Processor 与通用 LLM 入口，依赖批次 3。
- 批次 5：任务 5，接入子智能体强制/继承语义，依赖批次 1、4。
- 批次 6：任务 6，统一旧 Agent 路径并做跨层审计，依赖批次 2、3、4、5。

## 完成标准

- provider 和 model 可在设置页清空，保存并重载后仍为空；旧默认字段被实际删除。
- 强制开关默认关闭；完整绑定开启强制后所有相关入口使用该完整引用，不完整绑定时继续正常 Auto/显式选择。
- Auto 不再等同于固定 `default_model`，且对规则、轻量、推理、工具、视觉、长上下文和无候选场景有确定性行为测试。
- 主会话、任务执行、子智能体和旧 Agent 路径使用同一优先级；Step 与持久化记录真实选择模型。
- 所有新增测试目标可编译，差异检查无空白错误，最终 Clippy 退出码为 0。
