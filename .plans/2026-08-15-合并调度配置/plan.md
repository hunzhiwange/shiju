# 合并调度配置计划

目标：将内置调度器设置收拢到“定时任务配置”的内部页签，移除独立入口。

范围：调整桌面端系统设置导航、Cron 内部页签和相关 UI 测试；复用既有调度器状态、消息和持久化逻辑。

范围外：不修改 Scheduler 配置字段、默认值、Gateway API 或任务执行语义。

假设：用户所称“调度配置”是系统设置中 `SystemTab::Scheduler` 对应的内置调度器页面；其设置仍由 `scheduler_settings` 保存。

## 设计决策

- 移除 `SystemTab::Scheduler` 的顶级入口，在 `CronSettingsTab` 增加“调度器”页签。
- 保留既有调度器页面组件作为嵌入内容，避免复制字段、消息和帮助逻辑。

## 架构说明

- `system_settings_cron` 负责定时任务内部导航；`system_settings_scheduler` 继续渲染调度器字段。
- `SystemTab` 同时驱动左侧导航、搜索、错误展示及内容路由，移除变体时须同步更新测试。

## 开发策略

- 对会改变行为的代码，使用失败验证-通过验证-重构。
- 在实施步骤前规划失败验证命令和预期失败。
- 将实施步骤限制在失败测试所证明的行为范围内。
- 测试真实行为，不验证模拟对象或实现细节。
