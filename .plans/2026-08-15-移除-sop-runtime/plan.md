# 移除 SOP Runtime 计划

目标：完整移除 SOP 运行时、Agent 工具、配置 API 与桌面设置，不保留可达入口。

范围：删除 `vw-agent` 的 SOP 模块及五个 SOP 工具；移除 MQTT 调度接线、工具注册和 Agent 公开接口；删除跨 crate 的 `[sop]` 配置、设置 DTO 与桌面「标准流程配置」状态、消息、视图、帮助和测试；清理所有引用并以搜索和 clippy 验证。

范围外：不修改用户工作区中可能存在的 `sops/` 数据目录；不删除与 SOP 无关的既有未提交改动。

假设：仓库扫描未发现已提交的 `SOP.toml` 或 `SOP.md` 示例。SOP 仅由本仓库代码和配置承载，且用户明确不需要兼容或迁移。

## 设计决策

- 采用彻底删除，不保留空模块、弃用别名、隐藏开关或旧配置兼容逻辑。
- 所有入口同步移除，避免二进制仍暴露失效的 `sop` 命令或设置页。

## 架构说明

- SOP 运行时位于 `crates/vw-agent/src/sop/`，默认工具集直接构造五个 SOP 工具。
- 配置类型位于 `vw-config-types`，桌面端经 API 类型、设置状态和视图暴露配置。
- 删除跨 crate 接线后才进行全量 clippy，以捕获残余导入与序列化字段。

## 开发策略

- 本次为功能删除；测试驱动开发不适用。先删除对应测试和实现，再用编译、clippy 和零命中搜索验证已无可达行为。
- 验证命令遵循仓库规则：`cargo clippy --all-targets --all-features -- -D warnings`。
