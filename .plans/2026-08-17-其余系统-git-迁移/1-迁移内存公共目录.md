- 行为：普通仓库、linked worktree、非仓库和缺失目录均不依赖系统 `git` 获得现有结果。

- 通过验证命令：`cargo test -p vw-agent memory::paths_tests -- --nocapture`
- 模拟策略：使用临时真实 git2 仓库和 worktree；不 mock Git 状态。
