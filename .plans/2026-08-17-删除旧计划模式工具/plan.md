# 删除旧计划模式工具计划

目标：移除 `plan_enter`、`plan_exit` 和 `verify_plan_execution` 的运行时、配置与桌面展示支持。

范围：删除三项工具实现、注册、别名、权限、配置清单、会话提示、执行器计划模式限制，以及桌面端工具元数据、渲染器和对应测试。

范围外：不删除独立的 todo 工具或技能系统；不改动用户已有的其他工作区变更。

假设：书面规划技能将承担规划流程；仓库中 `ToolUseContext` 的计划状态没有这三项工具以外的生产调用者。

## 设计决策

- 三项工具是同一套已废弃功能，整体删除，避免留下不可进入或不可退出的状态机路径。
- 保留通用 todo 工具和书面规划技能。

## 架构说明

- 工具由 `vw-agent` 定义、注册和执行；配置类型与 desktop 端仅消费工具 ID。
- 删除后，工具列表和 UI 不应再识别这三项 ID 或其历史别名。

## 开发策略

- 本次为删除冗余功能，现有专属测试随实现移除；不新增失败测试。
- 以全仓精确文本搜索证明无遗留引用，再运行规定的 Clippy 检查。
