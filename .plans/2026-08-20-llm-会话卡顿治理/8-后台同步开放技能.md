# 任务 8: 后台同步开放技能

批次：【批次 8】 依赖批次 7

状态：未开始

目的：LLM 会话准备阶段只读取本地 OpenSkills 副本，不在首包关键路径执行 Git clone 或 pull。

来源任务：无

预计会话范围：只调整当前 session processor 使用的复数 `skills` 模块，将远程同步拆成后台单飞和本地可用性读取；不改旧 `skill` 模块、技能安全检查或目录优先级。

## 文件

- 修改：`crates/vw-agent/src/skills/open_skills.rs`
- 修改：`crates/vw-agent/src/skills/mod.rs`
- 测试：`crates/vw-agent/src/skills/open_skills_tests.rs`
- 测试：`crates/vw-agent/src/skills/mod_tests.rs`

## 上下文

- `load_skills_with_open_skills_config_and_provider` 每轮调用 `ensure_open_skills_repo`；后者在目录缺失时 clone、过期时 pull，均是同步命令。新增本地解析函数只返回已存在目录，后台同步函数按规范化路径单飞，失败继续使用旧副本且不记录凭据。
- 首次没有副本时当前轮次不注入 OpenSkills，后台完成后下一轮可见；该行为必须在测试和日志中显式。

## 测试计划

- 行为：加载技能目录时不会同步调用 clone/pull；已有副本立即可用，缺失副本返回空且只安排一次后台同步，失败保留旧副本。
- 失败验证测试：新增 `skill_loading_never_runs_open_skills_vcs_on_request_thread`、`missing_open_skills_repo_schedules_single_background_sync` 和 `failed_background_sync_keeps_existing_repo_available`。
- 失败验证命令：`cargo test -p vw-agent skill_loading_never_runs_open_skills_vcs_on_request_thread`
- 预期失败原因：现有 `ensure_open_skills_repo` 会在加载调用栈中直接执行 clone 或 pull hook。
- 通过验证命令：`cargo test -p vw-agent skill_loading_never_runs_open_skills_vcs_on_request_thread && cargo test -p vw-agent open_skills_repo_schedules_single_background_sync && cargo test -p vw-agent failed_background_sync_keeps_existing_repo_available`
- 模拟策略：仅用现有测试命令 hook 替换外部 Git 边界并计数；目录解析、过期判断、单飞和加载使用真实文件系统临时目录。

## 步骤

1. 用命令 hook 编写会话加载线程不得执行 VCS 的失败测试。
2. 拆分“已有本地副本解析”和“远程同步”，在技能加载中先读本地再安排后台工作。
3. 为规范化仓库路径增加进程内单飞保护，后台结束无论成功失败都释放状态。
4. 验证缺失副本、陈旧副本、拉取失败和禁用配置四条路径，不改变安全过滤与目录顺序。
5. 运行技能聚焦测试与仓库 clippy。

## 验证

- 运行：`cargo test -p vw-agent skill_loading_never_runs_open_skills_vcs_on_request_thread && cargo test -p vw-agent open_skills_repo_schedules_single_background_sync && cargo test -p vw-agent failed_background_sync_keeps_existing_repo_available && cargo clippy --all-targets --all-features -- -D warnings`
- 预期：请求线程 VCS 计数为 0；同路径并发只产生一个后台同步；旧副本在失败后仍加载；clippy 无警告。
- 所需证据：旧实现同步调用失败、三个通过测试摘要、单飞释放路径审查、敏感日志检查、clippy 退出码 0。

## 完成

完成时 `skills/mod.rs::load_skills_with_open_skills_config_and_provider` 的同步调用链不得执行 Git 或网络；`open_skills.rs` 的后台同步必须单飞、失败安全且不扩大技能权限。
