## 测试计划

- 行为：所有剩余专用工具同时显示可区分的类型与生命周期状态，专用动作不丢失，旧布尔标题入口在迁移完成后无调用者并删除。
- 失败验证测试：新增 `specialized_tool_headers_use_shared_lifecycle_contract`、`specialized_tool_actions_survive_header_migration`、`legacy_boolean_tool_header_has_no_callers`。
- 失败验证命令：`cargo test -p vw-desktop specialized_tool_headers_use_shared_lifecycle_contract`
- 预期失败原因：专用工具仍只把状态压缩为 `is_error`，无法表达等待、完成和取消，旧入口仍有调用者。
- 通过验证命令：`cargo test -p vw-desktop specialized_tool_headers_ && cargo test -p vw-desktop specialized_tool_actions_ && cargo test -p vw-desktop legacy_boolean_tool_header_`
- 模拟策略：使用各视图现有真实 JSON fixture 和 `Message` 断言；不 mock diff、权限或 Agent 会话模型。
