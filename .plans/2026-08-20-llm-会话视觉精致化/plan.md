# LLM 会话视觉精致化计划

目标：参考 Codex 的低噪音会话体验，统一消息、工具、运行状态与输入区的视觉语言，使信息清晰、精致且不突兀。

范围：桌面端 LLM 会话阅读列、用户/助手消息、Markdown 层级、思考与全局运行状态、各类工具头部及生命周期图标、输入卡片与会话区衔接、暗黑/明亮主题实际渲染检查。

范围外：会话协议和持久化、工具执行逻辑、权限策略、工具详情内容重构、主题系统重做、新增用户配置、像素级复制 Codex 品牌资产。

假设：现有图标资产、工具解析结果、状态动画帧、主题色和详情弹窗足以完成改造；`.plans/2026-08-20-llm-会话卡顿治理/6-轻量工具结果卡片.md` 会先完成，避免同时修改 `text_view.rs`。

## 现状分析

- 工具已有集中式名称、动词和图标映射，但读取/写入仍使用小号箭头，类型辨识度弱；运行、等待、完成、失败与取消没有统一的第二视觉维度。
- 通用工具行、Bash 行和各专用工具视图分别组合标题，字号、间距、状态表达与详情入口不完全一致。
- 底部全局状态用 14–34px 星形呼吸动画，视觉权重高且会与正文争夺注意力；等待与取消也未形成明确语义。
- 助手正文已采用平面布局、用户消息已有气泡、Markdown 已区分代码和引用，但阅读列、块间节奏、元信息和输入卡片仍可进一步统一。
- 输入卡片默认 20px 圆角和较大阴影，消息列、状态行、输入区尚未共享同一居中宽度，宽屏下容易产生割裂感。

## 参考 Codex 的设计原则

- 单一阅读轴：正文、工具活动、运行状态和输入区共享居中列，宽屏不无限拉长，窄屏保留安全边距。
- 类型与状态正交：左侧图标表示工具类型，右侧小状态表示等待、运行、完成、失败或取消。
- 渐进披露：主列表只展示动作、关键摘要和详情入口；完整载荷继续按需打开，不回填长输出。
- 克制动效：只有等待、运行和思考状态使用动画，且放在固定尺寸槽位中；静态终态不闪烁、不造成布局跳动。
- 文档式正文：助手回答以正文层级为主，用户输入使用轻量表面；工具和元信息退到次级对比度。
- 文字自然：中文使用默认聊天字体，只有纯 ASCII 路径、命令或代码允许等宽字体。

## 设计决策

- 复用现有 SVG `Icon` 注册表，不使用 emoji 或引入新图标依赖；调整现有语义映射并新增 UI 层生命周期表示。
- 工具标题保留领域专用内容，只统一头部骨架、图标槽、状态槽、字号、间距和主题色，不抹平专用交互。
- 完成态低对比、运行态使用主题强调色、等待态使用克制的暖色、失败态使用危险色、取消态使用中性弱色。
- 全局状态改为固定尺寸的小型状态标记，保留耗时、token 和当前动作，但缩短文字并折叠空白，避免视觉突变。
- 会话性能计划中的轻量工具卡片是本计划前置条件；本计划不重新引入内联长输出或额外滚动容器。

## 架构说明

- `tool_meta.rs` 维护展示语义，专用视图只消费结果；`global_status.rs` 负责活动摘要，消息模块负责正文层级，外壳只负责宽度与间距。
- 所有滚动条维持 4px；暗黑主题优先校验对比度，动态中文路径必须走真实渲染检查。

## 成功标准

- 读取、编辑、终端、搜索、网页、Agent、MCP、任务等常见工具具有可区分的仓库内 SVG 图标。
- 等待、运行、完成、失败和取消在工具行中具有一致状态图标、文案和色调，未知状态安全退化为中性展示。
- 状态动画不改变行高；请求进行时可见，终态不持续抢占注意力，中文状态文案简短且一致。
- 助手正文、列表、引用、代码、思考块、用户气泡和元信息层级清楚；宽屏行长受控，窄屏无截断。
- 消息列、状态行和输入卡片在暗黑、明亮和带皮肤背景时形成连续阅读轴，无非 ASCII 字形整形 panic。

## 依赖与执行

- 外部前置：先完成并删除 `.plans/2026-08-20-llm-会话卡顿治理/6-轻量工具结果卡片.md`，再开始本计划任务 1。
- 本计划按批次 1–6 线性执行。各任务共享工具展示与会话样式，且全量 clippy 会争用同一构建目录，不安排并行批次。
- 每个任务只修改其列出的文件；发现协议字段不足时先记录阻塞，不在 UI 任务中扩大会话数据模型。

## 开发策略

- 对会改变行为的代码，使用失败验证-通过验证-重构。
- 在实施步骤前规划失败验证命令和预期失败。
- 将实施步骤限制在失败测试所证明的行为范围内。
- 测试真实行为，不验证模拟对象或实现细节。
- 每个任务完成前执行聚焦测试和 `cargo clippy --all-targets --all-features -- -D warnings`；不运行全量 `cargo test`、fmt check、wasm check 或 Makefile 命令。
