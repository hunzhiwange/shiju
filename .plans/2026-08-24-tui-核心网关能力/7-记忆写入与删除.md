## 上下文

- 写入语法固定为 `/memory remember <key> <content>`，请求体为 `key`、`content`、`category:"core"`。
- 删除语法固定为 `/memory forget <key>`；只允许删除最近 memory 查询/目录中的稳定 key，并要求破坏性确认。
- 所有写入都必须确认，因为服务端可能覆盖当前查询未展示的同名 key；成功后重新查询，失败不乐观更新。

## 测试计划

- 行为：所有写入与删除都必须确认，未知 key 删除被拒绝，Gateway 失败不改本地目录。
- 失败验证测试：新增 `memory_mutation_parser_requires_key_and_content`、`memory_mutations_confirm_overwrite_and_delete`。
- 失败验证命令：`cargo clippy --all-targets --all-features -- -D warnings`
- 预期失败原因：memory mutation route、confirm intent 和 runtime 调用尚不存在。
- 通过验证命令：`cargo clippy --all-targets --all-features -- -D warnings`
- 模拟策略：HTTP fixture 校验 POST JSON 与编码后的 DELETE 路径；不模拟 overlay。

## 步骤
