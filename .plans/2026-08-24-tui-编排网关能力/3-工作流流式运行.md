## 上下文

- 请求使用 `GatewayWorkflowStreamRequest`，`user` 从当前会话稳定 ID 派生，UUID 必须属于当前 Workflow snapshot。
- 新增 `ActiveStreamKind::Workflow`，与 chat/plan-run 互斥；持有 request/run/conversation ID，不复用聊天取消协议。
- `GatewayWorkflowStreamEvent` 映射到现有 step/progress/text/terminal 展示；Unknown 与 Error 必须可见。

## 测试计划

- 行为：动态 Workflow 命令只运行已加载 UUID，SSE 顺序投影为节点、文本和单一终态，并记录暂停归属数据。
- 失败验证测试：新增 `workflow_dynamic_command_requires_catalog_uuid_and_query`、`runner_projects_workflow_stream_and_single_terminal`。
- 失败验证命令：`cargo clippy --all-targets --all-features -- -D warnings`
- 预期失败原因：动态命令、Workflow active stream 与事件适配尚不存在。
- 通过验证命令：`cargo clippy --all-targets --all-features -- -D warnings`
- 模拟策略：使用真实 HTTP SSE fixture；不模拟 adapter 输出。
