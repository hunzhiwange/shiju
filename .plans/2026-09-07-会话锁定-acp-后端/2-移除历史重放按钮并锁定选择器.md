# 任务 2: 移除历史重放按钮并锁定选择器

批次：【批次 2】 依赖批次 1

状态：未开始

目的：让输入面板在会话开始后不可展开 ACP 选择器，并移除四种历史重放按钮及最近条数输入框。

来源任务：无

预计会话范围：只修改输入面板的 ACP 控件渲染和相邻测试；复用任务 1 的统一判定，不清理协议字段或其它 ACP 配置入口。

## 文件

- 修改：`crates/vw-desktop/src/app/components/input_panel/mod.rs`
- 测试：`crates/vw-desktop/src/app/components/input_panel/tests.rs`

## 上下文

- `acp_selector_button` 当前始终构建可展开 popover；`view` 在三个布局分支中调用 `acp_history_controls`。
- 会话开始后保留当前 ACP 图标/标识，但不应产生 `ToggleAcpPopover` 交互；空会话行为不变。
- 删除 `acp_history_controls` 及其三个布局调用和专属测试；不得删除 `AcpHistoryReplayMode`、请求字段、配置解析或消息枚举。

## 测试计划

- 行为：新会话 ACP 选择器仍可交互，已开始会话选择器被锁定，所有输入面板布局均不再渲染历史重放控件。
- 失败验证测试：更新 `optional_selector_buttons_reflect_app_state` 并新增 `acp_selector_locks_after_session_started`；将历史控件测试替换为输入面板子树不包含历史策略交互的结构断言。
- 失败验证命令：`cargo clippy -p vw-desktop --all-targets --all-features -- -D warnings`
- 预期失败原因：测试期望的新选择器接口/锁定状态尚不存在，且现有输入面板仍构建 `acp_history_controls`。
- 通过验证命令：`cargo clippy --all-targets --all-features -- -D warnings`
- 模拟策略：使用真实 `App` 状态构建 Iced `Element`，检查控件结构与消息能力；不模拟渲染器。本次删除中文按钮且不新增字体路径，无需额外字形渲染场景。

## 步骤

1. 先更新输入面板测试，覆盖空会话可选、已开始会话锁定和历史控件消失。
2. 运行失败验证命令并确认预期失败。
3. 复用任务 1 判定调整 ACP 选择器交互，删除历史重放控件函数和三个布局分支中的调用。
4. 运行全仓库规定的通过验证命令，并审查只移除了聊天输入区按钮。
5. 仅在检查保持通过时删除由 UI 移除产生的未使用 import 或局部变量。
