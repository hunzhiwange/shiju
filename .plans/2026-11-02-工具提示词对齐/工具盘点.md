# 实际注入工具契约盘点

审阅日期：2026-11-03。任务 1 无前置依赖；本产物仅为源码静态审计，不代表模型效果评测或真实工具执行成功率。未修改生产代码。参考本地 Codex `codex-rs/core/src/tools/handlers/`；参考目录无 Git 元数据，无法记录提交版本。

## 注入边界与计数口径

- 工厂依据：`crates/vw-agent/src/tools/toolset/mod.rs` 的 `default_tools_with_runtime`、`all_tools_with_runtime`、`execution_environment_for_config_inner`、`tool_specs_for_context`。完整工厂覆盖下表全部工具；默认工厂仅 shell 四项、文件七项及非空时 batch。Windows 另有 PowerShell，完整工厂 shell 分支另有 git_operations；文件分支另有 worktree 两项。
- 浏览器、HTTP、fetch、search 按配置启用；AgentTool 仅在有 enabled 且 allow_as_subagent 候选时注册；PDF/screenshot 仅 native。表为所有条件分支的并集，不表示每个模型每次都收到全表。Exa 与其它 WebSearch 实现互斥，共用稳定 ID。
- `traits.rs` 已迁移至 `tools/traits/mod.rs`。`ToolSpec::new` 将 id/name、input_schema/parameters 镜像；有 spec 覆盖时以覆盖后的稳定 ID 和 description 为准，不能只统计 name()/description()。
- 最终 native 模型路径 `session/llm/aisdk/stream.rs` 将 `spec.id`、`spec.description`、`spec.input_schema` 转为 AiTool。description 原样复制，无日期模板替换；可选严格处理递归设置对象 additionalProperties=false（`aisdk/util.rs::normalize_strict_object_required`，不能仅依该函数名或注释推断 required 被重写）。schema 转换失败会 fallback 默认 schema，此处只核对静态定义，不宣称捕获真实网络请求。
- 会话工具可替换同名工厂项，随后仍受授权目录过滤；MCP 先进入授权目录，按 discovery/search 状态延迟暴露。ACP 外部代理自带的远端工具不应等同此内置工厂目录。
- 字数使用 Unicode 字符数，包含换行与空白，不是词数或 token。文本资源按文件全文；内联字符串解码 Rust 转义，concat 拼接。动态项给出公式/边界，不伪造固定数字。
- 下表“字段”分号前为 required，分号后为可选；问号表示整组可选。条件必填仍由执行器校验。“一致性”按 schema 与 Args/execute/call/validate 路径核对，不是仅比较两个字符串。
