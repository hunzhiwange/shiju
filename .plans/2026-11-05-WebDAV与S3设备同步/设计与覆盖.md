## 架构与前置交接

1. 母任务1提供原样快照与许可；母任务2及其`网关服务底座原生化`子计划注册业务包，并提供统一存储/认证/执行主机合同。正式业务逻辑不得依赖upstream或Tauri/AppHandle。
2. `vw-agent-apps/src/device_sync/`负责类型化配置校验、manifest/摘要、归档、WebDAV和S3传输；不得反向依赖agent。agent的`src/device_sync/`负责真实统一存储/凭据/技能资源、应用与投影、任务/互斥及调度。API类型只在api-types；SDK只在client；Iced只使用SDK。
3. 母任务18提供统一存储的类型化导出、应用预览/恢复前回退点、跨数据库与技能资源恢复合同；母任务6提供作用域绑定凭据。它们当前没有可引用的已交付业务符号，任务3须记录真实交付符号和证据，后续代码任务以此为硬依赖。不能把整库快照、任意SQL执行器或新数据库当捷径。
4. 可同步类别覆盖各前置能力的供应商/MCP/技能/规则/组合/偏好等已定义共享配置；任务2逐字段形成允许表。日志/健康/用量/安装状态、设备地址和路径、连接凭据、授权令牌、自动同步状态和服务端任务均不进入同步包。未知字段默认拒绝/排除，接收端同样不信任远端分类。
5. 任务 1–3 可先核对文档。配置校验、归档和传输使用已交付的业务包与各自合同，真实快照、应用和回滚必须等待母任务 18 的对应生产接口。

## 拟定协议合同

- 选择识矩原生独立远端格式`shiju-device-sync`，初始protocol_version=1；data_compat_version由任务3绑定18已交付快照版本，不复用CC数据库代数。
- 远端路径`<remote_root>/<profile>/shiju-device-sync/v1/data-v<兼容版本>/`；制品固定`config.json`（18的类型化共享快照）、`skills.zip`、`manifest.json`。默认remote_root=`shiju-sync`，profile=`default`。不覆盖现有CC目录。
- manifest带format/version/data_compat_version/device_name/created_at/artifacts/snapshot_id；artifact带sha256和size，制品集合固定；snapshot_id保留上游排序摘要计算思想，manifest限制1MiB、单制品512MiB、归档最多30000条目、总解压512MiB。
- 保留两制品先上传、manifest最后发布、下载校验全部成功才应用、状态存储best-effort但附警告。固定key不是远端分布式事务：断点/并发写可能使远端临时不一致，读取必须检测并明确报错，不能把本地互斥宣传为跨设备锁。
- 同步是内容哈希变化判定后整份传输；不新增分块去重/二进制delta协议。远端与本地双方变化需明确冲突，执行时复核预览版本；无ETag时使用manifest摘要，不把HEAD失败当版本相同。
- 旧CC v2/db-v6与legacy db-v5属于来源事实：必须记录语义，但本次未要求兼容旧结构。旧SQL显式迁入由18唯一负责；本领域遇到旧/未知格式明确不兼容，不自动导入、迁移或写回原目录。
- 超时保留300秒基础加制品字节/16KiB每秒、空闲120秒；可控时钟验证，不在快速测试实际等120秒。下载流超限即停止，不只相信Content-Length。

## 拟定API合同

基路径`/v1/agent-apps/device-sync`；transport枚举只允许`webdav`和`s3`。只注册下列端点，不提供通用命令调用。

| 路径 | 方法 | 行为/任务 |
| --- | --- | --- |
| /{transport}/config | GET、PUT | 脱敏读取/显式SecretUpdate写入；41–42 |
| /webdav/config | DELETE | 清除本设备WebDAV配置，远端保留；43；来源无S3清除命令，不凭空扩展 |
| /{transport}/test | POST | 验证未保存草稿与凭据绑定，不保存；44 |
| /{transport}/remote | GET | 已保存配置的有界远端预览；45 |
| /{transport}/upload | POST | request_id与expected_remote_snapshot，202返回任务；46 |
| /{transport}/download | POST | 同上，下载前预览版本复核；47 |
| /tasks/{id} | GET、DELETE | 状态查询/取消；48–49 |

- Basic管理认证与可信TenantScope沿用实际网关，不把任意header宣称公司成员鉴权。host仅选择实际已支持执行端；现状只有网关本机时明确只支持该host，其他host返回unsupported/unreachable，不回落桌面。test/remote也需要权限和网络范围校验。
- 配置GET响应含脱敏last_status与active_task_id，桌面可发现自动任务并查询进度；不需猜任务ID或新增事件总线。配置存储作用域为租户+执行主机+传输连接；同步内容来自该作用域内经过授权选择的数据，不从请求接受任意存储namespace、SQL或文件根。作用域隔离不等于拥有未实现的跨公司认证。
- SecretUpdate明确Keep/Replace/Clear，不依靠空字符串猜测。Get仅secret_present；网络错误、URL/日志与状态均脱敏；连接身份改变不得继承其他连接秘密。自动同步默认关闭，两表单开启前确认，确认状态不跨设备导入。
- 启动请求不可盲目重试；request_id幂等仅绑定同作用域同参数；预览远端empty需与未提供expected字段区分。任务queued→running（阶段及单调字节进度）→succeeded/failed/cancelled/interrupted；冲突为结构化失败，警告附成功事实。提交临界区取消too_late，先完成或回滚，再返回实际终态。
- 状态包含manual/auto来源、最近成功/错误/基线、投影与持久化警告；断线通过GET恢复，重启中断不重放。保留范围/数量须遵循母任务2合同，不在此添加无调用者分页/SSE框架。
