# 会话入口优化计划

目标：为会话控制列表和智能体配置卡片补齐图标，突出开始会话入口，将智能体推荐会话收为紧凑菜单。

范围：桌面会话控制的智能体、工具、技能列表；已启用和官方智能体卡片的图标及开始会话按钮；当前智能体推荐提示词的菜单展示与开关生命周期。

范围外：不改变配置结构、智能体启停规则、已开始会话的身份绑定、ACP 安装与认证流程，不实现配置精简计划，不覆盖其他工作区改动。

假设：会话控制指输入区智能体/工具/技能选择浮层；推荐会话对应 recommended_prompts，继续只填充草稿。已有 CatalogLaunch 创建并选择新会话，缺少项目时明确提示。

## 设计决策

- 复用 ACP 品牌图标与 Robot 兜底；原生用现有 Hexagon，不新增图片依赖。
- 卡片使用明确的“开始会话”主按钮，复用既有启动链路。
- 推荐会话沿用 Git 菜单交互；平铺仍占空间，独立面板增加层级。

## 架构说明

- 沿用 icons、tool_selector、catalog 与 AboveOverlay，菜单状态仅驻留桌面 UI。
- 不放宽会话启动和身份切换守卫；中文默认字体、4px 滚动条及内容留白。

## 开发策略

- 行为变更先编写并运行失败验证，再最小实现和通过验证；测试放独立文件。
- 使用真实 Iced 布局、绘制及事件测试，不以源码字符串断言代替用户行为。
- 明暗主题均检查中文、长名称、长推荐列表和窄窗口；保留选中标记。
- 任务执行顺序、批次、证据要求见编号任务和 prompt.md；本文件生成后只读。
- 本轮只生成文档，不执行 Cargo；实施阶段遵守任务中的共享槽位规则，聚焦测试后执行仓库要求的 Clippy。
