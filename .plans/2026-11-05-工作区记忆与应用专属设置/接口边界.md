# 拟新增接口与执行边界

这些是本计划定义的实施合同，不是当前已实现的符号或路由。任务 1 必须对照母任务 2 实际交付的上下文/路由前缀/主机寻址/任务合同登记最终符号到正式文档；职责已有时沿用，不能形成第二套服务。未交付时阻塞代码任务。

- 请求复用前置认证的租户、用户、项目和执行主机上下文；不得信任裸路径或客户端自报租户即授权。API 基础前缀沿用现网，以下为领域相对路径。
- 文件和记忆内容可由已获授权编辑者原样读取，但不进入普通列表日志、错误或全局记忆；env 内容需独立敏感读取权限，未授权拒绝而非用掩码覆盖真实值。
- workspace 文件枚举严格对应 AGENTS.md、SOUL.md、USER.md、IDENTITY.md、TOOLS.md、MEMORY.md、HEARTBEAT.md、BOOTSTRAP.md、BOOT.md。
- 日期 filename 是有效公历 YYYY-MM-DD.md。列表/搜索只收合法普通文件；不沿用上游任意 .md 扫描和符号链接越界缺陷。摘要偏移必须按原文字符边界，不能复用 lowercase 字节偏移切原文。
- 工作区 GET/PUT `/agent-apps/openclaw/workspace/files/{filename}`；每日 GET `/agent-apps/openclaw/workspace/daily`，GET/PUT/DELETE `/agent-apps/openclaw/workspace/daily/{filename}`；搜索 POST `/agent-apps/openclaw/workspace/search` 使用前置可取消任务合同，查询显式传输。目录 POST `/agent-apps/openclaw/workspace/open-directory` 只收 workspace/memory。
- OpenClaw GET/PUT `/agent-apps/openclaw/settings/model`、`catalog`、`defaults`、`env`、`tools`；GET `/agent-apps/openclaw/settings/health`。各分节显式路由，不接受任意 JSON 路径或命令名。保留 JSON5 非目标文本、未知字段、写警告与冲突结果。model/defaults 修改共用前置配置写锁。
- Hermes GET/PUT `/agent-apps/hermes/memory/{kind}`；GET `/agent-apps/hermes/memory-limits`；PUT `/agent-apps/hermes/memory/{kind}/enabled`；GET `/agent-apps/hermes/model` 只读，调用母任务 4 的模型快照服务。
- Hermes POST `/agent-apps/hermes/dashboard/probe` 和 `/agent-apps/hermes/dashboard/start`；启动复用前置取消/进度。探测使用目标主机 loopback。浏览器在桌面执行，仅使用受支持、本机可访问的地址；无隧道/受支持远程协议时明确不可用，不新建协议或转发 token。来源实际接受所有 HTTP 响应为在线，不能按注释误改成仅 200/401。
- DTO 用 Rust 强类型与 serde；未知扩展字段只限应用配置对应分节；IO 错误、拒绝、缺失、离线、取消、写入冲突和警告不能统一吞掉为空对象。SDK 不拼原始 Tauri command。
- 模型选择列表复用母任务 5 的目录投影服务，登记 provider/model 组合去重、名称回退和中文排序证据；母任务 5 缺契约在任务 1 阻塞，不由 Iced 临时绕过。
- 不新增 Hermes 深层模型/工具/cron 配置编辑：来源在 Hermes 自有 Web UI 提供。预算只读，开关可写。预算字符口径保持 TS length 的 UTF-16 单元语义，不强制截断用户记忆。
