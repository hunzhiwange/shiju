# 实施接口契约

本文件定义本子计划拟新增接口，不表示仓库已经存在。各任务先复核真实前置交付；若母能力2提供不同等价路径，在对应任务记录实际路径，不改只读plan.md。纯文档计划无Cargo调用。

## 实施前置与所有权

- 母1/2：vw-agent-apps包、服务生命周期、认证作用域、持久化/事务、长任务进度取消、事件设施。母3/4/5/6：应用路径、供应商/项目/模型ID、账户隔离。母8/9：代理终结点、请求身份、错误与重试事实。母14/15/16：外部会话只读读取器、项目归属和作用域。只有消费项目归属和作用域接口的任务需要等待对应交付。
- 当前事实：根 workspace 已注册 vw-agent-apps；API类型和SDK各无feature段；vw-agent默认带rag-pdf/firecrawl等；vw-desktop默认features为空，主bin为shi-ju；vw-agent设autotests=false，新增其测试必须显式注册。
- API参考：gateway/api/handlers/integrations.rs的require_auth、gateway/bootstrap.rs的client_router；SDK参考client/provider_api.rs与directory_query；桌面现有views/usage为当前会话视图，不能拿内存累计值代替全局账本。
- 余额/套餐/账户脚本及UsageCache由母7唯一拥有；本计划消费其状态和限额接口。models.dev下载/模型目录由母5唯一拥有；本计划拥有价格选择与同步。母14拥有日志路径和会话解码，分析仅提取用量投影。
- 只支持有来源证据的11扫描器：Claude、Codex、Gemini、OpenCode、GrokBuild、Pi、OMP、MCode、AGY、Kimi、DSH。Claude Desktop共享Claude身份；DSH双端共享目录。Hermes/OpenClaw等未在sync_all_unlocked注册专用扫描器，不伪造原生支持，可经已支持路由来源计量。

## 拟新增文件与导出

- `crates/vw-api-types/src/usage.rs`与独立`usage_tests.rs`：请求记录/分项、过滤器/范围、聚合、分页、扫描/维护任务、价格、汇率、显示设置与错误DTO。由src/lib.rs导出；测试模块使用独立文件。
- `crates/vw-agent-apps/src/usage/mod.rs`为领域导出，各编号任务列出的同级文件为窄实现；`tests/usage_<标识>.rs`为对应集成测试并由Cargo.toml按需要注册。母2公共存储与任务设施不复制。
- `crates/vw-agent/src/usage_bridge/`为relay/native/events接入；`gateway/api/handlers/usage/{read,scan,prices}.rs`为具名处理器；只在既有bootstrap.rs、handlers/mod.rs及服务生命周期做必要连线。
- `crates/vw-gateway-client/src/client/usage_{read,scan,price}_api.rs`及独立对应测试，由client/mod.rs导出。
- `crates/vw-desktop/src/app/views/usage/center/`按state/logs/overview/groups/charts/scan/pricing/models/display分文件；复用现有Message/App状态和settings控件，不复制业务存储与调度器。
- 新的测试函数过滤统一`usage17_<标识>_`；这些测试在对应任务中创建、命名和注册。本计划的cargo命令在前置包注册后才可执行，零测试不可完成。

## 记录与计费

- 原始身份包含执行主机/认证scope、应用、来源、原生request/session与稳定文件身份；跨来源共享同一canonical记录，保留来源关联。供应商来自证据，无证据为unknown。
- Token包含输入、输出、reasoning、cache read、cache creation及1h子集，明确fresh/total语义。reasoning若已在output中不得再次相加。成本区分原生/计算/估算/未知，金额使用Decimal字符串，账本基准USD。
- 记录保存request_model、response_model、pricing_model及倍率依据；实测/估算首字、延迟、速度分别标记，缺值为空。无usage失败请求可保留状态，但合成零usage不得虚增计费请求数；同时返回总请求与计费请求数。
- 同请求源到达顺序不影响计数；无稳定关联仅标疑似重复。归档必须保存可防重放身份或等价水位，禁止删明细后清空游标重新累加历史。
- 价格同步采用显式自定义覆盖优先：自动价格更新不覆盖标记为自定义的价格；手工批量导入必须明确来源。补价只更新未知计算成本，不改原生费用。与源默认有差异处在覆盖证据中标注该选择。
- 时间统一UTC存储，显式IANA时区解析范围/分桶。对外start/end为Unix秒，服务解析返回统一边界；持续范围每次查询重算，日历范围不能使用固定24h相减替代。

## 拟定API清单

前缀`/v1/usage`；按母2现有请求上下文确定目标主机/租户/项目，不能用query冒充其他scope。下表方法是本计划拟定合同，均由SDK封装。

| 方法与相对路径 | 语义 | 任务 |
| --- | --- | --- |
| GET /logs、/logs/{id}、/sources | 分页/明细/来源分布和能力状态 | 42 |
| GET /summary、/summary/apps、/summary/sessions、/first-date | 总览/应用/会话/首日 | 42 |
| GET /stats/providers、/stats/models、/trends、/heatmap | 分组与时序 | 42 |
| POST /scans、GET /scans/last、GET /jobs/{id}、POST /jobs/{id}/cancel | 同步/完整扫描时间/任务/取消 | 43 |
| POST /maintenance/codex-rebuild、/maintenance/rollup、/maintenance/backfill | 具名维护任务 | 43 |
| GET/PUT /settings、POST /activity | 来源开关、暂停与显示/刷新设置、页面活跃意图 | 43 |
| GET/POST /prices、PUT/DELETE /prices/{id}、POST /prices/import | 定价CRUD及批量导价 | 44 |
| GET /models-dev/candidates、GET/PUT /models-dev/config、POST /models-dev/sync | 候选/选择/同步；结果由任务状态返回 | 44 |
| GET /rates、POST /rates/refresh、GET/PUT /display、GET /limits | 汇率缓存/手工显示配置/限额 | 44 |

- GET只读，不以访问页面触发破坏性维护。长操作返回202与task id；取消幂等。所有路由先鉴权/范围校验再解析敏感资源，400参数错、401未认证、403越权、404未知资源、409设置版本冲突、503外部源不可用；降级缓存单独返回stale/source/error。
- SDK只暴露具名方法；上游record_models_dev_sync_result映射为服务内部同步结果提交，不提供客户端伪造结果接口。fetch_models_dev复用母5获取，绝不变成任意URL代理。
- 事件沿用母2既有通道，新增用量revision/扫描进度类型而不新建WSS协议。200ms合并仅影响通知，落账不延后；重连由revision全量查询恢复。事件与缓存均按scope隔离。

## macOS验证策略

每个代码任务先写对应失败测试，再仅运行该过滤组；默认features，不指定其他平台target。每次Rust修改先cargo fmt --all，随后聚焦测试及cargo clippy --all-targets --all-features -- -D warnings。用槽位保留缓存，禁止全量cargo test、fmt --check、wasm和Makefile。

最后3个验收会话分别验证扫描、记账API、实际Iced绘制；不集中成超长会话。纯文档收口独立一项。只报告实际macOS版本/架构，不要求双架构和Windows/Linux打包。
