# 跨应用会话浏览恢复与历史迁移计划

目标：外部会话通过识矩 API、SDK 与 Iced 完整浏览、受控恢复及维护，仅验收 macOS。

范围：13 个来源适配器、项目/主机索引、分页搜索、结构化阅读/长正文/图片、删除、终端恢复、Codex 历史统一/备份回滚/压缩设置，以及原生桌面闭环。

范围外：Windows/Linux/WSL 运行验收、跨引擎续聊、改写加密正文、用户真实数据试迁移、重做母任务4供应商配置或15工作区功能；保留来源非 macOS 文件及能力登记。

假设：来源提交 ca58c0313360eae7c851fbd7553c1614c7af03e7（4.0.25）；vw-agent-apps 尚未存在。母任务1/2/3/4/13 的来源、底座、应用、配置事务及前置能力是代码执行依赖，规划不代表已交付。

## 设计决策

- 选择独立业务包经网关/SDK接入；直接复用 Tauri 命令会扩大信任边界，桌面直读文件会破坏主机隔离。
- 只恢复原应用；跨引擎导入缺少恢复身份保障，不采用。

## 架构说明

- API 类型→SDK；网关认证/主机路由→业务包→目标主机文件/进程。
- Iced 仅做展示与本机系统交互；原始 command/sourcePath 不能成为任意执行/读写入口。

## 开发策略

- 每个编号任务只交付一个窄模块或可测试行为；通常 30–90 分钟实现范围，冷编译和真实应用准备另计。任务卡含精确路径、验证和证据，不要求读所有任务。
- 先失败验证，再最小实现，通过后才重构；来源不存在的能力明确拒绝。完整来源审计与最终环境验收不用伪造失败测试。
- 并行批次和直接产物依赖以 prompt.md 及编号任务卡为准。公共入口与共享证据按母计划执行分线逐项合入。
- 初次规划不实现、不运行 Cargo，不修改母计划、母任务及历史来源清单。plan.md 生成后只读；任务卡管理状态，正式文档保留证据。
- crates/vw-agent-apps/src/sessions/ 下所有路径与符号均为本计划拟新增；API/SDK/UI 路径也在任务卡明确标记为新增。先核对母任务2实际合同，若已存在等价模块复用并在本任务记录落点，禁止另造底座或伪称现有接口。
- Rust 修改先 cargo fmt --all，再运行聚焦测试和 cargo clippy --all-targets --all-features -- -D warnings。仅 macOS host 默认 features 聚焦测试；全 features 用于强制 Clippy。不执行全量 cargo test、fmt check、wasm 检查、Makefile。
- 测试独立文件，注册进实际模块；有效数量必须大于零。使用隔离临时根/真实 SQLite fixture，不改全局 HOME，不用真实用户历史做破坏性测试。PostgreSQL 等底座能力复用已验收合同，不另建业务数据库。
- 缺账号、应用、终端或平台实测必须登记未验证；九种终端可分次补证，不把模拟进程等同真实恢复。macOS 最终所需证据未齐，相关任务保留待回归，母任务维持未完成。
- 明暗主题、统一表单/模态、4px 滚动条与双侧7px留白、中文不用等宽字体、实际字形整形无 panic、toast 均为桌面验收条件。
- source-map.md 逐来源映射是防遗漏索引，任务1须审计到实际函数/事件；Exit code 101 是测试文本候选，不据词法扫描建立虚假事件。

实机验收由用户按`.plans/2026-11-05-CC能力完整融合/人工验收.md`人工完成。自动任务以聚焦测试、隔离夹具和命令输出为证据，无需启动真实桌面、使用真实账号、截图或录屏。
