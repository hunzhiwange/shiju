# 设置与表单帮助卡片推广计划

**目标**　将「常规 → 界面」的问号帮助推广到桌面系统设置、配置弹窗和有解释文案的内嵌表单。

**范围**　覆盖常规其余标签和系统设置各分类及其配置弹窗。非设置入口覆盖项目编辑、知识库、专家中心、任务看板、工作流、应用书签、预览设置和 Git 提交表单。迁移页面标题、分组标题和字段旁已有的可选说明。

**范围外**　设置值、持久化、权限、控件统一计划、常驻业务状态、操作确认、聊天正文、外部应用和网页。

**假设**　576ac9637 是交互基线。「类似表单」指桌面端可编辑配置且含独立解释的入口。没有解释的字段维持现有布局。长篇帮助可沿用原有弹窗。

## 设计决策

- 页面内逐处实现容易漂移。全局替换会隐藏必要提示。沿用公共帮助卡片，在各入口显式选择迁移的说明。
- 复用现有标题和行布局，控制窄屏折行。说明沿用现有译文，字段错误、必填条件和风险继续在操作旁展示。

## 架构说明

- 从 `system_settings_common` 接入已有问号、侧边浮层和可选择富文本。右键菜单与聊天回复共用样式和动作。
- 配置页、弹窗和内嵌表单各自保留控件、焦点、保存、校验和状态逻辑。

## 开发策略

- 闲置时只呈现标题、控件、当前状态与必要提示。问号位于对应标题或字段名旁，悬停预览、左键固定，卡片内标题加粗，正文可跨行拖选。选区在移动指针和轻微滚动时保留。
- 右键弹出复制、添加到对话、百度搜索、Google 搜索、Bing 搜索。选择菜单项后才执行。复制快捷键使用系统习惯。菜单只接收静态帮助文字，选中时使用选区。添加到对话只更新当前草稿，搜索只在主动选择后打开浏览器。密钥、令牌、实际路径、用户输入和当前配置值不进入帮助卡片或菜单负载。
- 可随控件状态变化的有效范围、当前模式、保存状态及下一步操作应在原位可见。纯解释性的模式说明可以随状态切换进入卡片，但复制负载仍来自静态说明词条。保留独有的长篇指南和导航。
- 明暗主题、简体中文、繁体中文、英文和窄窗都走实际 Iced 布局。区分浮层与父级弹窗的关闭顺序，验证滚动、下拉菜单、键盘焦点、页签切换和字段搜索定位。
- 行为变更先跑失败测试，再实现和验证。使用真实视图、鼠标和键盘事件，外部浏览器和系统剪贴板只验证消息边界。所有样本使用虚构数据，渲染产物存到各自 Cargo 槽位。
- 与《表单控件统一》划分职责。沿用该计划已落地的公共输入及选项构造函数。遇到同一文件仍有其它会话改动，按差异区分归属，待相关修改落地后接入。按 `prompt.md` 的串行批次执行。
