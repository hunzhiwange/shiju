# Codex ACP Chat Completions 协议转换

让使用识矩客户端模型的 Codex ACP 会话通过既有模型中继连接支持工具的 Chat Completions 服务，覆盖实际 ACP 请求和工具回合。原生 Responses 继续走现有链路。

沿用网关持有的模型绑定、短期凭据和 SSE 转换。已有通用转换缺少 Codex 工具形态。桌面代理快照中的独立转换器依赖另一套会话与供应商状态，因此复用网关中继并补齐协议差异。代理只转换工具数据，执行及授权仍由 Codex 处理。

文本、图像、结构化输出、普通与命名空间函数、自由文本工具和上下文回放按协议能力转发。服务端托管工具和仅原生协议能表达的状态须明确限制。模型需具备其声明的输入和工具能力。
