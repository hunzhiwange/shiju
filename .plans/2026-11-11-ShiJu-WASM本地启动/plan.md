# ShiJu WASM 本地启动计划

目标：完整 ShiJu 应用在本地浏览器加载、渲染并接受中文输入。

范围：修复 vw-desktop 和调用依赖的 WASM 编译边界、浏览器文件与网络接口、启动时原生能力调用；提供本地启动和真实浏览器验收。

范围外：新建账户或技能中心 Web 产品能力、对外发布、修改其他任务业务逻辑。

假设：本机已有 Rust WASM target、wasm-bindgen 0.2.126、Chrome 和 Playwright；原生专用模块已有 cfg 边界但部分调用者遗漏。

## 设计决策

- 沿用现有 Web 网关与 Iced 渲染路径，补齐调用方平台边界。浏览器可用能力直接适配；原生能力明确不可用。
- 相比将整个原生账户/安装实现搬入浏览器，本方案避免引入本机文件和密钥存储行为。

## 架构说明

- 保留主应用与正常消息队列；不以验收示例替代产品。
- 不扩大网关权限、不关闭认证、不把秘密写入启动 HTML。

## 开发策略

- 线性执行两个批次，当前会话完成实现及验证。
- 编译边界使用真实 WASM 构建证明失败与通过；浏览器验收覆盖真实产品渲染、中文输入和设置交互。
