# 浏览器时间兼容计划

目标：核查浏览器可达的时间 API，修复不兼容调用并证明聊天与工作流操作不会因读取时间 panic。

范围：以 vw-desktop 为入口审计其工作区依赖的 Instant、SystemTime 及相关计时路径；修复已确认的工作流 ID 时间源，验证 agent_stream 已有 web_time 修复。

范围外：原生服务端时间 API、仅原生模块、第三方源码批量替换、ID 算法升级、全量测试及无关改动。

假设：当前 agent_stream 的缓冲区和聊天计时已修复；工作流编辑在浏览器可达，须在实施时以实际调用路径和运行证据复核。

## 设计决策

- 选现有 web_time 与共享时间工具；逐点 cfg 分支重复多，新增时钟抽象无必要。
- 单调计时保持 Instant，ID 保持毫秒时间戳；不修改 ID 格式与去重策略。

## 架构说明

- vw-shared::time 已提供跨平台时间；vw-desktop 已依赖 web-time。
- 沿模块 cfg 与调用链判定可达性；构建成功无法证明浏览器运行安全。

## 开发策略

- 对会改变行为的代码，使用失败验证—通过验证—必要重构。
- 工作流修复前先用真实浏览器重现；已有修复验证不得人为回退制造失败。
- 原生聚焦测试保障语义，浏览器回归保障时间读取；网关仅用本地固定响应。
- 任务按编号串行，批次与依赖见任务文件和 prompt.md；不并行占用源码与浏览器验证资源。
- 遵守 AGENTS.md：代码完成必须执行规定 clippy，不执行禁止的全量测试、wasm check、格式检查或 Makefile。
