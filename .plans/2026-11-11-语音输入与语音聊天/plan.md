# 语音输入与语音聊天计划

目标：为 ShiJu 桌面实现听写、可打断的语音聊天、语音设置和 macOS 跨应用语音输入。

范围：输入框麦克风、设备选择、自动或指定识别语言、词典、音色选择与试听、语音聊天热键、按住听写与双击免提、最近二十段本机录音、macOS 权限引导和跨应用插入、主动启用的前台屏幕上下文；包含网关鉴权、服务接入、真实窗口和音频验收。

范围外：修改 Codex 源码、借用 ChatGPT 私有服务或登录凭据、移动端与浏览器录音、Windows/Linux 全局注入、离线模型、发布安装包。

假设：以 macOS 为首个真实验收平台；本机音频后端按原生桌面设计，其他系统未经实测不得声称支持。首个服务采用公开 OpenAI 音频接口及用户显式配置的凭据；不假定已有聊天模型支持音频或截图中的音色可用。

## 设计决策

- 选网关代理公开接口；比桌面直连更易守住凭据边界，比复制私有 WebRTC 链路依赖少。
- 听写采用录音完成后转写；语音聊天采用双向流。独立配置能力，音色以服务契约为准。

## 架构说明

- 本机负责权限、采集、播放与插入；网关负责凭据、服务协议和会话隔离。
- 复用现有设置、消息与审批链；队列有界，取消后拒绝迟到数据，屏幕与留存默认关闭。
