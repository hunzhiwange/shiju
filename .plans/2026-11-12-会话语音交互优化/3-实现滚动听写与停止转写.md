## Cargo 共享槽位规则

1. 从仓库根目录直接使用已存在的 `python3 scripts/cargo_slot.py <命令及参数>`；入口自动领取或核验继承 `target/rust-slot-1` 至 `rust-slot-20`，不要在外层再手工领取第二个槽位。
2. 同一开发阶段将顺序原生检查放在一次入口调用中，持续复用缓存。例如 `python3 scripts/cargo_slot.py sh -c 'cargo check -p vw-desktop --lib && cargo clippy --all-targets --all-features -- -D warnings'`；实际 crate、features 与聚焦命令以本任务下文为准。下文裸 Cargo 表示入口内部命令，不表示允许绕过入口。
3. `CARGO_TARGET_DIR` 与 `CARGO_BUILD_BUILD_DIR` 由入口设置为同一槽位绝对路径，子脚本继承，不另建构建目录、不覆盖已领取路径、不执行 clean。任务涉及的二进制从该槽位定位。
4. 入口持有锁直到自有前台子进程组停止；常驻测试或应用存活期间不能提前释放。不启动脱离前台进程组的后台任务，不删除其它会话的锁、进程或缓存。正常、失败及中断退出后保留缓存。
5. 槽位只隔离缓存，不解除本任务的源码、任务依赖及验收资源互斥；20 个槽位不代表应并发运行 20 个重型构建。遵守现有批次与串行约定。
6. 完成时记录实际槽位、两个绝对目录、确切原生验证命令、退出码和有效测试数量。原生聚焦测试、整仓 `cargo clippy --all-targets --all-features -- -D warnings` 及要求的真实渲染、授权、音频与实机验收继续执行；零测试和热更新通过不能替代完成验收。

## 步骤

1. 先补真实布局事件与 App::update 红测，用确定音量序列证明历史移位、停止只触发一次转写、结果仅回填不发送；禁止测试函数仅名称匹配却没有执行组件事件。
2. 新建局部波形模块，固定有界历史（默认最多120个采样点），利用已有100ms Tick 追加摘要，历史向左移动、新样本从右进入，按可用宽度裁剪。静音为低幅圆点/短线，声音为居中竖线；用现有 SVG 渲染可避免新增 canvas 特性。
3. Recording 时以圆角横条替换输入编辑区：左侧叉号取消、中间 Fill 波形、右侧方形停止按钮及圆形向上确认按钮。两个结束入口均调用现有 Finish，停止 tooltip 精确为“停止听写”；确认 tooltip 为“完成听写”。悬停只显示 tooltip，不停录、不暂停动画、不转写。
4. 准备麦克风时显示明确准备态与取消，设备未 ready 不伪造音量；重复完成沿用 finish_requested。仅追加摘要而非每次读取重复旧振幅；无新数据按静音衰减，空闲不启动动画任务。
5. Finish 后立即进入“正在转写…”状态，停止采集波形、禁重复提交，保留取消；完成后复原编辑区并沿用原光标/原草稿回填。待应用结果保留明确“应用听写”和丢弃入口，不能隐式发送。
6. cancel、失败、超时、切会话/项目/网关、关闭时清理波形及在途结果；旧 Tick 和 Completed 无效。保留 Local 不访问云端及 Cloud 显式配置路线；使用 toast 呈现错误。
7. 运行绿测与 `python3 scripts/cargo_slot.py cargo test -p vw-desktop --lib voice_task_07_ -- --nocapture`、`python3 scripts/cargo_slot.py cargo test -p vw-desktop --lib app::message::voice::new_draft_tests -- --nocapture`、`python3 scripts/cargo_slot.py cargo test -p vw-desktop --lib voice_dictation -- --nocapture`；后两项执行前核实最新模块注册，若模块名已变化须记录并使用实际非零测试入口，最后 clippy。所有中文默认字体，图标居中，窄窗口波形收缩而按钮不被裁掉。
