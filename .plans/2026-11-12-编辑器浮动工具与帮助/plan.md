# 编辑器浮动工具与帮助计划

目标：在设置图标旁新增使用帮助，以 Zed 风格浮动菜单整合现有 API 支持的编辑操作与设置，展开不挤占编辑区。

范围：内置文件编辑器的工具栏、操作菜单、快捷设置、普通/Tab/Vim 帮助、现有系统编辑器设置复用及原生浮动搜索入口；包含明暗主题、只读保护、焦点与实际渲染验收。截图和依赖能力详见 `参考与能力.md`。

范围外：完整 Zed IDE、编辑器内核改造、升级依赖、私有 API、无公开 API 的整词/正则搜索、全选匹配、Helix、Git blame、诊断导航、AI 预测、迷你地图。

假设：新增显示开关、Vim 与缩进选择作用于当前标签页会话；已有全局主题、字号、行高和 LSP 沿用原持久化范围。系统配置整合仅指编辑器相关设置。

## 设计决策

- 采用锚定浮层与现有设置弹窗共用表单；内联面板会挤占空间，完整重造搜索需私有 API，均排除。
- 以锁定 v0.4.4 源码为能力依据，截图仅作视觉参考。

## 架构说明

- 沿用 preview_panel、EditorMessage 与公共设置控件；操作通过现有 EditorEvent 管线。
- 当前编辑器状态直接读取；保持只读和保存边界，不新增网关配置。

## 开发策略

- 对会改变行为的代码，使用失败验证-通过验证-重构。
- 在实施步骤前规划失败验证命令和预期失败。
- 将实施步骤限制在失败测试所证明的行为范围内。
- 测试真实行为，不验证模拟对象或实现细节。
- 线性顺序和批次见 prompt.md；任务文件是进度来源，本文件生成后只读。
