## 交互与配置决定

- 顶部路径右侧按“搜索、操作、设置、帮助”紧凑排列；保存、撤销等现有必要入口保持可达，项目模式不能因旧 toolbar 早退导致新增入口消失。
- 操作、快捷设置、帮助均锚定图标下方，以 Iced overlay 覆盖正文，禁止用 column.push(panel) 扩张布局。圆角、细边框、阴影、分隔线、选中主色，保持现有应用字号比例，不按 2x 截图尺寸机械复制。
- 三个外围面板互斥；Escape、点击外部、重复点击、切换/关闭文件时收起。点击面板不穿透正文；关闭后可继续键盘编辑。
- 设置浮层展示当前文件开关和“完整编辑器设置”；完整设置打开已有标准配置弹窗，复用系统编辑器字段。保留系统设置导航，整合表单与数据来源，不搬走所有系统配置。
- 已有全局设置保留现有持久化与应用到新旧编辑器的逻辑；新增开关只作用当前实例，UI 明示“当前文件·本次打开有效”，重开恢复底层默认值。这样避免为外围功能扩展配置协议。
- 搜索 UI 不能在无公开 API 情况下重做成截图横向布局；保留底层原生紧凑浮层是明确边界。帮助和菜单外观可按截图实现。
- 普通模式 Tab 插入所选缩进；Shift+Tab 实际走焦点导航，搜索框内 Tab/Shift+Tab 切换字段。以固定版本实际键盘路径为准，不能照 Message::Backtab 的旧注释写成反缩进。
- 帮助区中文及非 ASCII 统一默认字体，只有单独纯 ASCII 按键块可等宽。介绍普通编辑、搜索、折叠、命令面板、多光标和 Vim；不宣称完整 Vim。
- Vim 文档包括 hjkl、w/b/e、0/^/$、gg/G、计数、i/a/I/A/o/O、v/V、d/c/y、dd/cc/yy、x/p/P、u/Ctrl+R、/、n/N、:N、:w/:q/:wq、Escape；寄存器与系统剪贴板区别；:q 仅退出 Vim，不关闭文件。
- 所有滚动条 4px，内容两侧预留7px；配置类长表单只滚正文，标题/操作固定，统一使用 system_settings_common 控件。反馈使用 toast。
