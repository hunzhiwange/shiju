## 验证计划

结构迁移不改变业务行为，人为制造红灯不适用。优先迁移既有行为测试，测试数量以执行前清单和平台 cfg 为准；迁出后不能通过减断言或保留重复副本凑数量。边界测试使用临时数据和真实本地实现；网络/系统边界规则见专属约束。

```sh
cargo test -j 1 -p memory-types --lib memory::traits:: &&
cargo test -j 1 -p memory-types --lib memory::backend:: &&
cargo test -j 1 -p memory-types --lib memory::none:: &&
cargo test -j 1 -p memory-types --lib memory::embeddings:: &&
cargo test -j 1 -p vw-agent --lib memory::embeddings::tests:: &&
cargo test -j 1 -p vw-agent --lib package_boundaries::memory_types_tests:: &&
cargo tree -p memory-types -e normal
```

预期：9+10+4+5 个契约/空实现原测试通过；agent 剩余工厂及 HTTP fixture 测试有效大于零；新边界测试 1 个有效通过。所有必要命令退出 0、failed=0。新包单测编译过同一目标不重复 check；agent 边界测试同时编译直接调用者。此阶段不运行整仓检查。

所需证据：原/新测试清单映射及实际有效数、失败/ignored/内部跳过情况、生产依赖接线与树、旧入口类型身份或实际路径行为、迁移函数体无语义变化、槽位双路径/退出码/进程收尾。统一回归由总计划 D 承接，不在本任务重复。
