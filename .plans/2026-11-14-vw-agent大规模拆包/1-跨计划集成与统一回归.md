## 验证命令

已领取同一槽位的前台阶段运行，前一步成功再执行下一条：

```sh
cargo metadata --no-deps --locked --format-version 1 &&
cargo test -j 1 -p vw-agent --features memory-postgres,memory-mariadb,sandbox-bubblewrap,sandbox-landlock --lib package_boundaries:: &&
cargo test -j 1 -p vw-agent --features memory-postgres,memory-mariadb --lib memory::mod_tests:: &&
cargo clippy -j 1 --all-targets --all-features -- -D warnings
```

预期：元数据包含 13 个新增 libs 成员（前置四包另计）；package_boundaries 中新迁移测试至少 13 个有效通过；memory 工厂定向族有效大于零、failed=0；Clippy 退出 0。既有无关 Clippy 失败不得改写为通过。

依赖树逐包核对使用 `cargo tree -p git-discovery -p project-storage-paths -p secret-store -p gateway-pairing -p process-sandbox -p memory-types -p memory-markdown -p memory-sqlite -p memory-postgres -p memory-mariadb -p memory-lucid -p memory-response-cache -p memory-snapshot -e normal --locked`；确认输出包含实际已实现的包，无隐蔽 feature 默认开启。

所需证据：13 个生产依赖及模块迁移差异、每个原测试归属与最新有效输出、集成命令退出码、feature/平台核对、内部跳过清单、一次公共检查新结果及性能结论边界。只有具体外部缺口或无关阻塞才保留待回归，不能把未验证写成通过。
