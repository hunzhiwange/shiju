# vw-config-types 全面拆分计划

目标：为配置数据与默认逻辑建立单向领域库，原包只保留发布门面。

范围：完整归属见 [源码审计](audit.md)；本计划准备实施，尚未完成代码拆分。

范围外：业务行为、安全策略、依赖升级与动态验证。

假设：基于当前 0.6.0、edition 2024；后续会话开始时重新核对源码。所有 config-* 目标都是拟建接口，不是现存库。

## 设计决策

整体搬包无法隔离职责；每个类型建库会放大清单成本。选择按配置领域分库，大文件先局部分层，再迁移。UI 与安全保留各自领域组合根，不混入运行引擎。

## 架构说明

箭头表示调用者依赖被调用者：aggregate → 各领域；agent → agent-profile、tools；channels → agent-profile、channel-services、channel-types；channel-services → channel-types；ui → voice、gateway；security/worktree → runtime-paths。无反向边。其余领域为叶子。门面 → aggregate 及各领域。
