## 验证

以下命令在已领取的同一槽位环境依次成功后运行下一条：

```sh
cargo metadata --no-deps --format-version 1 --locked &&
cargo tree -p patch -e normal --locked &&
cargo tree -p domain-matcher -e normal --locked &&
cargo tree -p content-guard -e normal --locked &&
cargo tree -p memory-algorithms -e normal --locked &&
cargo clippy -j 1 --all-targets --all-features -- -D warnings
```
