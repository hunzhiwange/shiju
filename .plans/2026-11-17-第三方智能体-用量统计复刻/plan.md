# 第三方智能体用量统计复刻计划

目标：以本机 cc-switch 源码和七张截图为基准，在 ShiJu 第三方智能体中精确复刻用量统计的布局、交互和统计语义。

范围：独立入口与今日摘要、日期时间范围、十一应用及供应商/模型筛选、四项指标、趋势图与热力图、日志/供应商/模型三标签、详情分页排序列设置、用量设置抽屉、扫描与 Codex 重建、币种显示、模型定价及 models.dev 同步。

范围外：重写第三方智能体其他页面、修改品牌、发布、读取真实私有会话内容、迁移历史数据结构。

假设：cc-switch 为只读参考；在 Iced 中复现视觉与行为，保留 ShiJu 项目/主机鉴权边界；截图金额和数量是示例而非硬编码数据。

## 设计决策

- 选择复用现有 Rust 网关和 Iced；嵌入 React 会新增双栈，另写账本会重复底层能力。
- 截图约束视觉，源码约束算法；发现两者差异时记录具体差异，禁止用静态占位冒充支持。

## 架构说明

- desktop-usage/center 持有状态；desktop-navigation 与 vw-desktop 接线；gateway-usage-*、app-usage-store 提供数据。
- 保留身份、查询快照和请求代次校验，禁止跨项目或主机结果回写。
