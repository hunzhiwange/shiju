# 任务 43 · 共存集成与证据收口

先阅读并遵守 [公共执行规则](plan.md)。

批次：【批次 7】　依赖：任务 2 至 42

状态：未开始

目的：处理跨适配器共享根因，并核对注册项与当前共存证据。

## 步骤

1. 用 `crates/libs/acp-agent-registry/src/agent_registry.rs` 的 `BUILT_IN_AGENT_DEFINITIONS` 对照回执文件集，别名归原 key。写出 `docs/dev/acp/mcp-policy-audit/coexistence/README.md`，每个 key 一行，链接版本、平台、权限场景、结果及未验证项。
2. 本任务负责各卡已定位的共享实现、制品接线或测试缺陷。只改证据指向的共享分支。先用对应失败轨迹复现，再修复并重放受影响适配器。复核目标服务过滤、显式拒绝、调用归属、取消与撤除。共享改动完成后将复验条件与结果记入汇总，待回归任务复用该证据。
3. 核对五项整改的当前安装版本和入口与实际复验制品相符。已验证且未受共享修改影响的轨迹直接引用。

## 验证

用 `git diff --no-index --check /dev/null docs/dev/acp/mcp-policy-audit/coexistence/README.md` 核对格式，以无空白错误诊断为通过。有共享 Rust 修改且获授权时，按受影响路径选择现有目标，注册路径用 `python3 scripts/cargo_slot.py cargo test -j 1 -p acp-agent-registry --lib managed_runtime_tests::` 前先用源码确定相关单项测试名，将命令过滤条件缩至该单项；以非零有效测试和修复前后可对应的行为为准，并复跑对应适配器卡中的受影响场景。记录无法运行的目标及证据缺口。
