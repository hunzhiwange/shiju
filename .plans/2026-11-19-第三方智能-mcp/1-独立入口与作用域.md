# 任务 1 · 独立入口与作用域

先阅读 [公共执行规则](plan.md)。

批次：【批次 1】依赖无

状态：未开始

目的为迁出旧配置内的第三方管理入口，并建立无应用预选的宿主页面与作用域。

## 文件

- 修改 `crates/vw-desktop/src/app/components/{third_party_settings,system_settings_mcp,system_settings}.rs`、`crates/vw-desktop/src/app/components/system_settings_agents/mod.rs`、`crates/vw-desktop/src/app/mcp_link_preview.rs` 和 `crates/vw-desktop/src/app/message/settings/apps_catalog.rs`。
- 修改 `crates/libs/desktop-settings-mcp/src/{third_party,third_party_tests}.rs` 及 `crates/vw-desktop/src/app/components/third_party_settings_integration_tests.rs`。核对 `crates/libs/desktop-apps-ui/src/catalog_state.rs` 中泛型宿主的默认初始化。

## 步骤

1. 让 `ThirdPartyPage::Mcp` 直接从当前目录上下文启动，去掉 `expanded` 前置条件。将页面代次和凭据代次纳入动作守卫，发布目标重新校验同主机可信安装事实。保留同一上下文写入的原请求结算。
2. 将受管目录新增、编辑、导入、绑定、重写与相关诊断入口从智能体配置的 MCP 区移走，取消共享弹层的跨页串用。保留原有 ShiJu MCP 服务器配置、运行时检查和 ACP 独立选择。技能页招回误跳转只在查到真实旧调用时处理。
3. 把设置搜索的第三方 MCP 命中及明确确认后的 MCP 深链导到新工作页。先定位目标作用域再开深链预览，保留拒绝和失败行为。
4. 提供固定页头、滚动正文和独立弹层宿主，任务 7 接入矩阵与各工作流。迁移旧入口断言，使现有导入、重写和工具测试检查新宿主。

## 验证

- 新增 `third_party_mcp_route_` 前缀的断言，覆盖无预选进入、隔离旧入口、确认深链与过期动作拒绝。实现前运行下行命令，应命中旧预选或旧路由失败。
- 实现后运行 `python3 scripts/cargo_slot.py cargo test -j 1 -p vw-desktop --lib third_party_mcp_route_`。失败及通过阶段记录实际测试数与路由断言结果。
