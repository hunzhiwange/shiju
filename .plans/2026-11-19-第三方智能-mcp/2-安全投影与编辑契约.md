# 任务 2 · 安全投影与编辑契约

先阅读 [公共执行规则](plan.md)。

批次：【批次 1】依赖无

状态：未开始

目的为补充矩阵的安全连接摘要、JSON 导出，以及受管记录的元数据编辑契约。

## 文件

- 修改 `crates/libs/api-mcp-management/src/mcp_management.rs`、`crates/libs/agent-app-services/src/mcp/{catalog_update,catalog_update_tests,mod}.rs`。
- 修改 `crates/libs/gateway-mcp/src/server/{mcp_management_read,mcp_management_update}.rs`、相邻 `src/host_tests/mcp_management_{read,update}_tests.rs`、`crates/libs/gateway-mcp-read/src/mcp_management_read.rs` 和 `crates/vw-gateway-client/src/client/mcp_management_read.rs`。如需声明新接口，由本任务完成 SDK、路由及 DTO 接线。更新请求新增字段时同步修改构造点，包含 `crates/libs/desktop-settings-mcp/src/management_form.rs`，避免交付无法编译的请求契约。

## 步骤

1. 目录支持受限的公开连接摘要，优先复用已验证的静态模板匹配和现有显示元数据校验。允许用户明确提供可公开的命令或地址显示值，校验后供搜索和列表显示。已有私有连接无安全摘要时用传输名显示。真实命令、参数、工作目录、请求头、环境变量和私有 URL 走现有私有存储，禁止从私有连接猜测哪些值可公开。
2. 为「复制全部为 mcpServers JSON」和逐条复制提供同一网关授权下的安全结果。仅导出可证明为公开且完整的连接定义，例如与内置模板完整匹配的定义。按 ID 报告跳过项，受保护连接不要伪造成可导入的配置。全部不可导出时返回明确原因。若沿用现有公开 DTO，保持新字段可缺省且无私有定义。
3. 扩展修订检查下的更新请求，支持显示名、描述、标签、主页和文档的局部编辑及清除。连接编辑保持现有替换语义，允许只改元数据而无需提交私有连接。保留旧请求语义和已有凭据引用，元数据单改不递增连接修订。公开摘要由独立明确动作设置或清除，连接换掉时不带出过期的派生摘要。
4. 以同一受管目录为权威。沿用现有网关 scope 校验、公开元数据校验和 CAS。交付摘要、导出结果和更新请求类型供任务 3、4、6 使用。

## 验证

- 新增 `third_party_mcp_contract_` 前缀测试，先证明旧行为无法完成纯元数据更新、无法区分安全导出与不可导出项，再覆盖旧修订、跨租户、凭据留存和导出结果中的合成秘密缺失。DTO 新增能力可先建立返回不支持的窄入口以取得行为级失败。
- 失败与通过阶段分别使用 `python3 scripts/cargo_slot.py cargo test -j 1 -p agent-app-services --lib third_party_mcp_contract_` 和 `python3 scripts/cargo_slot.py cargo test -j 1 -p gateway-mcp --lib third_party_mcp_contract_` 验证各自的测试。记录两包实际测试数与脱敏断言。
