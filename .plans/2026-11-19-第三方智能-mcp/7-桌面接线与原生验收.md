# 任务 7 · 桌面接线与原生验收

先阅读 [公共执行规则](plan.md)。

批次：【批次 3】依赖任务 3、4、5、6

状态：未开始

目的为交付现有入口下完整可操作的原生界面，并核对七张图中的对应流程。

## 文件

- 修改 `crates/vw-desktop/src/app/components/third_party_settings.rs`、`crates/vw-desktop/src/app/message/settings/apps_catalog.rs` 及 `crates/vw-desktop/src/app/components/third_party_settings_integration_tests.rs`。
- 接好前序任务交付的矩阵、编辑器、导入、操作面板与作用域入口。若出现组合缺陷，只修当前流程所需的最短调用链。

## 步骤

1. 组合固定页头、搜索、矩阵、编辑、导入与所有菜单。品牌图标走 `desktop_settings_apps::system_settings_apps::list::brand_icon`。维持独立应用目录、技能配置、原生 MCP 与 ACP 的旧调用。确保网关重连、换项目、换主机可刷新该页。
2. 在两个窗口宽度下观察正文滚动、表头与行对齐、列末动作、命令和地址省略、目标多列布局，以及固定表单页脚。分别验证浅色与深色的层次、可读性、键盘焦点、中文和弹层点击拦截。以七张图逐项对照，并采用本项目原生间距和色彩。
3. 用受控网关和临时目录走添加模板、粘贴、勾选、保存、检查、重开编辑、导入、重写、JSON 复制及删除。加入部分失败重试、切上下文、窄窗横滚和隐藏列的交叉场景。禁止把用户真实应用配置当作夹具。
4. 核对兼容行为和未验收项，报告本次截图或渲染采证、命令、有效测试数及已知限制。完成后按公共收尾规则提交自己的接线和修复。

## 验证

- 新增 `third_party_mcp_workspace_` 前缀用例，接线之前应在页头、动作分发或隔离断言失败。接线后同命令确认真实宿主、明暗渲染与过期消息隔离。
- 失败和通过均运行 `python3 scripts/cargo_slot.py cargo test -j 1 -p vw-desktop --lib third_party_mcp_workspace_`。取得桌面运行授权后，从仓库根执行 原生入口 `python3 scripts/cargo_slot.py cargo run -j 1 -p vw-desktop --bin shi-ju`，逐项获取窗口实测证据。运行期间保持已有槽位，关闭自有桌面实例后释放。
