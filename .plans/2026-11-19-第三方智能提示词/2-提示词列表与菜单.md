# 任务 2 · 提示词列表与菜单

先阅读并遵守 [公共执行规则](plan.md)，再执行本任务。

批次为 2，依赖任务 1 的页面壳和作用域选择。状态为未开始。来源为截图 1、3、5。

目的为完成提示词工作页的文件状态、搜索、空态、条目和动作菜单。

## 文件

- 修改 `crates/libs/desktop-settings-skills/src/prompts/list.rs` 与 `update.rs`。必要时调整 `prompts/transfer.rs` 的界面接线，保留现有副作用。
- 搜索及菜单状态测试放在同目录新建的 `list_tests.rs`，由 `list.rs` 注册。接好任务 1 的桌面页面桥接。

## 步骤

1. 顶栏放页名、帮助、添加和更多。应用选择与目标文件状态在次级工具栏，已加载且有条目时展示搜索。窄窗允许工具栏换行。区分未读取、读取失败、文件缺失、空文件和已有内容。目标用 `PromptTargetPreview` 的真实路径与快照，不在主页面展开完整文件。
2. 更多菜单收纳刷新、导入当前文件、从本机选择文件、打开本机所在位置或复制远端路径、复制路径，以及现有同步与专属资源入口。缺失或空文件给出禁用原因，按 `TransferEvent` 的现有条件决定可用性。识矩系统提示词和项目规则保留可发现入口。
3. 空库居中展示当前应用与添加操作，搜索无结果提供清除搜索。对当前已授权目录条目按名称、说明、正文作本地不区分大小写的过滤。应用和主机切换清除查询和打开的菜单。列表项左侧显示名称、说明或简短首行、UTF-8 字节和可用元数据，`created_at` 只标为创建时间。右侧展示状态、启用／停用、编辑和更多。
4. 条目菜单保留复制到其他应用、复制正文、删除和现有撤销。区分忙碌与禁用态，按条目 ID 操作，保持现有版本校验。每次只展开一个菜单，菜单超出视口时调整位置；外部点击、滚轮或 Escape 的处理不能触发背后的条目。

- 获授权后前后运行 `python3 scripts/cargo_slot.py cargo test -j 1 -p desktop-settings-skills --lib prompt_library_search_matches_fields_and_resets_on_scope_change`。记录有效测试数及退出码。实机记录空库、有条目、无匹配、导入禁用和条目菜单两个主题截图，核验菜单关闭和点击无穿透。
