# 任务 3 适配私有配置与模型中继隔离

先阅读并遵守 [公共执行规则](plan.md)，再执行本任务。

批次：【批次 1】 依赖：无

状态：未开始

来源任务：无

目的：让受管 ACP 在 Linux x64 和 ARM64 上拥有可验证的私有配置和状态目录。

## 文件与范围

修改 `crates/libs/llm-runtime/src/acp/model_source/{profile.rs,profile_tests.rs,gateway.rs,gateway_tests.rs}`。

## 上下文

沿用已有 Unix 私有状态目录和回环模型中继。

## 实施

1. 复用 Linux 私有目录校验，覆盖临时目录与持久历史、创建中断、不安全父目录、符号链接和复用时权限变化。验证所有者及私有权限。
2. 保留会话级模型绑定和回环鉴权。凭据不进入 argv、公共日志或用户真实配置。撤销先关闭访问，再清理自有目录。
3. 提供可由现有驱动调用的验证路径，按任务 48 的接线约定交付。平台测试源码必须断言实际权限失败关闭。

## 验证

- 先写独立回归测试，使用 `acp_platform_private_profile` 作为测试名或前缀。旧行为预期失败点为受管目录被平台门控拒绝，或不安全目录未被拒绝。
- 后续在 Linux Docker 容器内使用同一红绿命令 `python3 scripts/cargo_slot.py cargo test -j 1 -p llm-runtime --lib acp_platform_private_profile`。仅列为后续命令，本轮不执行。绿灯要求命中本任务测试且零失败。
- 本轮静态逐项检查测试断言、调用者接线及本任务差异。记录受影响目标和待运行项。
