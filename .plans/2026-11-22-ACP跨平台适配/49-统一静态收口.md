# 任务 49 补齐 Linux 定向集成验证代码

先阅读并遵守 [公共执行规则](plan.md)，再执行本任务。

批次：【批次 5】 依赖：批次 4

状态：待回归

来源任务：无

目的：补齐 Linux Docker 定向集成验证脚本及测试源码，静态核对 82 个 key/架构组合。

## 文件与范围

修改 `scripts/verify_acp_integration.py` 及 `scripts/tests` 下对应独立测试。各适配器源码的功能修复归原任务，会造成跨模块接线问题的修复归此任务并记录边界。

## 实施

1. 核对真实入口，按无挂载、挂载、撤除三轮准备测试。对照原生和外挂技能、原生工具/MCP 与外挂工具独立标记、请求模型和协议、批准与拒绝的执行回执。覆盖取消、恢复及适配器支持时的分叉。
2. 宿主进程测试要核对退出和自有进程清理。使用回环模型与 MCP，保持既有真实工具和网关行为。
3. 对照注册表确认 41 个唯一 key 及其 82 个 Linux key/架构组合。每项标明源码已实现、待目标验证或具体阻塞。在本编号任务文件逐项注明目标架构、固定版本、制品、测试入口及权限证据，不把被阻塞行计为已支持。
4. 汇总可独立推进与仍需上游制品/能力的项目。以各编号任务的源码位置、接线记录及具体缺口作为静态审查证据。

## 验证

- 先添加 `scripts/tests/test_verify_acp_platform_integration.py`，旧脚本应因漏核拒绝后的服务调用、撤除或错误的续轮关联而失败。后续在 Linux Docker 容器内执行的红绿命令 `python3 -m unittest discover -s scripts/tests -p test_verify_acp_platform_integration.py`，绿灯必须命中新增用例且零失败。
- 本轮只审核脚本、测试源码及各编号任务的交付记录。
