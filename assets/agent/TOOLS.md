# TOOLS.md - 本地笔记

技能定义工具 _如何_ 工作。这个文件记录的是 _你自己的_ 具体信息 —— 也就是只属于你这套环境的内容。

## 这里放什么

例如：

- 摄像头名称和位置
- SSH 主机和别名
- TTS 偏好的声音
- 扬声器或房间名称
- 设备昵称
- 任何与环境相关的特定信息

## 示例

```markdown
### 摄像头

- 客厅 → 主要区域，180° 广角
- 前门 → 入口处，动作触发

### SSH

- 家用服务器 → 192.168.1.100，用户：admin

### TTS

- 偏好声音："Nova"（温暖，略带英式口音）
- 默认扬声器：厨房 HomePod
```

## 为什么要分开？

技能是可共享的，而你的环境配置只属于你。把它们分开，意味着你可以在不丢失个人笔记的前提下更新技能，也能共享技能而不泄露你的基础设施信息。

## SessionTool

`SessionTool` 协作当前工作区中的用户可见任务会话，不替代 `AgentTool`、plan-run 或 Agent Scheduler。

- `create`：创建并异步启动，立即可见且不切换当前会话。
- `send`：续发消息；忙碌目标会被拒绝。
- `read`：读取有界的历史输出。
- `status`：查询指定任务状态。
- `list`：列出当前会话发起的可见任务。
- `wait`：按 `any` 或 `all` 等待状态变化，单次最长 60 秒。

仅允许同租户、同项目、同规范化目录的任务，并拒绝 self、busy、未知 ID、跨作用域或非可见任务目标。
跨任务用户消息显示“由 ChatGPT 从另一项任务发起”；内部来源标记在展示和复制前被剔除。
