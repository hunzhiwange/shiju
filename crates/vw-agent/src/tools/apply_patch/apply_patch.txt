Use the `apply_patch` tool to edit files. Its patch language is a concise, file-oriented diff format designed to be easy to parse and safe to apply. Think of it as a high-level envelope:

*** Begin Patch
[ one or more file sections ]
*** End Patch

Inside this envelope is a sequence of file operations.
You must include a header specifying the operation you are taking.
Each operation begins with one of three headers:

*** Add File: <path> - Create a new file. Every following line is a + line containing its initial content.
*** Delete File: <path> - Delete an existing file. Nothing follows.
*** Update File: <path> - Patch an existing file in place, with an optional rename.

Example patch:

```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```

Important reminders:

- You must include a header describing the intended operation (add/delete/update).
- When creating a new file, you must prefix every new line with `+`.
