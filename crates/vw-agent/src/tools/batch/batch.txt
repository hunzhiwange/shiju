Execute independent tool calls concurrently (up to 4 at a time).

Payload format (JSON object):
{"tool_calls": [{"tool": "file_read", "args": {"path": "Cargo.toml", "limit": 20}}]}

- Supply 1-25 calls. Calls beyond 25 are discarded and reported as failures.
- tool is the exact registered tool ID; args is an object matching that tool's schema and defaults to {} when omitted.
- Execution order is not guaranteed. Only group independent operations, such as reading separate files or independent searches.
- Do not batch edits to the same file, dependent operations, or mutations requiring an order. Execute those sequentially.
- Recursive batch calls are rejected. Inner calls retain ordinary permission and safety checks.
- Partial failure does not stop other calls. Inspect the per-call errors and retry only failed operations after correcting their cause.
