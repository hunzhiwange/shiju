- Search the current workspace for code locations and snippets most relevant to the information request.
- Accept natural-language queries such as "Where is the entry point?", "Who calls X?", or "Where is Y defined?"; keywords are extracted and searched automatically.
- Return a relevance-ranked file list with line numbers and content snippets for each match.

Usage:
  - Works best with exact strings such as paths, identifiers, and import paths.
  - Use `target_directories` to restrict the search directories and improve speed.
  - Results are capped by `head_limit`, which defaults to 20 files.
