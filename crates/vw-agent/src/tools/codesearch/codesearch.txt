Search external API, library, and SDK documentation and code examples through Exa over the network.

- Use query for the information request; information_request is a compatibility alias. If both are supplied, query takes precedence. A nonempty query is required.
- tokensNum is an integer token budget, default 5000, clamped to 1000–50000.
- This tool does not search the local workspace. Use glob for local file names and grep for local contents.
- Network access, action policy, and rate limits may reject the request; do not treat an error as an empty search result.

Example: {"query":"Rust serde deserialize enum examples","tokensNum":5000}
