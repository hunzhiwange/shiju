Write complete content to the local file system.

Usage:
- Use it to create a new file or replace an existing file in full.
- If the target already exists, you must read it with the file_read tool first; the write will fail otherwise. If the file changed since that read, read it again and reconsider the replacement before retrying.
- Prefer the file_edit tool for partial changes to an existing file instead of replacing the entire file with file_write.
- Prefer editing existing files. Create new files when needed to complete the user's requested task; individual new files need not be explicitly named.
- Never proactively create documentation files (`*.md`) or README files. Create documentation only when the user explicitly asks for it.
- Use emoji only when the user explicitly requests them. Otherwise, avoid writing emoji to files.

Example: {"path":"src/example.txt","content":"Hello\n"}
