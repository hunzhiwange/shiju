- A fast file-pattern matching tool that works with codebases of any size.
- Supports glob patterns such as `**/*.js` and `src/**/*.ts`.
- Returns matching file paths sorted by modification time.
- Use this tool when you need to find files by name pattern.
- For open-ended local searches, start with glob to locate candidate files, then use grep to narrow by content.
- Batch only independent searches when batch is available.
- Omit path to search the workspace; do not pass null or "undefined".

Example: {"pattern":"src/**/*.rs"}
