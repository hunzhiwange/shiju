- Search file contents with regular expressions.
- Supports `output_mode=files_with_matches|content|count`.
- Use `include` or `glob` to filter files by pattern, such as `"*.js"` or `"*.{ts,tsx}"`.
- Supports `head_limit` and `offset` to control the result size.
- Supports `-i` for case-insensitive searches.
- Supports `-n` to include line numbers in `content` mode.
- Does not currently support `-A`, `-B`, `-C`, `type`, or `multiline`.
- Use this tool when you need to find files containing a specific pattern.
- Use glob for file names and grep for local file contents; narrow broad searches by path and include.
- head_limit defaults to 100 entries and is at least 1; offset defaults to 0. Entries are files in files_with_matches/count mode and matching lines in content mode. Increase offset to continue a truncated result.

Example: {"pattern":"fn main","include":"*.rs","output_mode":"content","-n":true,"head_limit":20,"offset":0}
