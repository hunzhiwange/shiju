Interact with Language Server Protocol (LSP) servers to access code intelligence features.

This tool starts the appropriate language-specific LSP server locally and performs code navigation and symbol queries over stdio.

Supported operations:
- goToDefinition
- findReferences
- hover
- documentSymbol
- workspaceSymbol
- goToImplementation
- prepareCallHierarchy
- incomingCalls
- outgoingCalls

Supported parameters:
- operation
- filePath
- line
- character
- query
- uri (for compatibility with legacy calls)

Results include a structured payload, count summaries, and location or symbol details suitable for UI rendering.
