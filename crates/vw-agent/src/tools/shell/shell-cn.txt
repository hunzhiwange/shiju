执行 Shell 命令。在指定工作目录中运行命令，支持超时控制和沙箱隔离。

参数：
- `command`（必填）：要执行的命令
- `description`（必填）：用 5-10 个词描述命令作用
- `timeout`（可选）：超时毫秒数，无默认期限
- `workdir`（可选）：工作目录，推荐使用此参数替代 `cd`
- `approved`（可选）：监督模式下显式批准命令

安全限制：
- 命令在工作目录沙箱中执行
- 只能访问允许的路径
- 环境变量经过白名单过滤
- 危险命令需要用户确认

推荐用法：
- 用 Glob/Grep 工具替代 `find`/`grep` 命令
- 用 FileEdit 工具替代 `sed`/`awk` 命令
- 用 FileRead 工具替代 `cat`/`head`/`tail` 命令
- 用 FileWrite 工具替代 `echo > file` 命令

进程会话：
- 普通命令省略 `yield_time_ms`。Bash 最多等待 30000 毫秒，命令退出即返回。只有需要提前返回时才指定较短的等待窗口，整数范围为 250–30000。
- `timeout` 是可选正整数执行期限，无默认期限。
- 命令已到终态时直接使用结果。仅当最新结果为 `state=running` 时调用 `bash_wait`，即使 `success=true` 且输出为空。沿用同一 `process_id`，将 `next_cursor` 作为 `cursor`。
- 仅在用户要求停止等确有中止理由时调用 `bash_cancel`。它会终止进程树。句柄按可信租户、工作区和会话隔离。不支持 stdin 或 PTY。
