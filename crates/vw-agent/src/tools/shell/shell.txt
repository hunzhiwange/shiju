Execute shell commands in a specified working directory, with timeout controls and sandbox isolation.

Parameters:
- `command` (required): The command to execute.
- `description` (required): Describe what the command does in 5-10 words.
- `timeout` (optional): Timeout in milliseconds; defaults to 120000.
- `workdir` (optional): Working directory; prefer this parameter over `cd`.
- `approved` (optional): Explicitly approve the command in supervised mode.

Security restrictions:
- Commands run in the working-directory sandbox.
- Only permitted paths are accessible.
- Environment variables are filtered through an allowlist.
- Dangerous commands require user confirmation.

Recommended usage:
- Use the Glob/Grep tools instead of `find`/`grep` commands.
- Use the FileEdit tool instead of `sed`/`awk` commands.
- Use the FileRead tool instead of `cat`/`head`/`tail` commands.
- Use the FileWrite tool instead of `echo > file` commands.
