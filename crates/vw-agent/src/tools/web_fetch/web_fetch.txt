- Fetch content from a specified URL.
- Accept a URL and an optional format as input.
- Retrieve the URL's content and convert it to the requested format, which defaults to markdown.
- Return the content in the specified format.
- Use this tool when you need to retrieve and analyze web content.

Usage:
- Important: Prefer another tool when it is better suited to web retrieval, more appropriate for the task, or less restrictive.
- The URL must be complete and valid.
- HTTP URLs are automatically upgraded to HTTPS.
- Format options are `"markdown"` (default), `"text"`, and `"html"`.
- The optional timeout is specified in seconds and has a maximum of 120.
- Large responses are limited to 5 MB, and output may be truncated.
- This tool is read-only and does not modify any files.
- Very large content may be summarized.
