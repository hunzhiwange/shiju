- Search the web with Exa AI, performing real-time web searches and optionally fetching content from specific URLs.
- Provide up-to-date information about current events and recent data.
- Support a configurable result count and return content from the most relevant websites.
- Use this tool to access information beyond the knowledge cutoff.
- Searches execute automatically in a single API call.

Usage:
  - Supports live-crawl modes: `'fallback'` (use live crawling when cached content is unavailable) and `'preferred'` (prefer live crawling).
  - Search types: `'auto'` (balanced), `'fast'` (quick results), and `'deep'` (comprehensive search).
  - Context length is configurable for optimal LLM integration.
  - Domain filtering and advanced search options are available.

Today is {{date}}. When searching for the latest information or current events, you must include the current year.
- Example: If today is 2025-07-15 and the user asks for "the latest AI news," search for "AI news 2025," not "AI news 2024."
