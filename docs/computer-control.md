# 电脑操控（macOS，尚未验收）

截至 2026-11-14，任意应用、Chrome、Excel、Word 已有实现路径，尚不能作为五项完整支持交付。锁屏只有状态检测、取消及有限的结构化执行路由，缺少完整原生 GUI 锁屏执行机制；结构化路由也未取得真实锁定期间执行证据。Windows/Linux 原生控制不在本次交付范围。

本轮仅编写文档并核对源码，未运行构建、测试或实机验收，未发布。具体实现来源、历史环境与待验收项见[五项验收矩阵](dev/computer-control/五项验收矩阵.md)。“服务端报告已就绪”表示运行时探测结果，不能替代实际操作与回读。

## 安装与连接

以下是后续人工部署步骤，本轮没有执行。需先取得包含 computer-control 资源的 ShiJu.app；本仓库的打包接线不代表已有经验证的安装包。将应用移到稳定位置后，按[本地资源说明](../plugins/shiju-computer-control/README.md)执行安装、状态查询与卸载命令。安装器依赖 Python 3，解释器位置须保持有效；资源写入 `~/.shiju/computer-control`，不修改系统授权。

1. 在实际运行网关/控制宿主的 Mac 上安装资源。在 ShiJu 的设置→电脑操控点击“刷新状态”，确认当前网关身份。远程网关报告的是远端主机状态，不能用本地系统权限替代。
2. 原生应用控制：在 macOS 系统设置中为实际宿主授予辅助功能与屏幕录制权限，涉及应用自动化时按系统提示决定授权。ShiJu 的应用授权与系统权限分别管理，开关不会自动取得 TCC 权限。
3. Chrome：在宿主创建的隔离 profile 中加载安装目录的 `plugin/chrome`。当前资源要求 Chrome 106+，Native Messaging 仅接受扩展 ID `ogfgcnpdhnmkpcbaclbglefaclanipmg`。仓库没有稳定扩展签名 key，任意 unpacked 安装不保证取得该 ID；不匹配时应取得维护者提供的匹配扩展，不能放宽 allowed_origins。每个文档需点击扩展临时授权，站点策略仍独立检查。
4. Office：在支持 ExcelApi 1.2、WordApi 1.3 的实际客户端中，按资源说明配置 `https://localhost:3000/office/` 静态服务及可信 localhost TLS，再旁加载对应 manifest 并打开任务窗格。安装器不启动 HTTPS 服务、不生成或信任证书。普通浏览器打开任务窗格网页不代表 Office 已连接。
5. 打开要授权的 ShiJu 聊天，在对应 Excel/Word 卡片点击“确认 Office 文档配对”，填写加载项提供的稳定文档 ID。确认会授予该文档持久权限，并生成 60 秒有效的一次性配对码；将其填入对应加载项。服务地址和凭证须由实际宿主提供，不借用其他产品的会话。

## 五项授权与撤销

| 设置项 | 含义与限制 |
| --- | --- |
| 任意应用 | 允许进入 macOS 原生观察、截图与输入路径；仍需系统授权及指定应用授权，不保证每个应用都可操作 |
| Chrome | 允许进入隔离浏览器桥接；扩展连接、当前文档临时授权和精确站点 Origin 策略仍须满足 |
| Excel | 允许已配对工作簿的结构化读取和写入；文档身份、会话及能力集须匹配 |
| Word | 允许已配对文档的结构化读取和写入；不能以文件名相同替代文档身份 |
| 锁屏使用 | 独立附加策略，不会解锁系统或扩大已有目标授权；后端不支持时开启会被拒绝。不能据开关声称支持锁屏 |

设置中的“始终允许的应用与文档”按 Bundle ID 或文档 ID 展示授权，点击“撤销授权”后等待服务端确认并刷新。“Chrome 站点管理”按 Origin 展示授权并提供撤销；重新操作须重新授权。关闭某项能力和撤销某个目标是不同操作，卸载资源也不会替代授权撤销。

Office 关闭文档、任务窗格或断线后，应重新检查连接；旧会话或 generation 不能当作新文档的授权。必要时重新打开加载项，在原聊天和项目上下文中重新生成配对码；不要复用过期凭证。关闭配对弹窗会清除本地显示，已复制的凭证仍需自行从剪贴板清除。不要把凭证写入日志或验收截图。

## 停止、锁屏与卸载

需要中止时点击设置页顶部“停止所有电脑操控”，等待服务端确认。请求失败时刷新状态并确认实际宿主连接，不能把点击按钮当作停止成功。停止与撤销不承诺撤回已提交到应用的修改；测试使用临时文档并保留基线。

锁屏期间原生 GUI 输入不受支持；锁定状态未知也不能当作解锁。当前结构化路由仅涵盖已授权 Chrome 文档的 Snapshot/Fill、已配对 Excel 操作以及 Word 读取、查找、替换、文档起止插入；不包括 Chrome 导航/点击、系统截图与键鼠、Word 当前选区插入，也不会批准新站点或新文档。该路由尚未验证，后台 API 可调用不等于真实锁屏可执行。没有自动解锁、登录窗口操作或系统密码读取。

卸载前先停止控制、撤销目标授权并关闭能力，删除隔离 Chrome 扩展与 Office 旁加载项，关闭任务窗格，再按资源说明卸载。安装器只删除记录中哈希仍匹配的自有文件，保留用户文件、profile、socket 与目录；系统权限需另在 macOS 设置中撤销。没有完成这些步骤的实机验收，不声称已彻底清理或撤销。
