# ACP 工具共存审计 · 协议接入与显式拒绝

基线为 `0df6ac2e83a8eac1b155506960659e07f6723993`。引用中的行号按此次检查的源码定位。与基线相比，共享安装文件另有其他适配器的并行改动，本报告按这六个 key 的分支取证。本轮实测仅包括报告格式和静态引用检查。下文的原生探针、回环模型和真实模型记录均为历史实测，未重跑。

宿主先解析项目服务选择与审批策略，再生成会话 MCP 声明。ACP 客户端在新建、加载和恢复前检查后端合同，随后把声明写入请求。通用 `allowedTools` 位于 Claude 扩展元数据，其中的宿主目录不能证明其他后端执行了名单。DimCode、Dirac 遇到所选服务的显式工具允许或拒绝名单时直接报错。Aionrs、Nova 则接收逐服务策略并在各自目录发现路径应用。见 [acp_defaults.rs:78–179](../../../../crates/libs/session-engine/src/acp_defaults.rs#L78)、[protocol.rs:272–488](../../../../crates/libs/acp-client/src/client/protocol.rs#L272)、[session_meta.rs:15–24](../../../../crates/libs/acp-client/src/client/session_meta.rs#L15)。

六项的受审安装和 `session_model` 能力发布均限定 macOS arm64。Linux 和 Windows 不在这六项的受审安装及发布分支内，也无匹配实测。Dirac 和 siGit 的驱动还有 Unix 实现与非 Unix 拒绝分支，siGit 挂载另行要求 macOS。原生 CLI 在其他平台的能力待对应版本验证。会话模型仍须通过宿主有效 Provider、凭据及中继路由检查。见 [managed_runtime.rs:360–371](../../../../crates/libs/acp-agent-registry/src/managed_runtime.rs#L360)、[drivers/mod.rs:58–108](../../../../crates/libs/llm-runtime/src/acp/model_source/drivers/mod.rs#L58)、[drivers/mod.rs:164–222](../../../../crates/libs/llm-runtime/src/acp/model_source/drivers/mod.rs#L164)、[request.rs:1000–1033](../../../../crates/libs/llm-runtime/src/acp/request.rs#L1000)。

历史验收曾把额外工具调用与精确答复格式纳入判据。[动态挂载计划的现行合同](../../../../.plans/2026-11-19-acp动态挂载mcp/plan.md#统一验收合同)已取消这些前置条件，与[共存合同](../../../../.plans/2026-11-19-acp工具共存审计/plan.md#共存复验口径)一致，以真实调用、结果回传和撤除为核心，保留显式拒绝及宿主权限。复验统一使用匹配摘要的原版和受管版、同一只读项目私有副本、固定模型及原权限，采集无挂载、挂载和撤除三个新会话的工具目录、同一调用 ID 的审批和结果、模型续轮及官方只读工具证据。
