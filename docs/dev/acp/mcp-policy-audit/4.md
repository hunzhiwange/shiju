## poolside

- **首个断点与现行桥。** 旧受管启动器在建会话前拒绝非空列表，原生绕过该旧门禁虽接受会话，模型仍只见 `read/write`。原生设置支持启动时加载 MCP；宿主 stdio 路径在 Docker 内不可用，历史容器只读挂载曾完成发现，调用在探针时限内无审批或结果。私有 HTTP 诊断取得原生审批、三工具执行和续轮。现行 v2 在新会话原子替换私有 `mcp_servers`，只暴露获选服务，绑定当前原生会话和参数的一次批准才放行。提示结束清除授权，取消撤权，进程退出关闭服务；已有挂载进程拒绝接另一会话。[旧门禁与原生探针](../mcp-acceptance/poolside.md#失败边界与复跑条件) · [容器与 HTTP 诊断](../mcp-acceptance/poolside.md#原生设置传输与审批) · [原生会话接线](../../../../patches/acp-model-source/poolside/launcher.py#L110-L169) · [设置、审批和执行](../../../../patches/acp-model-source/poolside/mcp_bridge.py#L113-L253)
