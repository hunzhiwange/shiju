包内 `@oai/sky/dist/project/cua/sky_js/src/targets/mac/native-pipe.js` 显示：

- 客户端要求 `globalThis.nodeRepl.nativePipe.createConnection`；缺失可信运行时会直接失败。
- 默认连接 `$HOME/Library/Group Containers/2DC432GLL2.com.openai.sky.CUAService/IPC/computeruse.sock`；连接失败后请求宿主 `ensureService`，或通过受信任的 Launch Services 接口启动应用。
- 帧为 4 字节 little-endian 长度加 JSON-RPC，有 API 版本 ping、8 MiB 上限、请求 deadline 和 turn metadata。这只是所观察版本的内部协议，并非稳定公共 SDK。
- `lsof` 实际显示 `SkyComput` 服务进程持有该 socket。客户端是连接者；服务端源码及完整身份校验未提供，不能仅凭 socket 推断可以独立认证。

服务签名和 entitlements 属于 OpenAI Team，含专属 application group、keychain group 和 Apple Events entitlement。录屏、辅助功能与 Apple Events 授权不是可复制给 ShiJu 的资源。当前 Python 探针录屏预检 true、辅助功能预检 false，仅描述探针进程的结果，不代表服务或 ShiJu 的 TCC 状态；没有读取或修改 TCC 数据库。

Chrome 用户级 `NativeMessagingHosts/com.openai.codexextension.json` 的 host 为 `com.openai.codexextension`、`stdio`，指向插件缓存内 `ChatGPT for Chrome`，有两个明确 origin。没有复制该 host、扩展 ID 或授权记录。

## 当前官方约束

以下链接均于 2026-11-11 查询。版本支持以后续实际宿主运行时检测为准。

- [Apple 屏幕捕获预检](https://developer.apple.com/documentation/coregraphics/cgpreflightscreencaptureaccess().md)：macOS 10.15 起提供权限预检。辅助功能 API 需单独检查；“已安装”不等于已获 TCC 授权。
- [Apple Authorization Plug-ins](https://developer.apple.com/documentation/security/authorization-plug-ins.md)：扩展系统授权决策，不能据此推导锁屏桌面可操作。系统策略修改边界见锁屏文档。
- [Chrome Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)：macOS host 路径须为绝对路径；manifest 放在系统或用户 NativeMessagingHosts 目录；origin 不能用通配符。Chrome 启动 host，用 stdio 交换 JSON 长度帧；只允许扩展后台上下文调用，内容脚本需经扩展转发。须单独授权站点访问，不能把 native host 安装成功当成浏览器控制成功。
- [Office 版本与 requirement sets](https://learn.microsoft.com/en-us/office/dev/add-ins/develop/office-versions-and-requirement-sets)：支持依赖 Office 产品、版本与平台。
- [ExcelApi 支持表](https://learn.microsoft.com/en-us/javascript/api/requirement-sets/excel/excel-api-requirement-sets)、[WordApi 支持表](https://learn.microsoft.com/en-us/javascript/api/requirement-sets/word/word-api-requirement-sets)：本轮不选择未经验证的最高 API 版本。后续按操作所需最小集合在 manifest 声明，并用 `Office.context.requirements.isSetSupported` 核对实际 Mac/web 宿主。
- [Office 初始化](https://learn.microsoft.com/en-us/office/dev/add-ins/develop/initialize-add-in)：等 `Office.onReady()` 后才能调用 Office API；普通浏览器加载网页不构成 Office 会话。
- [Office 权限](https://learn.microsoft.com/en-us/office/dev/add-ins/develop/requesting-permissions-for-api-use-in-content-and-task-pane-add-ins)：使用应用专属 API 须声明文档读写权限，即使只读。ShiJu 的逐会话/逐操作授权仍需另行实现，不能扩大 Office 给出的权限。

安装＝产物在磁盘；启用＝宿主允许加载；连接＝双方握手；授权＝当前操作对指定目标被允许；可执行＝操作生效并回读。每一层分别记录，不能互相替代。

独立初始化的确切可重跑命令（不设置或借用 `nodeRepl`、access identity）：

```sh
env -i HOME="$HOME" PATH=/usr/bin:/bin \
  /Applications/ChatGPT.app/Contents/Resources/cua_node/bin/node --input-type=module -e \
  "import {MacComputerUseClient} from 'file:///Applications/ChatGPT.app/Contents/Resources/cua_node/lib/node_modules/@oai/sky/dist/project/cua/sky_js/src/targets/mac/client.js'; try {const c=new MacComputerUseClient({timeoutSeconds:2}); await c.listApps(); console.log('unexpected independent success');process.exitCode=2;}catch(e){console.log(e.name+': '+e.message);process.exitCode=1}"
```
