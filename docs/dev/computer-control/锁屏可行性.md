# macOS 锁屏可行性

调查日期：2026-11-11（Asia/Shanghai），macOS 27.0 / 26A428，arm64。

结论：本轮未发现符合计划边界、可由 ShiJu 独立调用且已验证的锁屏执行后端。任务 17 不得标记完成，任务 23、24 的五项完整验收继续阻塞。此为依赖调查结论，不能把拒绝执行、开关、后台任务或 ChatGPT 初始化成功计为支持锁屏。任务 18—22 不依赖该锁屏机制，可继续。

## 三种状态

| 状态 | 判断与验收边界 |
| --- | --- |
| 应用后台 | 应用不是前台；用户会话仍可能解锁。后台 API 能工作不证明锁屏控制 |
| 显示器关闭 | 显示电源状态；可能尚未锁定，也可能随后锁定或系统睡眠。不能以黑屏照片认定锁屏 |
| 系统锁定 | 登录认证边界生效；应结合系统会话状态、锁定通知及人工观察确认。必须在整个动作窗口保持锁定，并回读目标变化 |

本轮通过 `CGSessionCopyCurrentDictionary()` 只读回读：字典存在，`CGSSessionScreenIsLocked` 键缺失；没有获得“已锁定”的正证据。该键不是此调查已确认的稳定公共契约，后续不得只依赖它。没有进行锁定后的输入、截图或文档写入实验，锁屏行为通过数为 **0**。

## 已调查的机制与阻塞

1. **现有 ChatGPT Locked use。** [官方 Computer Use 说明](https://learn.chatgpt.com/docs/computer-use)的 Locked use 部分明确描述：启用后安装 Apple 授权插件，受信任任务访问应用时临时解锁桌面，并遮盖显示器、限制本地输入；此权限专属于 ChatGPT 的活动任务。官方描述证明它不是“始终锁定而继续操控”的普通客户端接口。它与本计划禁止自动解锁的边界冲突，不能借用身份或直接复用。
2. **本机授权插件产物。** `/Library/Security/SecurityAgentPlugins/CodexComputerUseAuthorizationPlugin.bundle` 存在；`@oai/sky` 的 package.json 列出 Installer、AuthorizationPluginInstallerTool、SkyComputerUseClient 和 CUALockScreenGuardian 等发布文件。只证明安装材料存在，不证明插件已启用或 ShiJu 可调用。未执行安装器、读取密码或更改 authorization database。
3. **自有 Apple 授权插件。** [Apple 扩展授权服务说明](https://developer.apple.com/documentation/security/extending-authorization-services-with-plug-ins.md)支持以插件参与系统授权策略；不保证“锁定状态下的任意 GUI 控制”。它涉及系统策略而非普通后台权限。没有实现或安装自有插件；自动解锁方案超出计划边界，不能以“公开 API”替代所需授权与安全审查。
4. **AX、屏幕捕获与私有服务管道。** 当前可信会话 `cua.getState()` 成功，但独立 Node 调用退出 1，错误为 `Sky Computer Use requires the trusted nodeRepl runtime`。已读取 native-pipe 客户端和签名归属，详见[接入证据](接入证据.md)。未发现可独立复用的服务鉴权协议。AX/录屏授权及 socket 的存在均不构成锁屏执行证据。
5. **Chrome/Office 后台结构化操作。** 技术上应与 GUI 输入区分；即使会话保持且文档 API 可以后台写入，也必须实测锁定状态、运行时生命周期和回读。本机 Microsoft Excel/Word 缺失，没有独立 ShiJu Chrome/Office 后端，因此没有可执行的受控锁屏探针。不能把其他宿主的文件编辑或 HTTP 成功充当验收。

## 实际探针与复现

以下只读 API 在 Python 3（系统 Command Line Tools）通过 ctypes 加载系统框架调用：`CGSessionCopyCurrentDictionary` → 查锁定键；`CGPreflightScreenCaptureAccess`；`AXIsProcessTrusted`。原探针在完成三个 API 后读取 lsof 时遭遇解码异常，外层退出 1；用下方隔离命令重跑，退出 0。结果分别为 lock key absent、录屏 true、辅助功能 false；权限仅属于探针进程。

```sh
python3 - <<'PY'
import ctypes as c
cf = c.CDLL('/System/Library/Frameworks/CoreFoundation.framework/CoreFoundation')
cg = c.CDLL('/System/Library/Frameworks/CoreGraphics.framework/CoreGraphics')
ax = c.CDLL('/System/Library/Frameworks/ApplicationServices.framework/ApplicationServices')
cg.CGSessionCopyCurrentDictionary.restype = c.c_void_p
cf.CFStringCreateWithCString.argtypes = [c.c_void_p, c.c_char_p, c.c_uint32]
cf.CFStringCreateWithCString.restype = c.c_void_p
cf.CFDictionaryGetValue.argtypes = [c.c_void_p, c.c_void_p]
cf.CFDictionaryGetValue.restype = c.c_void_p
cf.CFBooleanGetValue.argtypes = [c.c_void_p]
cf.CFBooleanGetValue.restype = c.c_bool
cf.CFRelease.argtypes = [c.c_void_p]
d = cg.CGSessionCopyCurrentDictionary()
k = cf.CFStringCreateWithCString(None, b'CGSSessionScreenIsLocked', 0x08000100)
v = cf.CFDictionaryGetValue(d, k) if d else None
print('locked=' + str(cf.CFBooleanGetValue(v)) if v else 'lock key absent')
cf.CFRelease(k)
if d:
    cf.CFRelease(d)
cg.CGPreflightScreenCaptureAccess.restype = c.c_bool
ax.AXIsProcessTrusted.restype = c.c_bool
print('screen_capture=', cg.CGPreflightScreenCaptureAccess())
print('accessibility=', ax.AXIsProcessTrusted())
PY
```

未请求 TCC 新授权，未模拟可信 `nodeRepl`、未借用 ChatGPT 的 turn metadata。没有合规后端可测时，直接锁定开发机既不能验证不存在的实现，也无法在无人值守条件下保证人工恢复，因此没有执行锁屏动作；这项实机验收仍明确缺失。

后续只有在找到并实现合规后端后才开展：使用可丢弃目标和非生产文档，从独立进程记录锁定前基线、锁定正证据、锁定期间动作及回读、撤销后拒绝、停止响应和结束状态；记录系统、签名宿主、浏览器/Office 版本及脱敏目标身份。由用户正常认证恢复，不索取解锁密码，不自动解锁或修改系统认证策略。若机制本身必须临时解锁，须先解决范围冲突，不能更名绕过。
