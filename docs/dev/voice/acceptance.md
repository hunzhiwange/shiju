# 语音集成验收

显式入口不属于默认测试：

```sh
cargo test -p vw-desktop --lib voice_task_19_ -- --nocapture
cargo test -p vw-desktop --test voice-window -- --scenario deterministic
cargo test -p vw-desktop --test voice-window -- --scenario live
```

每次调用 Cargo 前，按任务 19 的共享协议动态领取 `target/rust-slot-1` 至 `target/rust-slot-20`，设置绝对 `CARGO_TARGET_DIR`（及同值的 `CARGO_BUILD_BUILD_DIR`）；等待 Cargo、窗口和子进程退出后释放自身锁，保留缓存。不要复制一个固定槽号运行。

确定性入口用临时本机存储、隔离 bootstrap、真实 loopback HTTP/WebSocket、生产 `VoiceStream` 解析器和原生 Iced 窗口。它不启动麦克风、不访问公开服务、不读取用户历史。字幕经真实线协议进入窗口，生成六张原生截图，覆盖明暗主题、中文/emoji 动态字幕、音色表单和长词典。截图输出目录通过 `VOICE_ACCEPTANCE_OUTPUT` 指定，默认打印临时证据目录。关闭未完成的窗口、场景错误或缺少显示器均为失败；编译成功不算场景成功。

单元集成测试验证统一取消后迟到的转写不会改写草稿、请求代理工作或保留外部写入目标，以及窗口关闭使用的统一取消路径关闭尚在等待 HTTP 响应的音色试听。物理输出仅在测试中替换；真实连接必须断开，释放时间有上限。它们不能证明真人音频识别质量或真实 AX 写入。

真人入口必须由操作者显式提供 `VOICE_ACCEPTANCE_GATEWAY_BOOTSTRAP`（已配置的 ShiJu 网关 bootstrap 文件）和 `VOICE_ACCEPTANCE_SESSION`（专门验收的现有聊天会话 ID）。只复制该 bootstrap 到本次临时配置目录；服务凭据留在网关。预检要求网关可达、听写和实时语音均启用、有 provider、系统麦克风权限已授予且存在物理输入设备。缺少条件返回非零，不静默跳过。系统权限由用户本人完成，不能自动接受系统弹窗。

窗口提供本次听写及语音聊天控制。操作者还需在正式签名 `.app` 中完成下面的全部系统场景并保留证据。只有确认所有场景成功后，才可点击真人验收确认；直接关闭视为未完成。不把人工确认按钮当作自动验证，也不把该隔离进程的权限当作 `.app` 权限。

| 场景 | 必须观察的行为 |
| --- | --- |
| 中文/英文听写、词典 | 原光标回填一次，不自动发送；指定/自动语言正确，词典提示生效 |
| 取消、忙碌态 | 取消后迟到回复不写入；听写/聊天/回放/试听互斥 |
| 权限拒绝、撤销 | 清晰提示，设备不占用，不绕过系统授权 |
| 拔出、重选设备 | 停止旧流，显示错误，重新选择后恢复 |
| 音色试听和保存 | 仅播放；取消不保存；保存下次通话生效 |
| 字幕、静音、打断、结束 | 字幕不重复；静音不上传；打断清空旧音频；结束释放采集、播放和网络 |
| 工作交接 | 一次交接，沿用审批，拒绝不执行，状态和结果回到原语音会话 |
| 后台热键 | 按住/松开、双击免提、Escape、冲突和失活都正确 |
| 跨应用插入 | 只写启动时固定且仍匹配的可编辑目标；安全字段、焦点变化、关闭和取消均拒绝 |
| 最近二十段 | 默认不保存；启用后只在本机保留二十段，播放/重试/删除有效 |
| 屏幕分享 | 默认关闭；每次确认目标；拒权不采集；取消和结束拒绝迟到帧 |
| 原生包与渲染 | 签名 `.app` 的权限弹窗、录音和播放有效；明暗主题、长表单和中文动态文本正常 |

仅记录场景、时刻、计数、队列峰值与释放耗时；不在日志保存音频、字幕、屏幕或服务凭据。本文的固定中性字幕只用于 fixture。

当前真实平台证据和剩余缺口以保留的编号任务文件为准；未取得真人麦克风/扬声器、公开服务和全部系统场景证据前，任务 19 保持“已完成，待回归”，任务 2–18 的实机缺口仍然有效。
