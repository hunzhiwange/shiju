# macOS 本机逐轮语音聊天（任务11）

这是用户于2026-11-12授权的逐轮交互：点击开始录音，点击停止并发送，系统只在本机识别；识别文字交给当前会话的普通聊天模型，最终正文在本机合成并播放。模型本身可以在远端运行，因此不把整条链路称为离线聊天。Cloud 实时语音保留独立入口；Local 不读取 `voice_config`，不请求语音提供商，不上传录音。

## 已冻结的接入点

- `message/voice.rs` 在 ChatStart 读取本机 `Preferences.engine`，Local 进入 `voice_local_chat.rs`，Cloud 继续已有 Conversation。
- Local 复用 `voice_dictation::{prepare,transcribe}` 的严格本机分支。麦克风和 Speech 授权仅由用户点击开始录音触发。拒绝、系统限制、语言资源缺失、设备断开与超时显示中文提示，不回退云端。
- 识别成功使用 `ChatMessage::SendToSession`，沿用当前模型、会话历史、工具和权限。输入框有草稿、模型忙碌或排队、权限保存中、会话加载中、ACP、任务/工作流模式均先提示处理。斜杠命令留给普通聊天输入框显式发送。
- `complete_agent_stream` 在最终增量刷新后，向 Local 交付本轮请求ID、会话和完整消息。只朗读该请求新增的最终 Assistant 正文；使用聊天界面同一解析器排除思考、工具、代码与表格。流式中间文本、错误、旧答复和重复完成事件不触发朗读。
- `Preferences.local_voice: Option<String>` 消费已安装系统声音ID，None 为系统默认。任务13可用 `local::voices()` 列表编辑此字段；本任务没有扩展配置表单。`local_language=None` 继续表示系统识别语言，不表示自动语言检测。

## 生命周期与声音

准备、识别和合成都在后台执行。每个通话使用独立随机身份，每轮拥有递增代次；异步回包必须同时匹配身份、代次和阶段。静音会取消尚未发送的录音/识别；静音仅控制麦克风，已发送模型回答仍可朗读。打断与结束取消本机令牌、录音和播放，并且只停止该通话拥有的普通聊天请求。网关/租户/密钥、项目或会话切换会清理旧通话；停止请求保存旧端点和原请求标识，不把它发送给切换后的网关。网络停止失败明确提示在原会话确认。

合成最多2000字；长回复朗读开头并明确提示查看完整聊天。合成音频最长120秒，以100ms PCM包提交现有 Playback，领先已播放进度约1秒，低于2秒队列上限。后台线程拥有音频设备，每10ms检查取消与设备错误；不在 Iced 线程等待合成或播放线程退出。

本机语音控件位于输入框上方，正文、输入框与审批入口保持可用；审批和问题仍需手动处理。Local 支持主动单帧窗口分享，开关默认关闭。每次点击选择后有三秒切换目标应用，再返回确认窗口；确认才采集，复用单窗口、1024像素与40KiB PNG限额。只有当前轮次就绪、显式选定且目录声明支持图片输入的普通模型才能接收；自动模型、ACP、忙碌、草稿或模型能力不明时明确拒绝，提供普通聊天附件入口。

确认后使用当前会话的普通聊天图像标记通道发起一轮描述请求，最终正文沿用本机朗读。采集端不另存截图；网关与模型按普通聊天策略处理、保存已发送图像。图像及其中的文字作为不可信上下文，不提升权限，不自动批准工具。取消、关闭分享、结束、切换会话/网关、开始录音或打断都会使未发送帧失效；采集完成时重新检查权限、通话身份和当前模型能力。权限按钮只在活动通话且当前Local模型可接收图像时处理，不用旧事件触发无通话授权。
