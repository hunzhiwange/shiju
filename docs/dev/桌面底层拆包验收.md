- 桌面全目录搜索 rusqlite、strsim、syntect、walkdir，仅清单有匹配，删除四项直接依赖。walkdir 归 desktop-lsp 的项目扫描使用；其余三项当前没有桌面源码调用。
- cpal 仍用于 voice/conversation.rs 的 Stream 类型及测试复用源码；git2 仍用于 Git UI 操作与测试；similar 仍用于差异渲染与消息逻辑。不得随底层提取一起删除。
- zip 仍用于 skill_hub/web_install，parking_lot 仍用于 skill_hub，libc 仍用于更新辅助进程和主入口。objc2、block2、open 等继续服务桌面平台能力；build.rs 仍只直接使用 serde_json 与标准库，保留 build-dependencies。
- audio-capture/audio-playback 与桌面录音接线保持非 wasm cfg；cpal 不启用默认 features。voice-recordings 保留 Unix 文件权限及 libc cfg；voice-permissions 的 ObjC/block/open 仅在 macOS。
- desktop-git 保留非 wasm git2/similar 与 wasm 原有回退；desktop-lsp 的进程、扫描、安装及临时目录测试依赖保持非 wasm cfg。Git vendored 特性与 iced-code-editor 的 lsp-process 特性不变。
- 所有显式窗口测试清单的 harness=false、test=false 保持原样。recovery、plugin-compat、acp-options、agent-profile、apps 系列、companion、voice、archived-chats、cron-picker、editor-config 等入口仍直接声明 mod app；tray/worktree 窗口入口也未改动。
