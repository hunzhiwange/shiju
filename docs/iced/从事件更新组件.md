# 从事件更新组件

本教程延续 [自定义组件](./custom_widgets.md) 教程。我们将学习如何从事件中更新组件的状态。

当我们使用 [advanced](https://docs.rs/iced/0.13.1/iced/advanced/widget/trait.Widget.html) 模块创建自定义组件时，我们有机会访问组件的状态。这允许我们根据事件更新组件的状态，而不需要将状态提升到应用程序级别。

为了在组件中存储状态，我们需要使用 [Tree](https://docs.rs/iced/0.13.1/iced/advanced/widget/tree/struct.Tree.html) 结构体。[Tree] 存储组件的整个子树的状态。

首先，我们需要在结构体中定义一个状态字段。

```rust
struct MyWidget {
    count: u32,
}
```

然后，我们需要实现 [from_logical](https://docs.rs/iced/0.13.1/iced/advanced/widget/trait.Widget.html#tymethod.from_logical) 方法来从逻辑状态创建组件。

```rust
fn from_logical(state: u32) -> Self {
    Self { count: state }
}
```

接下来，我们需要实现 [update](https://docs.rs/iced/0.13.1/iced/advanced/widget/trait.Widget.html#tymethod.update) 方法来处理事件并更新状态。

```rust
fn update(
    &mut self,
    tree: &mut Tree,
    event: Event,
    layout: Layout<'_>,
    cursor: mouse::Cursor,
    renderer: &Renderer,
    theme: &Theme,
    style: &renderer::Style,
    viewport: &Rectangle,
) -> Option<Event> {
    if let Event::Mouse(mouse::Event::ButtonPressed(mouse::Button::Left)) = event {
        if cursor.is_over(layout.bounds()) {
            self.count += 1;
            tree.publish_message(Message::Increment);
        }
    }
    None
}
```

完整代码如下：

```rust
use iced::{
    Border, Color, Element, Event, Length, Rectangle, Shadow, Size, Theme,
    advanced::{
        Layout, Widget, layout, mouse,
        renderer::{self, Quad},
        widget::Tree,
    },
    widget::container,
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    Increment,
}

#[derive(Default)]
struct MyApp {
    counter: u32,
}

impl MyApp {
    fn update(&mut self, message: Message) {
        match message {
            Message::Increment => self.counter += 1,
        }
    }

    fn view(&self) -> iced::Element<Message> {
        container(MyWidget::new())
            .width(Length::Fill)
            .height(Length::Fill)
            .center_x(Length::Fill)
            .center_y(Length::Fill)
            .into()
    }
}

struct MyWidget {
    count: u32,
}

impl MyWidget {
    fn new() -> Self {
        Self { count: 0 }
    }
}

impl<Message, Renderer> Widget<Message, Theme, Renderer> for MyWidget
where
    Renderer: iced::advanced::Renderer,
{
    fn size(&self) -> Size<Length> {
        Size {
            width: Length::Shrink,
            height: Length::Shrink,
        }
    }

    fn layout(
        &self,
        _tree: &mut Tree,
        _renderer: &Renderer,
        _limits: &layout::Limits,
    ) -> layout::Node {
        layout::Node::new(iced::Size {
            width: 100.0,
            height: 100.0,
        })
    }

    fn draw(
        &self,
        _state: &Tree,
        renderer: &mut Renderer,
        _theme: &Theme,
        _style: &renderer::Style,
        layout: Layout<'_>,
        _cursor: mouse::Cursor,
        _viewport: &Rectangle,
    ) {
        let bounds = layout.bounds();

        renderer.fill_quad(
            Quad {
                bounds,
                border: Border {
                    color: Color::from_rgb(0.4, 0.4, 1.0),
                    width: 1.0,
                    radius: 10.0.into(),
                },
                shadow: Shadow::default(),
            },
            Color::from_rgb(0.6, 0.6, 1.0),
        );
    }

    fn update(
        &mut self,
        tree: &mut Tree,
        event: Event,
        layout: Layout<'_>,
        cursor: mouse::Cursor,
        renderer: &Renderer,
        theme: &Theme,
        style: &renderer::Style,
        viewport: &Rectangle,
    ) -> Option<Event> {
        if let Event::Mouse(mouse::Event::ButtonPressed(mouse::Button::Left)) = event {
            if cursor.is_over(layout.bounds()) {
                self.count += 1;
                tree.publish_message(Message::Increment);
            }
        }
        None
    }
}

impl<'a, Message, Renderer> From<MyWidget> for Element<'a, Message, Theme, Renderer>
where
    Renderer: iced::advanced::Renderer,
{
    fn from(widget: MyWidget) -> Self {
        Self::new(widget)
    }
}
```
