# 使用缓存绘制

之前我们提到，[Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html) 有 [draw](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html#tymethod.draw) 方法，每次对应的 [Canvas](https://docs.rs/iced/0.13.1/iced/widget/canvas/struct.Canvas.html) 需要重新绘制时，该方法就会被调用。

但是，如果 [Canvas](https://docs.rs/iced/0.13.1/iced/widget/canvas/struct.Canvas.html) 的形状保持不变，重新绘制所有这些形状效率不高。

我们可以做的是，将这些形状的图像存储在 [Cache](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Cache.html) 中，并在 [Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html) 的 [draw](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html#tymethod.draw) 方法被调用时绘制这个缓存。

为此，我们在应用程序中声明一个 [Cache](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Cache.html) 类型的字段

```rust
struct MyApp {
    cache: Cache,
}
```

并初始化它。

```rust
fn new() -> (Self, Task<Message>) {
    (
        Self {
            cache: Cache::new(),
        },
        Task::none()
    )
}
```

在 [draw](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html#tymethod.draw) 方法中，我们不使用创建新的 [Frame](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Frame.html)

```rust
let mut frame = Frame::new(renderer, bounds.size());
// ...
vec![frame.into_geometry()]
```

而使用 [cache.draw](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Cache.html#method.draw) 来构造 [Geometry](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Geometry.html)。

```rust
let geometry = self.cache.draw(renderer, bounds.size(), |frame| {
    // ...
});

vec![geometry]
```

闭包 `|frame| { /* ... */ }` 只在框架尺寸发生变化或缓存被显式清除时才会被调用。

此外，之前我们为结构体 `MyProgram` 实现了 [Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html)。但因为我们需要访问 `MyApp` 的 `cache` 字段，我们必须为 `MyApp` 实现 [Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html)。

完整代码如下：

```rust
use iced::{
    Alignment, Color, Length, Point, Rectangle, Renderer, Task, Theme, Vector, mouse,
    widget::{
        Canvas,
        canvas::{Cache, Geometry, Path, Program, Stroke},
        column,
    },
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view).run_with(MyApp::new)
}

#[derive(Clone, Debug)]
enum Message {}

#[derive(Default)]
struct MyApp {
    cache: Cache,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (
            Self {
                cache: Cache::new(),
            },
            Task::none(),
        )
    }

    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            "A Canvas",
            Canvas::new(self).width(Length::Fill).height(Length::Fill)
        ]
        .align_x(Alignment::Center)
        .into()
    }
}

impl<Message> Program<Message> for MyApp {
    type State = ();

    fn draw(
        &self,
        _state: &Self::State,
        renderer: &Renderer,
        _theme: &Theme,
        bounds: Rectangle,
        _cursor: mouse::Cursor,
    ) -> Vec<Geometry> {
        let geometry = self.cache.draw(renderer, bounds.size(), |frame| {
            frame.fill_rectangle(Point::ORIGIN, bounds.size(), Color::from_rgb(0.0, 0.2, 0.4));

            frame.fill(
                &Path::circle(frame.center(), frame.width().min(frame.height()) / 4.0),
                Color::from_rgb(0.6, 0.8, 1.0),
            );

            frame.stroke(
                &Path::line(
                    frame.center() + Vector::new(-250.0, 100.0),
                    frame.center() + Vector::new(250.0, -100.0),
                ),
                Stroke {
                    style: Color::WHITE.into(),
                    width: 50.0,
                    ..Default::default()
                },
            );
        });

        vec![geometry]
    }
}
```
