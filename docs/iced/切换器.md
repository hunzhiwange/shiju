# 切换器

[Toggler](https://docs.rs/iced/0.13.1/iced/widget/toggler/struct.Toggler.html) 组件表示一个布尔值，用于开启或关闭某项功能。
它有两种构造方式：`toggler` 函数和 `Toggler::new` 构造器。
默认情况下，切换器处于关闭状态，可以设置标签和状态。

```rust
use iced::{
    widget::{column, toggler, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    Toggle1(bool),
    Toggle2(bool),
    Toggle3(bool),
    Toggle4(bool),
}

#[derive(Default)]
struct MyApp {
    toggler1: bool,
    toggler2: bool,
    toggler3: bool,
    toggler4: bool,
}

impl MyApp {
    fn update(&mut self, message: Message) {
        match message {
            Message::Toggle1(b) => self.toggler1 = b,
            Message::Toggle2(b) => self.toggler2 = b,
            Message::Toggle3(b) => self.toggler3 = b,
            Message::Toggle4(b) => self.toggler4 = b,
        }
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            toggler("Toggler 1", self.toggler1).on_toggle(Message::Toggle1),
            toggler("Toggler 2", self.toggler2).on_toggle(Message::Toggle2),
            toggler("Toggler 3", self.toggler3).on_toggle(Message::Toggle3),
            toggler("Toggler 4", self.toggler4).on_toggle(Message::Toggle4),
        ]
        .into()
    }
}
```
