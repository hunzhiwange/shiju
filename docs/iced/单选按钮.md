# 单选按钮

[Radio](https://docs.rs/iced/0.13.1/iced/widget/radio/struct.Radio.html) 组件用于从多个选项中选择一个。
它有两种构造方式：`radio` 函数和 `Radio::new` 构造器。
默认情况下，单选按钮未选中，可以设置状态和标签。

```rust
use iced::{
    widget::{column, radio, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    Select(Option),
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum Option {
    A,
    B,
    C,
}

#[derive(Default)]
struct MyApp {
    selected: Option,
}

impl MyApp {
    fn update(&mut self, message: Message) {
        match message {
            Message::Select(option) => self.selected = option,
        }
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            radio("Option A", Option::A, self.selected, Message::Select),
            radio("Option B", Option::B, self.selected, Message::Select),
            radio("Option C", Option::C, self.selected, Message::Select),
        ]
        .into()
    }
}
```
