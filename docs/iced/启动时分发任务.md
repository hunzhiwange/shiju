# 启动时分发任务

有时你可能希望在应用程序启动时分发一个任务。这在你需要获取一些数据显示在屏幕上，或执行一些初始化逻辑时很有用。

为了实现这一点，你不能简单地使用 [`iced::run`](https://docs.rs/iced/0.13.1/iced/fn.run.html) 来运行应用程序，因为这个函数不允许你自定义应用程序的初始化逻辑。相反，你应该使用 [`iced::application`](https://docs.rs/iced/0.13.1/iced/application/index.html)。这个函数的调用方式与 `iced::run` 相同。但它不会立即运行应用程序，而是返回一个 [`Application`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html) 实例。

有了 `Application` 的实例，你可以自定义样式，并使用 [`run_with`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.run_with) 函数来分发任务。

[`run_with`]((https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.run_with)) 函数期望一个返回包含初始状态和任务的元组的函数。

为了与前面的示例保持一致，在下面的示例中，我们分发一个将焦点设置到输入字段的任务。当然，任务允许我们执行更多复杂的操作。

```rust
use iced::{
    Task, Theme,
    widget::{column, text_input},
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view)
        .theme(|_| Theme::TokyoNight)
        .run_with(MyApp::new)
}

const MY_TEXT_ID: &str = "my_text";

#[derive(Debug, Clone)]
enum Message {
    UpdateText(String),
}

#[derive(Default)]
struct MyApp {
    some_text: String,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        let app = Self::default();
        (app, text_input::focus(text_input::Id::new(MY_TEXT_ID)))
        // 尝试返回 (app, Task::none()) 并看看会发生什么
        // (app, Task::none())
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::UpdateText(s) => self.some_text = s,
        }
        Task::none()
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            text_input("", &self.some_text)
                .id(text_input::Id::new(MY_TEXT_ID))
                .on_input(Message::UpdateText),
        ]
        .into()
    }
}
```
