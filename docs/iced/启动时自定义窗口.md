# 启动时自定义窗口

通过使用 [`Application`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html) 的 [`window`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.window) 函数，我们可以传递一个 [window::Settings](https://docs.rs/iced/0.13.1/iced/window/settings/struct.Settings.html) 结构体来更改窗口的属性（如 [position](https://docs.rs/iced/0.13.1/iced/window/settings/struct.Settings.html#structfield.position) 和 [size](https://docs.rs/iced/0.13.1/iced/window/settings/struct.Settings.html#structfield.size)）。

[`Application`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html) 中其他有用的函数包括 [`window_size`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.window_size)，它是 [`window`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.window) 的语法糖，只更改窗口大小；[`centered`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.centered)，将窗口居中到屏幕；以及 [`position`](https://docs.rs/iced/0.13.1/iced/application/struct.Application.html#method.position)，允许我们指定窗口的位置。

```rust
use iced::{Point, Size, window};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view)
        .window(window::Settings {
            size: Size {
                width: 70.,
                height: 30.,
            },
            position: window::Position::Specific(Point { x: 50., y: 60. }),
            ..window::Settings::default()
        })
        .run()
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        "Hello".into()
    }
}
```
