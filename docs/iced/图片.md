# 图片

[Image](https://docs.rs/iced/0.13.1/iced/widget/image/struct.Image.html) 组件用于显示图片。
要使用该组件，需要启用 [image](https://docs.rs/crate/iced/0.13.1/features#image) 特性。

```toml
[dependencies]
iced = { version = "0.13.1", features = ["image"] }
```

该组件支持两种图片来源：[Handle](https://docs.rs/iced/0.13.1/iced/widget/image/struct.Handle.html) 和 [ImageData](https://docs.rs/iced/0.13.1/iced/widget/image/struct.ImageData.html)。

### Handle

[Handle](https://docs.rs/iced/0.13.1/iced/widget/image/struct.Handle.html) 用于从路径、URL 或内存中的 bytes 加载图片。

```rust
use iced::{
    widget::image,
    widget::image::Handle,
};

fn main() -> iced::Result {
    let img1 = Image::<()>::from(Handle::from_path("images/foo.png"));
    let img2 = Image::<()>::from(Handle::from_url(
        "https://example.com/foo.png",
    ));
    let bytes = include_bytes!("../foo.png");
    let img3 = Image::<()>::from(Handle::from_memory(bytes));
}
```

### ImageData

[ImageData](https://docs.rs/iced/0.13.1/iced/widget/image/struct.ImageData.html) 用于从 RGBA 原始数据创建图片。

```rust
use iced::{Height, Width, widget::image::ImageData};

fn main() -> iced::Result {
    let img_data = ImageData::from_pixels(
        &[0xFF, 0x00, 0x00, 0xFF, 0x00, 0xFF, 0x00, 0xFF, 0x00, 0x00, 0xFF, 0xFF],
        3,
        1,
    );
    let img = Image::<()>::from(img_data);
}
```
