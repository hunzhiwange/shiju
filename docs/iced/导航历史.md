# 导航历史

本教程延续 [多页面应用程序](./multipage_apps.md) 教程。我们将添加一个导航历史功能，让用户可以在页面之间前进和后退。

为此，我们需要使用一个 `Vec<Page>` 类型的栈来存储导航历史。

```rust
use iced::{
    Element, Task,
    widget::{button, column, text, Space},
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view).run_with(MyApp::new)
}

#[derive(Debug, Clone, Copy)]
enum Message {
    GoTo(Page),
    GoBack,
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum Page {
    Home,
    About,
    Settings,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (Self { history: vec![Page::Home] }, Task::none())
    }
}

#[derive(Default)]
struct MyApp {
    history: Vec<Page>,
}

impl MyApp {
    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::GoTo(page) => {
                self.history.push(page);
            }
            Message::GoBack => {
                self.history.pop();
            }
        }
        Task::none()
    }

    fn view(&self) -> Element<Message> {
        let current_page = self.history.last().unwrap_or(&Page::Home);

        column![
            match current_page {
                Page::Home => column![
                    text("Home"),
                    button("Go to About").on_press(Message::GoTo(Page::About)),
                    button("Go to Settings").on_press(Message::GoTo(Page::Settings)),
                ],
                Page::About => column![
                    text("About"),
                    text("This is a multi-page app with navigation history."),
                    Space::with_height(20),
                    button("Go Back").on_press(Message::GoBack),
                ],
                Page::Settings => column![
                    text("Settings"),
                    text("Configure your preferences here."),
                    Space::with_height(20),
                    button("Go Back").on_press(Message::GoBack),
                ],
            }
        ]
        .into()
    }
}
```
