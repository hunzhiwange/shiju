# 工具提示

[Tooltip](https://docs.rs/iced/0.13.1/iced/widget/tooltip/struct.Tooltip.html) 组件用于显示关于某个组件的附加信息。
它有两种构造方式：`tooltip` 函数和 `Tooltip::new` 构造器。
默认情况下，工具提示在鼠标悬停时显示，可以设置延迟和位置。

```rust
use iced::{
    widget::{button, column, tooltip, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            tooltip(
                button("Hover me!"),
                "This is a tooltip!",
                tooltip::Position::Top,
            ),
        ]
        .into()
    }
}
```
