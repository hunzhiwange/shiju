# 异步加载图片

本教程延续 [图片](./image.md) 教程。我们将学习如何异步加载图片并显示加载状态。

为此，我们需要启用 [image](https://docs.rs/crate/iced/0.13.1/features#image) 特性，并实现一个状态机来处理图片加载的不同阶段。

```rust
use iced::{
    widget::{button, column, image, text},
    Download, Element, Task,
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view).run_with(MyApp::new)
}

const IMAGE_URL: &str = "https://www.rust-lang.org/static/images/rust-logo-blk.svg";

#[derive(Debug, Clone)]
enum Message {
    LoadImage,
    ImageLoaded(Vec<u8>),
    ImageFailed,
}

#[derive(Default)]
struct MyApp {
    handle: Option<image::Handle>,
    loading: bool,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (Self::default(), Task::none())
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::LoadImage => {
                self.loading = true;
                return Task::download(IMAGE_URL.to_string()).map(Message::ImageLoaded);
            }
            Message::ImageLoaded(data) => {
                self.handle = Some(image::Handle::from_memory(data));
                self.loading = false;
            }
            Message::ImageFailed => {
                self.loading = false;
            }
        }
        Task::none()
    }

    fn view(&self) -> Element<Message> {
        column![
            button("Load image").on_press(Message::LoadImage),
            if self.loading {
                text("Loading...")
            } else if let Some(handle) = &self.handle {
                image(handle.clone())
            } else {
                text("Press the button to load an image")
            }
        ]
        .into()
    }
}
```
