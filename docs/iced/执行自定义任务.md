# 执行自定义任务

有时你可能需要执行系统命令、读取文件，或者做其他可能失败的事情。这些情况下，任务会返回 `Result` 类型。

```rust
use iced::{
    Task,
    widget::{button, column, text},
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view).run_with(MyApp::new)
}

#[derive(Debug, Clone)]
enum Message {
    LoadData,
    DataLoaded { data: String },
    Error { message: String },
}

#[derive(Default)]
struct MyApp {
    data: String,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (Self::default(), Task::none())
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::LoadData => {
                let task = Task::perform(async { "Some data" }, |data| Message::DataLoaded { data });
                return task;
            }
            Message::DataLoaded { data } => self.data = data,
            Message::Error { message } => {
                println!("Error: {}", message);
            }
        }
        Task::none()
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            button("Load data").on_press(Message::LoadData),
            text(&self.data),
        ]
        .into()
    }
}
```
