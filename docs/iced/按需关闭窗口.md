# 按需关闭窗口

本教程延续 [上一教程](./changing_the_window_dynamically.md)。
我们使用 [window](https://docs.rs/iced/0.13.1/iced/window/index.html) 模块中的 [close](https://docs.rs/iced/0.13.1/iced/window/fn.close.html) 函数来关闭窗口。
这也是通过返回 [close](https://docs.rs/iced/0.13.1/iced/window/fn.close.html) 函数获得的 [Task](https://docs.rs/iced/0.13.1/iced/struct.Task.html) 来完成的。

与 [resize](https://docs.rs/iced/0.13.1/iced/window/fn.resize.html) 函数类似，[close](https://docs.rs/iced/0.13.1/iced/window/fn.close.html) 函数需要我们将要关闭的窗口的 ID。为此，window 模块有一个 [`get_latest`](https://docs.rs/iced/0.13.1/iced/window/fn.get_latest.html) 函数。该函数也返回一个任务，需要解析为最新窗口的 ID。在我们的例子中，由于我们只有一个窗口，它将始终返回主窗口的 ID。一旦调用 `close` 函数，窗口将关闭，并且由于它是唯一的窗口，应用程序将退出。

```rust
use iced::{
    Task,
    widget::{button, row},
    window,
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    CloseWindow,
}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn close(id: window::Id) -> Task<Message> {
        window::close(id)
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::CloseWindow => window::get_latest().and_then(Self::close),
        }
    }

    fn view(&self) -> iced::Element<Message> {
        row![button("Close window").on_press(Message::CloseWindow),].into()
    }
}
```
