# 文本

[Text](https://docs.rs/iced/0.13.1/iced/widget/text/struct.Text.html) 是 Iced 的基本组件之一，用于显示文本。
它可以以不同方式构造：

```rust
use iced::{
    widget::text,
};

fn main() -> iced::Result {
    let text1 = text("Construct from a string literal");
    let text2 = text("Construct from a String").size(20);
    let text3 = text("Construct with a custom font").font(Font::DEFAULT);
    let text4 = text("Construct with a custom color").style(|_| text::Style {
        color: Some(Color::from_rgb(0.5, 0.5, 0.5)),
    });
}
```
