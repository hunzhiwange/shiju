# 文本输入

[TextInput](https://docs.rs/iced/0.13.1/iced/widget/text_input/struct.TextInput.html) 组件用于让用户输入文本。
它有两种构造方式：`text_input` 函数和 `TextInput::new` 构造器。
默认情况下，文本输入是单行的，可以设置占位符和值。

```rust
use iced::{
    widget::{column, text, text_input},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    UpdateInput(String),
}

#[derive(Default)]
struct MyApp {
    input_value: String,
}

impl MyApp {
    fn update(&mut self, message: Message) {
        match message {
            Message::UpdateInput(s) => self.input_value = s,
        }
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            text(&self.input_value),
            text_input("Type something...", &self.input_value)
                .on_input(Message::UpdateInput),
        ]
        .into()
    }
}
```
