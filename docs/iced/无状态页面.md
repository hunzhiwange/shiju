# 无状态页面

本教程延续 [多页面应用程序](./multipage_apps.md) 教程。

有些页面不需要维护状态。例如，一个只显示一些信息的关于页面。这类页面不需要用户交互，它们只是向用户显示信息。

为了创建无状态页面，我们可以使用 `()` 作为应用程序状态，而不是定义一个自定义结构体。

```rust
use iced::{
    Element, Task,
    widget::{button, column, text, Space},
};

fn main() -> iced::Result {
    iced::application("My App", update, view).run_with(new)
}

#[derive(Debug, Clone, Copy)]
enum Message {
    GoBack,
}

fn new() -> ((), Task<Message>) {
    ((), Task::none())
}

fn update(_state: &mut (), message: Message) -> Task<Message> {
    match message {
        Message::GoBack => Task::none(),
    }
}

fn view(_state: &()) -> Element<Message> {
    column![
        text("About this app"),
        text("This is a simple demo app."),
        Space::with_height(20),
        button("Go Back").on_press(Message::GoBack),
    ]
    .into()
}
```
