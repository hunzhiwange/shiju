# 更改样式

在 iced 0.13.x 中，更改样式发生了重大变化。与之前的版本一样，大多数组件支持使用 `style` 方法来更改样式。

但是，[`style`](https://docs.rs/iced/0.13.1/iced/widget/struct.Button.html#method.style) 方法现在接受一个闭包，该闭包接收主题和组件状态作为参数（如果适用）。这允许更动态和灵活的样式设置。你可以直接在闭包中使用组件的 [Style](https://docs.rs/iced/0.13.1/iced/widget/button/struct.Style.html) 结构体来定义颜色、背景等样式属性。

此外，组件还暴露了预定义函数，如 [`danger`](https://docs.rs/iced/0.13.1/iced/widget/button/fn.danger.html)、[`primary`](https://docs.rs/iced/0.13.1/iced/widget/button/fn.primary.html) 等。每个组件有不同的预定义样式。

例如，[Text](https://docs.rs/iced/0.13.1/iced/widget/type.Text.html) 组件在其 [`style`](https://docs.rs/iced/0.13.1/iced/advanced/widget/struct.Text.html#tymethod.style) 方法中接受 [`text::Style`](https://docs.rs/iced/0.13.1/iced/widget/text/struct.Style.html) 结构体。但你也可以使用预定义样式如 [`danger`](https://docs.rs/iced/0.13.1/iced/widget/text/fn.danger.html) 或 [`primary`](https://docs.rs/iced/0.13.1/iced/widget/text/fn.primary.html)。
类似地，[Button](https://docs.rs/iced/0.13.1/iced/widget/struct.Button.html) 组件在其 [`style`](https://docs.rs/iced/0.13.1/iced/widget/button/struct.Button.html#method.style) 方法中接受 [`button::Style`](https://docs.rs/iced/0.13.1/iced/widget/button/struct.Style.html) 结构体。但你也可以使用预定义样式如 [`danger`](https://docs.rs/iced/0.13.1/iced/widget/button/fn.danger.html) 或 [`primary`](https://docs.rs/iced/0.13.1/iced/widget/button/fn.primary.html)。请注意，按钮组件的 `style` 方法有一个 `status` 参数，可以根据按钮状态更改样式。

```rust
use iced::{
    Background, Color, theme,
    widget::{button, column, row, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            text("A solid color").style(|_| text::Style {
                color: Some(Color::from_rgb(0.5, 0.5, 0.0))
            }),
            text("A color from the theme").style(text::danger),
            row![
                button("Cancel").style(button::danger),
                button("Go!~~").style(button::primary),
                button("Save").style(|_, _| button::Style {
                    background: Some(Background::Color(Color::from_rgb(0.0, 0.5, 0.5))),
                    ..Default::default()
                })
            ],
        ]
        .into()
    }
}
```
