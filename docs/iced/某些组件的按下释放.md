# 某些组件的按下/释放

某些组件，如 [Button](https://docs.rs/iced/0.13.1/iced/widget/button/struct.Button.html) 和 [MouseArea](https://docs.rs/iced/0.13.1/iced/widget/mouse_area/struct.MouseArea.html)，支持 `on_press` 和 `on_release` 事件。

例如，我们可以创建一个在按下和释放时改变状态的按钮：

```rust
use iced::{
    widget::{button, column, text},
    Color,
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    Pressed,
    Released,
}

#[derive(Default)]
struct MyApp {
    is_pressed: bool,
}

impl MyApp {
    fn update(&mut self, message: Message) {
        match message {
            Message::Pressed => self.is_pressed = true,
            Message::Released => self.is_pressed = false,
        }
    }

    fn view(&self) -> iced::Element<Message> {
        let text_color = if self.is_pressed {
            Color::from_rgb(1.0, 0.0, 0.0)
        } else {
            Color::from_rgb(0.0, 0.0, 1.0)
        };

        column![
            text("Press and hold the button!").style(text_color),
            button("Hold me!")
                .on_press(Message::Pressed)
                .on_release(Message::Released),
        ]
        .into()
    }
}
```
