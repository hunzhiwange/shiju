# 水平线和垂直线

[Rule](https://docs.rs/iced/0.13.1/iced/widget/rule/struct.Rule.html) 是一个简单的组件，用于显示水平线或垂直线。
它有两种构造方式：`rule` 函数和 `Rule::new` 构造器。
默认情况下，线条是水平的，可以设置宽度和高度。

```rust
use iced::{
    widget::{column, rule, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            text("Above the rule"),
            rule::Horizontal,
            text("Below the rule"),
            rule::Horizontal,
            rule::Horizontal.height(10),
            rule::Horizontal.style(|_| rule::Style {
                color: iced::Color::from_rgb(0.5, 0.5, 0.5),
            }),
        ]
        .into()
    }
}
```
