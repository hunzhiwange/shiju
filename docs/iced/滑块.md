# 滑块

[Slider](https://docs.rs/iced/0.13.1/iced/widget/slider/struct.Slider.html) 组件用于选择范围内的值。
它有两种构造方式：`slider` 函数和 `Slider::new` 构造器。
默认情况下，滑块是水平的，可以设置范围和初始值。

```rust
use iced::{
    widget::{column, slider, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {
    SetValue(f32),
}

#[derive(Default)]
struct MyApp {
    value: f32,
}

impl MyApp {
    fn update(&mut self, message: Message) {
        match message {
            Message::SetValue(v) => self.value = v,
        }
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            text(format!("Value: {:.2}", self.value)),
            slider(0.0..=100.0, self.value).on_change(Message::SetValue),
        ]
        .into()
    }
}
```
