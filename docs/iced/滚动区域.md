# 滚动区域

[Scrollable](https://docs.rs/iced/0.13.1/iced/widget/scrollable/struct.Scrollable.html) 组件允许用户滚动其内容。
它有两种构造方式：`scrollable` 函数和 `Scrollable::new` 构造器。
默认情况下，滚动区域是水平和垂直滚动的，可以设置滚动方向和样式。

```rust
use iced::{
    widget::{column, scrollable, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        scrollable(
            column![
                "Item 1",
                "Item 2",
                "Item 3",
                "Item 4",
                "Item 5",
                "Item 6",
                "Item 7",
                "Item 8",
                "Item 9",
                "Item 10",
            ]
            .spacing(20),
        )
        .into()
    }
}
```
