# 空白间距

[Space](https://docs.rs/iced/0.13.1/iced/widget/space/struct.Space.html) 是一个简单的组件，用于在布局中添加空白间距。
它有两种构造方式：`space` 函数和 `Space::new` 构造器。
默认情况下，空白间距是固定的，可以设置宽度和高度。

```rust
use iced::{
    widget::{column, row, space, text},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            text("Above"),
            space::with_height(20),
            text("Below"),
            space::with_width(20),
            row![
                text("Left"),
                space::with_width(20),
                text("Right"),
            ],
        ]
        .into()
    }
}
```
