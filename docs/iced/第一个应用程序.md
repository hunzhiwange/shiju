# 第一个应用程序

让我们从最简单的 Iced 应用程序开始！

这个应用程序只显示文本 "Hello, World!"：

```rust
use iced::widget::text;

fn main() -> iced::Result {
    iced::run("My App", |_| {}, |_| text("Hello, World!"))
}
```

这个应用程序接收三个参数：
- 第一个参数是应用程序标题
- 第二个参数是 `update` 函数，我们在这里处理消息
- 第三个参数是 `view` 函数，我们在这里渲染 UI

由于我们还没有定义任何消息，我们可以将 `update` 函数设置为忽略任何消息。

`view` 函数返回一个 [Element](https://docs.rs/iced/0.13.1/iced/type.Element.html)，它是 Iced 的基本 UI 组件类型。

在这个例子中，我们返回了一个包含静态文本的 [Text](https://docs.rs/iced/0.13.1/iced/widget/text/struct.Text.html) 组件。

### 添加计数器

让我们添加一个计数器来演示更复杂的应用程序：

```rust
use iced::{
    widget::{button, column, text},
    Settings,
};

fn main() -> iced::Result {
    Settings::default()
        .window_size((300, 300))
        .run(|state, message| {
            println!("Received message: {message:?}");
        })
}
```

在这个例子中，我们演示了如何配置应用程序设置。

![第一个应用程序](./pic/first_app2.png)

### 应用程序配置

我们可以使用 `Settings` 来配置应用程序的各种选项：

```rust
use iced::Settings;

fn main() -> iced::Result {
    Settings::default()
        .window_size((300, 300))
        .run(|_, _| {})
}
```
