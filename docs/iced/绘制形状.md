# 绘制形状

[Canvas](https://docs.rs/iced/0.13.1/iced/widget/canvas/struct.Canvas.html) 是一个帮助我们绘制自由风格形状的组件。
要使用该组件，需要启用 [canvas](https://docs.rs/crate/iced/0.13.1/features#canvas) 特性。

```toml
[dependencies]
iced = { version = "0.13.1", features = ["canvas"] }
```

我们使用 [Canvas::new](https://docs.rs/iced/0.13.1/iced/widget/canvas/struct.Canvas.html#method.new) 来获取画布组件。这个函数接受一个 [Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html) trait。程序和应用程序的区别在于，程序对绘制、更新和事件分发有更多的控制，代价是更高的复杂性。

我们可以创建一个结构体（比如 `MyProgram`）来实现这个 trait。

```rust
impl<Message> Program<Message> for MyProgram {
    type State = ();

    fn draw(
        &self,
        _state: &Self::State,
        renderer: &Renderer,
        _theme: &Theme,
        bounds: Rectangle,
        _cursor: mouse::Cursor,
    ) -> Vec<Geometry> {
        // ...
    }
}
```

当我们实现 [Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html) trait 时，需要提供一个泛型数据类型 `Message`。这有助于我们适应应用程序使用的 `Message`。

关联类型 [State](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html#associatedtype.State) 在我们的示例中没有使用，所以设置为 `()`。

[Program](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html) 最重要的部分是 [draw](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html#tymethod.draw) 方法。
在这个方法中，我们定义要绘制的形状。

要实际绘制形状，我们需要使用指针。把它想象成一支笔。[Frame](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Frame.html) 是我们要使用的枚举。

例如，我们使用 [Frame](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Frame.html) 的 [fill_rectangle](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Frame.html#method.fill_rectangle) 方法来绘制一个填充矩形。
或者我们可以描边和填充任何 [Path](https://docs.rs/iced/0.13.1/iced/widget/canvas/struct.Path.html)。
最后，我们使用 [Frame](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Frame.html) 的 [into_geometry](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Frame.html#method.into_geometry) 方法将 [Geometry](https://docs.rs/iced/0.13.1/iced/widget/canvas/type.Geometry.html) 作为 [draw](https://docs.rs/iced/0.13.1/iced/widget/canvas/trait.Program.html#tymethod.draw) 方法的要求返回。

```rust
use iced::{
    Alignment, Color, Length, Point, Rectangle, Renderer, Theme, Vector, mouse,
    widget::{
        Canvas,
        canvas::{Frame, Geometry, Path, Program, Stroke},
        column,
    },
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Clone, Debug)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            "A Canvas",
            Canvas::new(MyProgram)
                .width(Length::Fill)
                .height(Length::Fill)
        ]
        .align_x(Alignment::Center)
        .into()
    }
}

struct MyProgram;

impl<Message> Program<Message> for MyProgram {
    type State = ();

    fn draw(
        &self,
        _state: &Self::State,
        renderer: &Renderer,
        _theme: &Theme,
        bounds: Rectangle,
        _cursor: mouse::Cursor,
    ) -> Vec<Geometry> {
        let mut frame = Frame::new(renderer, bounds.size());

        frame.fill_rectangle(Point::ORIGIN, bounds.size(), Color::from_rgb(0.0, 0.2, 0.4));

        frame.fill(
            &Path::circle(frame.center(), frame.width().min(frame.height()) / 4.0),
            Color::from_rgb(0.6, 0.8, 1.0),
        );

        frame.stroke(
            &Path::line(
                frame.center() + Vector::new(-250.0, 100.0),
                frame.center() + Vector::new(250.0, -100.0),
            ),
            Stroke {
                style: Color::WHITE.into(),
                width: 50.0,
                ..Default::default()
            },
        );

        vec![frame.into_geometry()]
    }
}
```
