# 行

[Row](https://docs.rs/iced/0.13.1/iced/widget/struct.Row.html) 帮助我们水平放置组件。
它可以在其边界和内部内容之间留出一些空间。
它也可以在其内部组件之间添加间距。
内部组件可以顶部对齐、居中对齐或底部对齐。

```rust
use iced::{
    Alignment, Length,
    widget::{Row, row},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        row![
            Row::with_children(vec!["Construct from the with_children function".into(), "another element".into()]),
            Row::new()
                .push("Construct from the new function and the push method")
                .push("another element again"),
            row(vec!["Construct from function".into()]),
            row!["Construct from macro"],
            row!["With padding"].padding(20),
            row!["Different alignment"]
                .height(Length::Fill)
                .align_y(Alignment::Center),
            row!["Space between elements", "Space between elements",].spacing(20),
        ]
        .into()
    }
}
```
