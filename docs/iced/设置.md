# 设置

在深入了解 Iced 之前，我们需要设置好开发环境。

首先，确保你已经安装了 Rust 和 Cargo。关于如何安装 Rust，请参考 [Rust 安装指南](https://www.rust-lang.org/tools/install)。

创建一个新项目：

```bash
cargo new my_iced_app
cd my_iced_app
```

在 `Cargo.toml` 中添加 Iced 作为依赖：

```toml
[dependencies]
iced = "0.13.1"
```

现在你可以开始编写你的第一个 Iced 应用程序了！
