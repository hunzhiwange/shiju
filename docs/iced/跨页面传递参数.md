# 跨页面传递参数

本教程延续 [多页面应用程序](./multipage_apps.md) 教程。我们将学习如何在页面之间传递参数。

为此，我们可以将参数存储在应用程序状态中，并在导航时更新它。

```rust
use iced::{
    Element, Task,
    widget::{button, column, text, Space},
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view).run_with(MyApp::new)
}

#[derive(Debug, Clone, Copy)]
enum Message {
    GoTo(Page, String),
    GoBack,
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum Page {
    Home,
    Profile,
}

#[derive(Default)]
struct MyApp {
    current_page: Page,
    user_name: String,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (
            Self {
                current_page: Page::Home,
                user_name: "Guest".to_string(),
            },
            Task::none(),
        )
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::GoTo(page, name) => {
                self.current_page = page;
                self.user_name = name;
            }
            Message::GoBack => {
                self.current_page = Page::Home;
            }
        }
        Task::none()
    }

    fn view(&self) -> Element<Message> {
        column![
            match self.current_page {
                Page::Home => column![
                    text("Home"),
                    text(format!("Welcome, {}!", self.user_name)),
                    button("View Profile (Alice)")
                        .on_press(Message::GoTo(Page::Profile, "Alice".to_string())),
                    button("View Profile (Bob)")
                        .on_press(Message::GoTo(Page::Profile, "Bob".to_string())),
                ],
                Page::Profile => column![
                    text("Profile"),
                    text(format!("User: {}", self.user_name)),
                    Space::with_height(20),
                    button("Go Back").on_press(Message::GoBack),
                ],
            }
        ]
        .into()
    }
}
```
