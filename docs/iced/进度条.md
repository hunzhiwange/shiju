# 进度条

[ProgressBar](https://docs.rs/iced/0.13.1/iced/widget/progress_bar/struct.ProgressBar.html) 组件用于显示进度。
它有两种构造方式：`progress_bar` 函数和 `ProgressBar::new` 构造器。
默认情况下，进度条是水平方向的，可以设置宽度和高度。

```rust
use iced::{
    widget::{column, progress_bar},
};

fn main() -> iced::Result {
    iced::run("My App", MyApp::update, MyApp::view)
}

#[derive(Debug, Clone)]
enum Message {}

#[derive(Default)]
struct MyApp;

impl MyApp {
    fn update(&mut self, _message: Message) {}

    fn view(&self) -> iced::Element<Message> {
        column![
            progress_bar(0.0..=100.0, 50.0),
            progress_bar(0.0..=100.0, 25.0).height(30.0),
            progress_bar(0.0..=100.0, 75.0).height(50.0).style(|_| progress_bar::Style {
                bar: iced::Color::from_rgb(0.2, 0.6, 0.8).into(),
                background: iced::Color::from_rgb(0.2, 0.2, 0.4).into(),
            }),
        ]
        .into()
    }
}
```
