# 通过定时器生成消息

本教程延续 [订阅](./subscriptions.md) 教程。我们将学习如何设置定时器来定期生成消息。

Iced 提供了一个 [time](https://docs.rs/iced/0.13.1/iced/time/index.html) 模块来处理定时器事件。该模块提供了 `every` 和 `periodic` 方法来设置定时器。

```rust
use iced::{
    time, Duration, Subscription, Task,
    widget::{button, column, text},
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view)
        .subscription(MyApp::subscription)
        .run_with(MyApp::new)
}

#[derive(Debug, Clone)]
enum Message {
    Update,
    ToggleTimer,
}

#[derive(Default)]
struct MyApp {
    counter: u32,
    timer_enabled: bool,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (Self::default(), Task::none())
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::Update => self.counter += 1,
            Message::ToggleTimer => self.timer_enabled = !self.timer_enabled,
        }
        Task::none()
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            text(self.counter),
            button("Toggle Timer")
                .on_press(Message::ToggleTimer),
        ]
        .into()
    }

    fn subscription(&self) -> Subscription<Message> {
        if self.timer_enabled {
            time::every(Duration::from_secs(1)).map(|_| Message::Update)
        } else {
            Subscription::none()
        }
    }
}
```
