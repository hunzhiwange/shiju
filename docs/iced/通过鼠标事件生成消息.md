# 通过鼠标事件生成消息

本教程延续 [事件](./events.md) 教程。我们将学习如何监听鼠标事件。

Iced 提供了一个 [mouse](https://docs.rs/iced/0.13.1/iced/mouse/index.html) 模块来处理鼠标事件。该模块提供了 `on_mouse` 和 `on_mouse_with` 方法来监听鼠标事件。

```rust
use iced::{
    event, Event, Subscription, Task,
    mouse,
    widget::{column, text},
};

fn main() -> iced::Result {
    iced::application("My App", MyApp::update, MyApp::view)
        .subscription(MyApp::subscription)
        .run_with(MyApp::new)
}

#[derive(Debug, Clone)]
enum Message {
    MouseMoved { x: f32, y: f32 },
}

#[derive(Default)]
struct MyApp {
    mouse_x: f32,
    mouse_y: f32,
}

impl MyApp {
    fn new() -> (Self, Task<Message>) {
        (Self::default(), Task::none())
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::MouseMoved { x, y } => {
                self.mouse_x = x;
                self.mouse_y = y;
            }
        }
        Task::none()
    }

    fn view(&self) -> iced::Element<Message> {
        column![
            text(format!("Mouse position: ({}, {})", self.mouse_x, self.mouse_y)),
        ]
        .into()
    }

    fn subscription(&self) -> Subscription<Message> {
        event::listen_with(|event: Event, status, _| match (event, status) {
            (
                Event::Mouse(mouse::Event::CursorMoved { position }) ,
                status::Ignored,
            ) => Some(Message::MouseMoved {
                x: position.x,
                y: position.y,
            }),
            _ => None,
        })
    }
}
```
