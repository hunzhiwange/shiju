# 长度

[Length](https://docs.rs/iced/0.13.1/iced/enum.Length.html) 枚举用于设置组件的尺寸。

```rust
use iced::Length;

fn main() {
    let length1 = Length::Shrink;
    let length2 = Length::Fill;
    let length3 = Length::Units(100.0);
}
```
