# 插件兼容范围与冻结基线

本轮目标是本地插件原包与公开 MCP 的可观察行为兼容。行为目标登记于
[baseline.json](baseline.json)，登记完成不表示实现或验收已经通过。

## 来源与读取方式

- 冻结日期：2026-10-30。参考目录为同级 `codex-main`，没有 Git 元数据；
  不给它分配提交号或发布版本。`sources` 对每个实际引用文件登记 SHA-256。
- 计划中固定的 `manifest.rs`、`agent_plugin_manifest.rs`、
  `agent_plugin_config.rs`、`app_mcp_routing.rs` 四个散列已逐一匹配。
- `items` 中每行包含稳定 ID、字段、预期结果、负责的任务、来源路径/符号/行号与
  文件散列。行号只是导航，内容散列才是快照身份。来源类型区分源码、计划验收契约、
  公开文档；它们不能互相替代。
- 计划验收来源额外固定仓库提交号；编号任务删除后，可从该提交读取原任务文本复核散列，
  不要求保留已完成的任务文件。
- `snapshot_verified` 仅指已阅读源码；`planned_acceptance` 仅指任务要求；
  `official_document_observation` 仅指公开指南。所有实现证据初始均为 `pending`。
  `acceptance.tNN` 确保任务 2–66 可追溯，不能用这些占位验收行替代具体行为断言。
- 后续证据写入 `evidence/tNN.json`，关联行 ID 与实际命令、退出码、有效测试数、
  原包散列、真实副作用、拒绝及隔离结果、平台和 Cargo 槽位。
  不改写既有来源/预期来迁就实现；新来源与差异须显式追加。

公开打包指南的正文由官方文档工具读取，基线保存 UTF-8 文本散列与检索日期，
不将可变网页当永久协议版本：[OpenAI 插件打包规范](https://developers.openai.com/plugins/build/plugins)。
外部 MCP/Apps 协议须在任务 26–31 及联调任务中补齐官方版本与来源散列；
当前的扩展 ID、客户端初始化版本和连接池适用版本分别登记，不能混写成一个版本。

## 已核实的行为限制

- legacy 查找顺序为 `.codex-plugin/plugin.json`、`.claude-plugin/plugin.json`、
  `.cursor-plugin/plugin.json`。有效或未知版本的便携根清单优先；未知版本不静默降级。
- portable 固定 `skills/` 与 `mcp.json`；内联 `extensions.com.openai` 替换整个
  legacy 展示/Hooks overlay，不与之合并。另有同名 stdio 服务的独立 env overlay。
- legacy 技能递归，portable 技能只发现直接子目录。技能内 `agents/openai.yaml`
  确有界面、依赖和策略元数据解析；没有依据把任意顶层 `agents/` 文件视为自动执行代理。
- 命令迁移拒绝若干动态模板。参考实现写包内迁移目录，而本项目要求原包不改写：
  派生技能、配置、缓存、数据、凭据和证据必须置于包外。此布局差异必须有行为与原包散列证据。
- portable MCP 明确拒绝 legacy SSE，限制执行路径、环境保留变量、HTTP URL 与客户端自有头。
  legacy MCP 的 `type` 归一化警告不是 SSE 已可执行的证据。
- 公开指南列出的 MCP `extensions.com.openai.auth` 比本地严格 portable parser 更广。
  文档声明单独登记，不能宣称快照已执行这些 OAuth/API-key 扩展；任务 17、26–28 补实际支持证据。
- `prompt`/`agent` Hooks 警告并跳过。SessionEnd 跳过 `mcp_tool`，把 async command
  警告后改为同步执行；SessionEnd 与 Interrupt 默认 1 秒、最多 3 秒，其它通常默认 600 秒。
- Pre/PostModelRequest 是仅观察事件，输出只作诊断，不控制或改写模型请求。
  PermissionRequest 不支持改写输入/权限；PostToolUse 不支持 `updatedMCPToolOutput`。
  PreToolUse 的 `updatedInput` 只在受支持的明确更新分支生效，不能视为宿主权限许可。
- 安装或启用不自动信任 Hooks。执行时校验声明与包内容；参考 fingerprint 忽略部分运行时目录，
  因此不能用它替代原包完整字节验收，也不复制私有信任白名单。
- `io.modelcontextprotocol/ui` 协商声明不证明已有完整渲染器。表单、桥接、应用面板、公开 OAuth
  和三平台验收必须取得各自实际证据；缺失环境不能记为完全兼容。

## 排除与不可放宽条件

用户排除 OpenAI 托管连接器、私有目录、账号后端及专属托管运行时；不复制令牌、
私有客户端身份、品牌或特权白名单，不承诺未知未来 schema 或模型逐字输出一致。
`.app.json` 只表明有托管映射，不能据此排除包内独立技能、脚本或公开 MCP 部分。
能随包分发的本地依赖也不能一概归类为私有服务。

沿用 VibeWindow 安全策略；来源差异须公开记录并评审，禁止以静默放宽权限取得兼容。
缺解释器、REPL、浏览器、媒体、公开账号授权或平台环境时，诊断可通过，但依赖它们的
包不能因此通过完整验收。外部服务不可用或缺平台证据仍阻止最终兼容声明。

## 本任务验证

本任务只新增来源文档，不修改运行行为；按任务契约不调用 Cargo、不领取槽位。
验证 JSON 可解析、ID 唯一、全部来源散列/符号可定位、后续任务映射完整、文档链接及差异无误。
相邻测试仅阅读其断言，未执行；不得把它们记录为本仓库通过证据。
