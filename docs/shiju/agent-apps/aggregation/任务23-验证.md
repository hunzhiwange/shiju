## 真实 Codex

使用本机 `codex-cli 0.167.0-alpha.3.2`。先执行 `codex debug models --bundled` 获取该客户端可读的模型行模板。用 Rust 编译临时夹具调用本任务同一个投影函数，从带卡片覆写的目录生成发布前后两份 JSON。每个场景以独立临时 `CODEX_HOME` 启动 `codex app-server --listen stdio://`，经 `thread/start` 选择 `approvalsReviewer: auto_review`、`approvalPolicy: on-request` 和只读沙箱。模型上游为动态端口的回环 Responses SSE 服务，返回固定审批结果。夹具以 `python3 client.py projected` 执行，退出 0。

| 输入 | 真实客户端请求 | 结果 |
| --- | --- | --- |
| 发布非默认成员，保留卡片原值作为输入 | Guardian 的 `POST /v1/responses` 请求使用 `ccs-member/reviewer` 一次 | `item/autoApprovalReview/completed` 返回 `denied` |
| 相同目录，上游返回畸形 JSON | Guardian 三次请求均使用 `ccs-member/reviewer` | 完成通知为 `denied`，理由明确指出自动审批因 JSON 无效而失败 |
| 移除成员并保留原请求意图 | Guardian 请求使用 `codex-auto-review` 一次 | 恢复默认审批并返回 `denied` |

三组均无用户审批请求，也未创建测试命令的标记文件。模型输入和输出使用本机夹具，配置与账号均隔离。此处覆盖 Codex 实际读取目录及发送审批请求，正式聚合发布、远端权限和设置 API 由对应后续任务验证。
