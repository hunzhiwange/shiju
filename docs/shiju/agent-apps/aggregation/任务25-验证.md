## 常驻 V2 链路

- `app_routing/compaction_tests.rs::aggregation_t25_aggregation_compaction_preserves_contract` 通过 `RoutingListener::publish_aggregation` 发布可信租户、项目、主机、账号代次和成员目标，再用真实 HTTP/SSE 访问同一监听。聚合标识精确映射到目标模型，错误目标返回脱敏 502，撤销后返回 401。
- `responses_compaction::Request` 只接收流式内联历史中的单个压缩触发或压缩回放。普通 Responses 请求沿该窄入口明确返回不支持。上游使用已授权目标的 Chat 端点，客户端字段不能改变地址或凭据。转换后的协议控制字段在供应商覆盖后再次固定，压缩回合禁用新工具调用。
- `responses_stream::Decoder` 复用现有分帧及流读取逻辑。正常完成时发出恰一个 `response.output_item.done` 和单项 `response.completed.output`，摘要以兼容封装供下一轮回放。截断或内容过滤返回 `response.incomplete`。空摘要、异常工具输出、无终帧和传输错误明确失败，错误消息不携带上游原文。
- 本机 Codex `app-server` 使用独立 `CODEX_HOME`、夹具凭证、只读沙箱及非交互审批设置，夹具仅返回摘要或文本。实际发送 `thread/compact/start` 和下一轮 `turn/start`，两个回合状态均为 `completed`。模型上游是受控回环 HTTP 服务，验证覆盖客户端协议和 ShiJu 数据面。
