## 权限与失败边界

| 状态 | 结果 |
| --- | --- |
| 400 | `invalid_request`：选择器、请求形状、未知字段或空修订无效 |
| 401/403 | `unauthenticated` / `forbidden`：缺凭证，或项目/应用/配置/路由权限不足 |
| 409 | `revision_conflict` / `recovery_pending`：旧修订、未认领资源或待恢复事务 |
| 422 | `unsupported_app` / `unsupported_target` / `invalid_model` / `invalid_configuration` |
| 502 | `target_failed`：真实原生写入失败，未宣称保存成功 |
| 503 | `target_unavailable`：目标离线、存储或可信账号执行前置不可用 |
