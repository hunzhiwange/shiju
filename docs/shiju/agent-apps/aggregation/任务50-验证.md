- `GatewayClient::aggregation_state`：GET `/v1/agent-apps/{app}/aggregation/state`，query 序列化主机及项目。
- `aggregation_preview`：POST 同前缀 `/preview`，JSON 传 scope、候选默认项和目录策略。

- 四项使用 endpoint 的 Bearer、平台和公司上下文，不接触本机配置；独立 native transport 禁止重定向和自动重试，写入不自动重放。AggregationApiError 区分传输、HTTP 状态/JSON 错误体、响应解码；Display 不输出业务错误体。
