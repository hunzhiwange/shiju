实现：`crates/vw-gateway-client/src/client/aggregation_native_api.rs`，公开方法 `GatewayClient::pi_directory_state`、`pi_directory_entry`、`omp_directory_state`、`omp_directory_entry`；独立测试 `aggregation_native_api_tests.rs`。`client/mod.rs` 仅追加本模块及测试模块注册，在共享合入锁内完成。沿聚合 SDK 的 AggregationApiError 返回结构化 HTTP 错误。

- 读取走实际约定的 POST `/v1/app-providers/{pi|omp}/config/state`，正文包含 targetHostId/projectId。写入走 PUT `/v1/app-providers/{pi|omp}/{id}/directory-entry`，携带不透明 expectedRevision 和各自类型的 change。
- PiProfile 与 OmpProfile 分开类型化。insert/replace 的 profile 是供应商声明，OMP 活动 profile 不由请求选择；响应的 null 和具名 profile 原样保留。remove 只发 kind，无配置载荷。没有公开接受通用 JSON 的目录写入口。
- ID 沿既有供应商规则：非空、至多128字节、ASCII 字母/数字/下划线/连字符；空白、路径、非 ASCII 和超长值在发送前拒绝。
- 原生 transport 禁用重定向和重试；认证使用 endpoint 的 Bearer，与旧入口 x-agent-apps-token 区分，租户头沿 apply_request_context 注入。不记录请求正文和凭证，不加入路径或进程参数。
- 不将冲突、权限、目标失败、坏响应或连接失败转为空目录，不自动刷新修订或重放写入。HTTP 非 JSON 错误保留状态且 body=null；传输/解码消息不回显服务端内容。
