- 在既有应用供应商弹窗增加「OMP 独立模型条目」，组件为 `crates/vw-desktop/src/app/components/agent_apps/aggregation_omp.rs`；消息及执行在 `app/message/settings/aggregation_omp.rs`，独立 reducer 在 `aggregation_omp/core.rs`。复用原 `ListState` 和 `ListMessage`，没有新建目录服务或本机配置解析入口。

- `read/execute` 仅调用 `GatewayClient::omp_directory_state/entry`。插入、替换、确认移除只发一项类型化变更；携带实际主机、已注册项目和服务端修订，不发送 profile/path 选择器、默认模型写入、MCP 或登录动作。供应商 YAML 是用户草稿，经语法转换后交给网关原所有者校验，不读取或编辑本机 models.yml。
- 表单绑定项目、主机及访问代次；切换后撤下旧表单，迟到的 scope/project/access/generation 响应不覆盖当前状态。执行时阻止编辑及关闭；失败解除忙状态，保留 ID、名称、YAML 草稿及原修订，不自动刷新或重放写入。用户可以修正后重试，或明确刷新并核对新修订。
- 权限、修订/恢复冲突、缺失条目、目标不支持、无效/不安全 YAML 与目标失败均有固定提示，不透出服务端消息或敏感载荷；事件与表单 Debug 隐去草稿。反馈使用原 toast，未新增登录或 MCP 写入入口。
- 使用统一 settings 输入/编辑器/按钮样式和 `settings_modal_layout/overlay/close_button`。标题及操作区固定，正文由公共组件提供4px滚动条、两侧7px留白；所有动态中文使用默认字体，没有 MONOSPACE。
