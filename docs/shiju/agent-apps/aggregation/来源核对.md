### stack.rs · 母 10 聚合规则

- `supports_stack` 支持 Claude Code、Codex 和 Claude Desktop。上游手册只列 Claude Code 和 Codex，任务以源码分支为准。 `allocate_key` 优先从内置图标或供应商名生成 ASCII key，持久登记并保留移除或删除项的占用，避免旧 ID 指向另一家。 `encode/decode` 分别使用 `ccs-claude-<key>--<model>`（可带 `[1M]`）、`ccs-<key>/<model>` 与 `claude-fable-ccs-<六位数字>`（稳定 FNV-1a）。Codex 缺少斜杠的 `ccs-` 名称仍按普通模型处理。 [stack.rs](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/stack.rs)
- `published_members` 只在启用时展开发布。Claude 的显式模型列表为空时不发布，未设置时沿用别名映射，按去掉 1M 标记的上游名去重。 `claude_route_default` 以默认供应商第一项投影别名。Codex 从供应商目录取模型，默认行走其原目录。Desktop 从已配置映射取模型，默认行走 profile 映射，非默认行按名单顺序对六位数字碰撞保留首项。Claude 和 Desktop 的模型发现分别调用 `claude_published_now`、`desktop_published_now`。 [模型规则](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/stack.rs) · [HTTP 调用者](../../../../crates/vw-agent-apps/upstream/src-tauri/src/proxy/handlers.rs)
- `proxy/handlers.rs::resolve_stack_target` 在普通路由前调用 `resolve`，命中后把请求的 model 改为上游值并携带目标供应商。关闭聚合、无效 ID、已移除及已删除等失败按协议拒绝，保留 ID 不回落到默认家。来源中的 Claude/Codex 在供应商仍为成员时允许历史模型名发到该供应商，由上游判断是否支持。Desktop 先反查实际发布顺序，再查变成默认家的旧 ID。 `handler_context.rs` 对精确命中只提供一个供应商，聚合中的普通模型也只选默认家。 `forwarder.rs::routing_state_enabled` 隔离精确命中的路由状态。相邻上游用例有 `stacked_ids_that_cannot_be_resolved_never_fall_back_to_the_route` 和 `stacked_ids_are_rejected_outside_stack_mode`。 [解析规则及用例](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/stack.rs) · [请求上下文](../../../../crates/vw-agent-apps/upstream/src-tauri/src/proxy/handler_context.rs) · [转发器](../../../../crates/vw-agent-apps/upstream/src-tauri/src/proxy/forwarder.rs)

### controller.rs · 母 4 模式事务，母 10 聚合约束，母 8/9 路由协作

- `commands/proxy.rs` 的 `set_proxy_takeover_for_app`、`set_proxy_route`、`get_proxy_stack`、`set_proxy_stack_member` 分别进入 `enter_with_route/exit`、`set_route`、`stack_view_with_clients`、`set_stack_member`，由 `lib.rs` 注册，`src/lib/api/proxy.ts` 调用。 `set_stack_member` 以目标布尔值增删，锁内先处理待恢复操作。默认项激活后不能移除，新设的合格默认项自动加入。 `check_stack_member` 拒绝官方账号，核验 Codex 目录及 Desktop 映射，Codex 官方可在默认路由保留客户端登录。 [控制器](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/controller.rs) · [命令](../../../../crates/vw-agent-apps/upstream/src-tauri/src/commands/proxy.rs) · [注册](../../../../crates/vw-agent-apps/upstream/src-tauri/src/lib.rs) · [TS 调用](../../../../crates/vw-agent-apps/upstream/src/lib/api/proxy.ts)
- `publish_stack/write_proxy` 将客户端投影与 `PendingTarget` 的状态和名单一起落定。未附着时只落定名单，相同契约通常免写客户端文件。 `StackWriteError::partial` 区分已经开始发布、需前滚的失败。 `commands/provider.rs` 的排序调用 `sync_stack_order`，`services/provider/live.rs` 的保存调用 `resync_saved_row_locked`，`commands/settings.rs` 触发 Codex 重发布。 `exit_locked/write_direct_for_exit` 恢复直连，进程退出的 `detach_all` 保留逻辑模式供 `startup` 恢复附着。 [控制器及事务用例](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/controller.rs) · [排序](../../../../crates/vw-agent-apps/upstream/src-tauri/src/commands/provider.rs) · [保存](../../../../crates/vw-agent-apps/upstream/src-tauri/src/services/provider/live.rs) · [设置](../../../../crates/vw-agent-apps/upstream/src-tauri/src/commands/settings.rs)
- `commands/failover.rs` 调用 `switch_route_for_failover`，`proxy/failover_switch.rs` 调用 `record_failover_route`。前者在聚合启用时拒绝自动切换，后者丢弃进入聚合前发起的迟到结果。退出聚合后原队列可继续用于路由模式。上游用例 `a_failover_finishing_after_entering_stack_mode_is_dropped` 与 `stack_mode_sends_default_requests_to_the_default_only` 覆盖两个分支。 [控制器及故障转移用例](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/controller.rs) · [启停调用](../../../../crates/vw-agent-apps/upstream/src-tauri/src/commands/failover.rs) · [结果调用](../../../../crates/vw-agent-apps/upstream/src-tauri/src/proxy/failover_switch.rs)

### contract.rs · 母 4 客户端契约，母 10 提供聚合投影

`CONTRACT_VERSION=1`。 `controller.rs::claude_contract/write_proxy` 消费 `contract::{claude,gemini,grok,claude_desktop}`。Claude 对排序后的 env、独有字段及非空 top（聚合的 `modelPicker`）计算摘要，Desktop 对网关 profile（地址、凭据、目录）计算摘要。Gemini/Grok 的代理投影仍归通用模式契约。Codex 由 `codex_direct::contract_of` 复用版本号，对最终地址、表项、目录摘要和登录等计算自己的契约，由 `write_proxy` 调用 `prepare/prepare_official_rows/plan` 后决定落盘。相邻用例 `the_contract_ignores_map_order` 和 `exclusive_fields_and_the_proxy_address_change_the_contract` 覆盖免重写与必须重写的边界。原生实现使用自身的契约版本 2 与前滚事务，聚合应传最终客户端投影。 [契约](../../../../crates/vw-agent-apps/upstream/src-tauri/src/mode/contract.rs) · [Codex 契约](../../../../crates/vw-agent-apps/upstream/src-tauri/src/services/provider/codex_direct.rs) · [原生契约](../../../../crates/vw-agent-apps/src/providers/mode_state.rs)
