# 同步冲突契约

`device_sync::conflict::preview` 比较固定制品内容产生的 snapshot_id，不使用时间或设备名。相同内容无需传输；有成功基线时仅本地变化可上传、仅远端变化可下载、双方变化冲突。无基线且远端不存在可上传；无基线但双方内容不同，以及已有基线后远端消失，均保守判为冲突。

Gateway 按目标、profile、data_compat_version 隔离保存成功基线，仅在传输、应用与回读成功后推进。远端缺失必须经传输层确认，认证、网络、解析或兼容性错误不得转换为缺失。

预览保留 `expected_remote_snapshot`（包括明确不存在）。执行者在副作用前重新读取并调用 `recheck_remote`；变化返回 `SyncConflict`，API 映射 HTTP 409。上传后回读 manifest 调用 `verify_published_snapshot`，不一致时不推进基线。执行者还须锁住本机操作并保证使用预览对应的本地内容。传输执行与 API 接线由后续任务消费这些接口。

复核与 ETag 均不是分布式锁，无法消除复核后的并发覆盖或 ABA；回读只能发现观察时的不一致，不保证此后没有写入。

本轮依用户要求仅实现并静态审阅，未运行 Cargo、单元测试或实机验证；未领取构建槽位。后续统一验证需覆盖判定矩阵、远端新增/变化/消失、非法摘要、发布回读不一致及 API 409 映射。
