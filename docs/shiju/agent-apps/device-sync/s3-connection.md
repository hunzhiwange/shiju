# S3 连接探测契约

`vw_agent_apps::device_sync::s3_transport::test_connection` 接收凭据已解析的 `S3Config`，由 Gateway 在授权执行主机网络访问后调用。允许显式测试尚未启用的配置，但必须提供桶、区域和访问密钥；不持久化配置，不创建桶或对象。

复用 `s3_signing` 的 AWS 虚拟主机地址、自定义端点路径地址和 SigV4 签名，对桶发送一次 HEAD。连接超时 10 秒、请求超时 30 秒，禁止跟随重定向，不自动重试。2xx 表示桶可访问，不证明写权限，也不表示桶为空。401、403、404、重定向、其它 HTTP 错误及网络/超时错误均返回错误；HTTP 错误保留状态码，错误文本不包含端点、密钥或响应体。HEAD 的错误响应可能无法区分凭据无效与权限不足，403 不推断桶不存在。

本轮仅实现并人工审阅源码，未运行编译、单元测试、loopback、实机或最终回归；未领取 Cargo 槽位，未设置缓存路径。后续统一验证应覆盖真实 loopback 签名 HEAD、AWS/custom 地址、各错误状态、网络失败与重定向不跟随。
