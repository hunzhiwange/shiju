# 任务状态查询

`GET /v1/agent-apps/device-sync/tasks/{id}?projectId=…&targetHostId=…` 返回 `SyncTaskStatus`，包含阶段、已传字节、可选总量、告警和带安全错误码的终态。响应禁止缓存。

租户由认证中间件注入，用户由现有 `device_sync_config` 项目/主机授权解析，与配置读取的任务摘要权限一致；完整目标必须匹配。未知任务、越租户、越用户、越主机及策略拒绝均返回无正文的 404。存储故障返回 503，不暴露底层错误。

优先读取运行中记录（包括持久化失败告警），重启后只读统一库日志；查询不会初始化恢复或把活动任务改为中断。重启前的非终态表示最后持久化状态，须等待网关执行所有者恢复后再判定中断。轮询是断线后的状态恢复依据，不承诺 SSE 可靠重放。

本轮仅实现与源码审阅，未编译、未运行任何测试或实机验证，未领取 Cargo 槽位或设置缓存路径。后续统一验证须覆盖阶段/字节/错误/告警/终态、未知 ID 与权限拒绝一致性、跨租户/用户/主机隔离、重启读取及查询无恢复副作用。
