# WebDAV 下载应用契约

`device_sync::webdav_download::download_webdav_snapshot` 由网关在已授权执行主机的同步锁内调用，连接凭据来自本机凭据所有者。冲突预览必须绑定相同目的地、profile 和兼容版本，且决策为 Download。

先下载 manifest，再完整下载并校验 config.json 与 skills.zip 的长度及 SHA256；下载后及发布前重新读取 manifest，ETag 或原始内容变化均拒绝。严格解压、配置所有者的本机字段保护、技能目录集合与内容摘要校验全部完成后，才调用本机技能准备回调。回调只暂存，不发布；返回集合及摘要必须与下载配置一致。

调用者提供本机授权的技能身份、绑定、恢复目标和完整前像，以及受影响领域的真实派生刷新任务。所有路径来自本机授权，不从远端解析；不恢复跨设备凭据。应用复用 apply_snapshot 的持久回退点、配置事务、技能回滚及刷新告警语义。内层错误保留恢复凭据；只有成功返回才可持久化返回基线。刷新告警表示配置已提交，重试走派生刷新接口，不能重放导入。

固定远端键的多次读取是乐观检查，不能阻止最后一次检查之后的远端写入；应用的仍是已校验的不可变下载字节。

本轮按用户要求仅实现及源码审阅，未运行编译、单元测试、实机测试或最终回归，未领取 Cargo 槽位。后续统一验证应覆盖损坏/缺失制品、manifest 变化、目录越界、技能集合与摘要不符、回滚和刷新告警。
