# 仅清除当前组合标记合同

`ProjectProfileStore::with_operation` 内的 `ProfileOperation::clear(project, target_host_id, group)` 复用现有租户状态事务，只移除指定执行主机和组的当前标记，不要求引用实体仍存在。标记缺失或重复清除均返回成功；实体、快照、版本、其他组及其他主机的标记不变，不调用供应商、MCP、技能、提示词或原生配置写入。

调用者必须先解析真实项目身份并授权目标主机，再在执行端调用；操作上下文校验租户，目标主机不匹配直接拒绝。指定槽位属于其他项目时返回冲突，不清除其标记。事务在移除前校验全部匹配记录，损坏存储中的重复记录也不能借此释放其他项目槽位。反序列化失败、权限边界不符及存储错误均返回失败，不能当作“没有标记”吞掉。API/SDK 接线属于后续任务，不能将该存储入口视为已交付可调用 API。
