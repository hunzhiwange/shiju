# 普通提示词激活契约

来源：固定来源 ca58c0313360eae7c851fbd7553c1614c7af03e7 的 cc-switch `services/prompt.rs::enable_prompt`；实现前核对源目录同名函数。消费持久化（任务4）、当前文件读取与固定目标（任务7）及原生配置事务；不修改 plan.md。

入口为 PromptsStore::activate_ordinary 和 prompts::activation。目标不存在于目录、当前选择损坏、非 UTF-8 文件、版本或权限冲突均在写入前拒绝。空正文有效。Pi/MCode 走专项，OpenClaw/Claude Desktop 不由普通激活处理。目录增加默认空 active_id，唯一选择与条目、备份在同一 CAS 载荷提交，旧目录无需迁移。

持有应用/物理目录锁读取 live，切换时回填旧选择；无选择或覆盖同一选择时按精确正文去重备份，保留空白及换行差异。备份使用服务器 UUID。激活同一条目先冻结目标正文，避免回填覆盖用户编辑。当前启用项编辑必须使用该入口携带 edit，普通 update 明确拒绝，删除启用项也拒绝。禁用副本编辑仍不写文件。

授权执行端提供 host、HOME、路径覆盖、环境和 ProviderTransactions，回调在发布前复核动作及物理归属；事务要求已绑定同一 ProjectScope，不自动认领。使用固定文件名和带前镜像比较的原子事务，不接受客户端路径。文件提交失败不提交目录；目录 CAS 失败比较刚发布正文恢复文件，恢复失败单独报错，避免覆盖外部编辑。进程崩溃窗口只由既有文件事务恢复，跨文件与目录数据库的崩溃原子性不在同步回滚保证内。

API/SDK/UI 留后续专项接线。本轮按用户最新要求未运行 Cargo、单元测试、实机或其它测试，未启动最终回归，也未领取槽位。后续统一验证需覆盖成功切换、去重备份、当前编辑即时投影、权限/归属/版本拒绝、目录提交失败恢复、外部文件冲突、双存储后端和 macOS 路径安全；此处不声明验证通过。
