# 桌面激活、停用与删除反馈（任务31）

来源：cc-switch PromptPanel 的 performDelete、handleToggle 与 toggleEffectText；消费任务29列表，以及 SDK activate/deactivate/delete/save/current 契约。

桌面不乐观更新激活标记。写操作串行，响应核对网关、租户、项目、主机、应用及请求代数；拒绝时保留已有选择，通过既有 toast 呈现错误。启用条目删除交由服务端拒绝。成功提交目录后重新读取目标快照；刷新失败明确提示“操作已保存，但目标快照刷新失败”，禁用后续写操作直到刷新。Pi 提示 /reload，Hermes 提示新会话生效。

撤销按钮保留一次操作后的目录 revision 和目标原文；目标快照必须与本次写入的预期结果一致才提供撤销。撤销使用原 revision 和原文，不用最新读取值重新授权覆盖，服务端 CAS 冲突不重试。切换范围或刷新清除撤销。当前 save 创建合同分配新 ID，因此删除撤销恢复为新的停用条目，不承诺原 ID 或排序位置。原生文件具有额外包装而无法证明写后全文一致时，不提供撤销。
