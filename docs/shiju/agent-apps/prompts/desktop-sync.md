# 桌面全部同步合同

来源：固定快照 ca58c0313360eae7c851fbd7553c1614c7af03e7 的 sync_all_to_live；消费任务28同步 API 与任务29资源 SDK，参见 sync-api.md、resources-sdk.md。

入口为外部应用提示词页的“全部同步 / 查看进度”。调用既有 SDK 提交、查询、取消操作，服务端拥有执行状态。普通同步不包含 OpenClaw；Pi 与 Claude Desktop 由服务端报告跳过。桌面不自行拼接文件或引入后台同步策略，进度通过显式刷新查询既有操作。

面板展示操作状态、已返回目标数及每目标成功、失败、跳过、未执行、原因和多选警告。取消保留服务端已完成结果，不承诺回滚；取消请求失败仍保留已有句柄与结果，可重新查询。重试仅向服务端提交终态报告明确标记 failed / not_executed 的目标；不重试成功、跳过或尚未返回的目标。

关闭面板、刷新提示词或切换应用不取消后端操作，现有提示词状态失效时保留同步句柄；重新打开同一网关、租户、项目、主机范围可继续查询。范围变化不复用旧操作，旧异步响应由上下文、范围和请求代数隔离。桌面进程退出后的句柄恢复不在现有持久化合同内。提交响应丢失时不自动重放写入，禁用重复提交并提示核对后端。

使用统一 settings modal、按钮及滚动布局，文本使用默认字体。2026-11-14 按本轮要求仅写代码与本合同，未运行 Cargo、单元测试、实机测试或其它测试，未领取槽位或启动最终回归。后续统一验证需覆盖取消保留完成结果、部分失败、精确重试、关窗后查询、跨范围与乱序响应、提交响应丢失及 macOS 明暗主题实际渲染。
