# 桌面复制、导入与文件定位（任务34）

来源：固定快照 ca58c0313360eae7c851fbd7553c1614c7af03e7 的 PromptCopyDialog、handleCopyToApps、usePromptPageCommon；直接消费任务29列表状态和既有提示词 SDK 的 copy/import 接口。

所有复制目标默认不选（包括 Hermes 与同名目标），当前应用不列为目标。明确勾选后调用复制接口，逐项展示后端成功或失败结果；提交后清空勾选，重试须重新选择。副本保持停用，不在桌面覆盖同名条目。正文与完整路径分别复制。

“导入当前目标主机文件”发送 CurrentFile，由授权网关读取目标文件；“从用户本机选择文件导入”只读取明确选择的 UTF-8 文件，最多 1 MiB，以 UploadedContent 上传正文和文件名，不上传客户端路径。导入结果使用服务端目录 revision，不激活条目。取消选文件不产生写请求。

仅 loopback 网关且 target_host_id 为 local_apps::HOST_ID 时可执行 Finder 定位，使用绝对路径和固定 /usr/bin/open -R 参数；其余路径仅复制。所有异步结果核对网关、租户、项目、主机、应用及目录/请求代数。操作期间禁用重复提交；弹窗复用统一控件、固定页眉页脚和 4px 滚动条、7px 留白，Unicode 使用默认字体。

复制接口没有安全撤销令牌，桌面不臆造跨应用回滚；导入后清除旧激活撤销状态，既有激活/删除撤销仍由原模块负责。
