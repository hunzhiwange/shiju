## 4. Grok 与 xAI 订阅

Grok CLI 读可配置目录下的 `auth.json`，优先选非空 OIDC key，次选 legacy session。文件不存在为 `not_found`，文件或结构错误为 `parse_error`。令牌过期且有 refresh token 标为待刷新，CLI 入口仍尝试一次旧 token，续期由 CLI 负责。托管 xAI 由账号命令提供 bearer 并复用 `query_grok_quota`。[凭据与状态](../../../../../crates/vw-agent-apps/upstream/src-tauri/src/services/subscription_grok.rs#L40-L179) · [CLI 入口](../../../../../crates/vw-agent-apps/upstream/src-tauri/src/services/subscription_grok.rs#L702-L734) · [托管调用](../../../../../crates/vw-agent-apps/upstream/src-tauri/src/commands/xai_oauth.rs#L20-L89)

向 `grok.com/grok_api_v2.GrokBuildBilling/GetGrokCreditsConfig` POST 空 gRPC-web 帧，15 秒超时。先检查响应头和 body trailers 的 gRPC 状态，再从 data 帧或裸 protobuf 启发式读取单档已用百分比及未来重置。只有缺少 fixed32 且具备周期标记和重置时推断为零用量。按重置距今四舍五入后的 4–12 天、20–45 天分别标周、月，其他标 credits。HTTP 401/403、gRPC 16 或指定 gRPC 7 标过期，gRPC 9 的无个人团队提示为团队用量不可用，HTTP 408、gRPC 4/14 或带超时含义的 1 返回瞬时错误。其它 HTTP 非成功或结构错误形成失败快照，前端另识别 429/5xx。任务 29 独占 CLI/托管协议解析，来源仅有一档百分比，无独立钱包金额或多套餐输出。任务 57 独占 macOS 实号验收。[帧与解析](../../../../../crates/vw-agent-apps/upstream/src-tauri/src/services/subscription_grok.rs#L285-L451) · [错误和查询](../../../../../crates/vw-agent-apps/upstream/src-tauri/src/services/subscription_grok.rs#L455-L699)
