# 技能安装与同步

技能平台由 `gateway-skill-market` 和 `gateway-shiju` 对接。专家中心和识矩技能使用这些接口读取目录、详情及安装包。

本地技能配置由 `gateway-desktop` 提供技能目录、详情和管理接口。技能卡片右键菜单的「同步到第三方」使用 `POST /v1/skills/sync`，由本机网关校验来源后安装到所选应用的全局技能目录。原有 ZIP 和文件夹导入继续使用本地技能导入器。

插件通过独立的插件接口安装。插件提供的技能随所属插件管理。

原「仓库与分发」已下线，仓库发现、旧安装任务、应用绑定、存储迁移、备份恢复及仓库导入链接已经退役。历史验收材料记录下线前的实现。
