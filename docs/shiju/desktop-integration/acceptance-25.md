# 任务 25：窗口状态恢复

状态：代码已实现，未验证。日期：2026-11-14。

依赖任务 1 的来源与接口盘点已交付（acceptance-1.md）。本任务无网关、账号或外部 SDK 产物依赖；使用现有 Iced 0.14、objc2-app-kit 0.3.2 的 AppKit 窗口接口，新增启用其 NSScreen 特性。

主窗口创建完成后，以稳定的 ShiJu.main-window 名称恢复并启用 AppKit frame 自动保存；调试版使用独立名称。仅处理真实主窗口句柄，宠物和辅助窗口不共享状态。macOS 启动不再强制最大化或首次宽屏缩放，避免覆盖保存的尺寸。读取 frame 后选择相交面积最大的屏幕；已断开的屏幕回退主屏，按 visibleFrame 缩小超大窗口并修正越界位置，保留有效负坐标。

恢复错误写入不含配置载荷的警告，保留当前窗口。非 macOS 维持现有窗口行为。

独立用例文件 desktop_integration_25_tests.rs 从底层 window 模块注册，覆盖有效负坐标、越界、超大窗口与非有限坐标；未修改共享 app/mod.rs 注册。入口默认值断言同步调整。

按用户本轮覆盖要求，未运行 Cargo、调用 Cargo 的脚本、单元测试、实机测试或最终回归；未领取构建槽位，CARGO_TARGET_DIR 未设置。以上仅为实现交接，不是测试通过证据。任务卡按要求删除。后续统一验证须覆盖原生 frame 跨重启保存、移动/缩放、屏幕断开、Dock 恢复及保存错误路径。
