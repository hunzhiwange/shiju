# 切换默认授权账号

母任务 6／批次 34。批次 1–33 的合同与交付已核对，直接前置为 [绑定供应商与授权账号](绑定供应商与授权账号.md)（`777353f5d`）。沿用 [批次 4 的开工裁定](脱敏账号与流程DTO.md#开工边界)，复用已验收的底座及已交付的供应商事务。来源为 cc-switch 4.0.25（`ca58c0313360eae7c851fbd7553c1614c7af03e7`）的 `commands/auth.rs::auth_set_default_account`、`commands/copilot.rs::copilot_set_default_account` 和 Kimi 独立命令 `kimi_oauth_use_account`。

- `vw-agent-apps/src/auth/accounts.rs` 通过既有主机凭据租约校验 Copilot、Codex 和 xAI 的账号材料，持租约直到发布结束。xAI 已标记需重登时返回 `reauth_required`。
- `vw-agent/src/agent_apps/auth_accounts/defaults.rs` 复核同作用域的受管元数据后，通过 `GatewaySettingsStore` 原子发布不透明账号 ID。平台和公司沿用数据库租户键，配置键为可信主体、主机和授权服务。受管命名空间与历史启动默认隔离，供应商继续消费显式绑定。
- AGY 默认对应获授权钥匙串的原生项，Kimi 选用账号对应既有供应商事务中的原生 `default_model`。调用方须提供与作用域一致的受信槽位所有者。原生路径各自只有一个发布点。Claude 官方卡和单 grant 的 DSH 返回 `unsupported`。查询和 HTTP 接线分别归批次 38、43。
