## 覆盖范围

- 通过真实回环 HTTP 和生产 Gateway SDK 启动 Claude 登录。夹具子进程收到回填授权码后将合成 access token 与 refresh token 写入受管凭据文件。轮询返回 `approved`，同作用域账号查询返回 `ready`。从主机文件回读确认合成凭据确已写入。账号响应、轮询 DTO、回填请求 Debug 与 tracing 均检查脱敏。
- 启动响应保留官方 CLI 登录所需的浏览器 challenge，包括 state 和 S256 challenge。Debug 隐去 URL 和 state。CLI 链接拒绝未知或重复查询参数、带查询串的回调，以及缺少 S256 方法的 PKCE challenge。
- 拒绝路径的夹具在 CLI stderr 写入合成凭据，并在授权链接中携带未知参数、嵌套回调授权码或未散列的 PKCE verifier。网关返回 HTTP 502、稳定码 `upstream_failure`、安全说明及新的关联 UUID，账号列表保持为空。SDK 保留状态、稳定码和关联 ID。每条失败日志只投影操作、服务、稳定码及同一个关联 ID。捕获事件和 span 字段并逐项检查秘密哨兵。
- 参照上游快照的 Claude 链接与回填合同，并核对本机 Claude Code 2.1.316 生成链接的字段。测试以真实本地子进程替代公网 OAuth 和正式账号交互。真实账号验收归批次 61。
