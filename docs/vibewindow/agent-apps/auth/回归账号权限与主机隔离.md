## 覆盖范围

- 真实回环 HTTP 使用生产管理路由、Basic 认证、租户解析和服务端主体策略。公司头伪造返回 403，重复公司头返回 400。缺 Basic 凭据或主体凭据返回 401。
- 同一个外部身份在两个公司、两个执行主机及 Codex、xAI 的受管账号中分别写入独立元数据和凭据。各作用域仅列出各自账号和默认项。两个公司的官方供应商可分别绑定本公司账号。跨作用域绑定或设为默认遭拒后，原绑定、默认项和凭据仍可回读。
- 主机内 Codex 和 xAI 令牌入口按同一作用域解析凭据。合法请求读取尚未过期的本作用域令牌，跨作用域请求在发起 OAuth 前失败。Codex 过期令牌的交换、身份校验及文件写回另用现有适配器测试和本地 OAuth HTTP 替身验证。
- 离线主机返回 503，在线但缺执行通道的远端返回 501。远端即使登记了 AGY 原生槽所有者，也在钥匙串操作之前返回 501。失败请求没有启动本地 Claude 夹具进程。
- Claude 登录启动实际子进程，使用测试目录派生的 macOS 钥匙串条目，执行真实写入、读回和删除。其他公司、主机或服务的合法授权无法取消该流程。原进程与条目保持可用，所属作用域取消后子进程已回收，临时目录与钥匙串条目已删除，流程状态为 `cancelled`。
