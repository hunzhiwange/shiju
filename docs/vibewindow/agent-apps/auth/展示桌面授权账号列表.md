## 使用与权限

在「设置 → 授权中心 → 管理连接」输入部署登记的执行主机、管理用户名、管理密码与主体令牌。打开表单时，仅从当前网关及同一平台、公司的应用列表连接预填主机与主体令牌。部署须配置网关管理 Basic 认证，并为主体在目标平台、公司、执行主机和服务上单独发放 `auth_account_read`。AGY 和 DSH 仍要求服务端登记原生槽位所有者。

桌面网关端点使用 HTTP，因此管理连接仅启用直连回环网关。独立的 Basic 凭据和主体令牌留在当前桌面会话内，普通 skey 继续用于配对连接。账号读取复用 `GatewayClient::agent_apps_auth_accounts`，页面只显示服务端投影的账号标签、默认标记和有效性状态。服务失败按稳定错误码显示原因，成功的其他服务仍可见。切换网关或租户立即清空列表和管理连接，异步结果须同时匹配当前网关、租户和请求代次。
