# 执行登出与撤销语义

母任务 6／批次 36。批次 1–35 的既有合同和原生底座已核对，直接前置为批次 35 的 `f0ec26aea`。来源为冻结的 cc-switch 4.0.25（`ca58c0313360eae7c851fbd7553c1614c7af03e7`）中的 `commands/auth.rs::auth_logout`、`commands/copilot.rs::copilot_logout`、`commands/dsh.rs::dsh_account_sign_out` 和 `services/dsh_account.rs::sign_out`。[接口契约](接口契约.md) · [账号删除证据](删除账号并处理绑定引用.md)

- `AuthAccountStore::logout_accounts` 通过可信作用域和既有账号存储解析指定账号、默认账号或全部账号。账号及默认只取消该账号的定向流程，全部还取消未指定账号的流程。DSH 每次登录均指向唯一的共享 grant，因此指定 DSH 账号也取消这个槽的待处理登录。取消复用既有流程状态机和监听器／进程清理。
- Copilot、Codex、xAI 清除所选私有凭据并按值删除该账号的默认引用。Claude 清除经验证的私有目录和钥匙串项。受管账号元数据及供应商绑定保留，凭据缺失表示已登出，消费端无法再取得该账号凭据。Claude 和 DSH 无可切换的默认账号。请求缺少默认目标时返回 `not_found`。
- AGY 在已证明归属的原生钥匙串下清除匹配的原生登录并将受管记录保留为 `signed_out`。记录只保留脱敏账号和作用域标识。当前 AGY 进程可写回该槽时返回 `account_in_use`。Kimi 默认按受信原生配置中选中的模型解析。只有匹配受管凭据的同一 grant 才清除原生文件，保留独立 CLI grant、模型配置及绑定。
- `AuthAccountStore::revoke_account` 仅支持 DSH。先验证目标及官方 issuer，再核对同一 grant 版本、清除本地共享记录，并使用本次请求内暂持的敏感头向固定平台发送 `POST /auth-api/v0/users/logout`。HTTP 成功及响应业务码为 0 时才确认撤销。失败、跳转或响应不明返回 `remote_revocation_unconfirmed`，本地登出继续有效。其他六类在本地操作和网络请求前返回 `unsupported`。
- 本批交付执行主机业务及存储接线。跨进程刷新写回的代际回归归批次 37，HTTP 接线归批次 45，真实公网账号验收归批次 57–63。
