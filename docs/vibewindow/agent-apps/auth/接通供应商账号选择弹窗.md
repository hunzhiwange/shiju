# 接通供应商账号选择弹窗

母任务 6／批次 52。直接前置为批次 51 的 `8518fae3d`；沿用其对累计前置及母任务底座的核对。来源是 cc-switch 4.0.25（`ca58c031`）的 `AuthSettingsPanel.tsx`、`authBinding.ts` 和相邻的服务定位、供应商编辑测试。[授权中心](接通浏览器与手工回填交互.md) · [绑定 API](接通账号绑定API.md) · [账号操作 SDK](提供账号操作SDK.md)

应用供应商的已保存编辑页进入授权中心，并定位 Claude、Codex、Antigravity 或 Kimi 对应服务。桌面通过原有 SDK 用同一网关、租户、执行主机与主体重新读取候选；只显示目标服务下凭据可用的账号。Kimi 额外校验与已保存官方档案的地区一致。Kimi 的表单接口只增加地区，Codex 的表单接口复用官方卡事务校验并只增加可绑定标记。尚未接通供应商绑定的服务不提供入口。

保存使用现有供应商事务，只传不透明账号引用。等待执行主机确认后关闭弹窗；拒绝时保留选择，用弹窗提示和 toast 显示稳定错误，省略上游正文和关联 ID。供应商档案或连接代次变化会使旧弹窗失效；账号有效性和最终写入权限仍由执行主机判定。
