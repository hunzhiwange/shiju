# 接通默认切换删除与登出交互

母任务 6／批次 53。批次 52 由 `7a3060c79` 交付，沿用该批对累计前置和母任务底座的核对。来源为 cc-switch 4.0.25 的 `ManagedAccountRemoveDialog.tsx` 与 `useManagedAccountUsers.ts`。[供应商账号选择](接通供应商账号选择弹窗.md) · [账号操作 SDK](提供账号操作SDK.md) · [接口契约](接口契约.md)

授权中心按账号提供默认切换、删除、本地登出和上游撤销，各自确认并反馈结果。默认切换和 DSH 撤销先读取当前执行主机的授权能力。其他服务提示可单独本地登出。本地登出保留账号记录和绑定，DSH 上游撤销未确认时明确提示本地登出已完成。

删除预检使用同一网关、公司、主机和主体读取目标账号的可见供应商绑定。网关返回供应商标识，弹窗逐项列出。预检需要账号读取和供应商配置读取权限。已知存在引用时仅允许重新检查；预检失败或提交遭拒时可再次检查。执行主机负责提交时的引用检查和凭据事务，桌面只调用 SDK。

操作仅接受当前账号列表代次和弹窗代次中的目标。确认后拒绝重复提交，成功或结果未确认时重新查询对应服务。响应断开时由用户依据刷新后的状态决定是否重试。反馈只使用固定错误提示和操作名。
