# 阻止撤销与刷新竞态

母任务 6／批次 37。前置批次 1–36 已对照原生包、作用域账号存储、供应商事务与验收记录。直接前置是批次 36 的 `5a4253a2b`。[登出与撤销](执行登出与撤销语义.md) · [账号删除](删除账号并处理绑定引用.md) · [来源映射](来源映射.md)

## 执行主机合同

- Codex 和 xAI 仍按作用域与账号跨进程序列化刷新。同一账号的刷新锁跨越 OAuth 请求，凭据写锁只在读取及提交期间持有。登出和删除用既有凭据写锁移除目标文件。Codex CLI 轮换也持刷新锁，避免与主机同时交换令牌。
- 刷新保留起始凭据的文件描述符和内容摘要，在写锁下重新核对文件身份与内容。目标缺失或被替换时返回 `conflict`，拒绝写入新令牌或更新重登状态。删除后以相同字节重新创建凭据也属于新一代。提交前对短暂的写锁争用最多等待两秒，再按当前代际判断。
- AGY 继续用钥匙串记录代际检查，已登出的记录拒绝旧响应。Kimi 原生槽和 Claude CLI 写回继续由现有租约互斥保护。DSH 的远端撤销沿用本地 grant 版本检查。
