# S3 地址与签名

`device_sync::s3_signing::build_object_url` 接受任务 7 的规范化 `S3Config` 和原始 UTF-8 对象 key。空 key 指向 bucket；首部斜线去除，内部斜线保留，字节按 AWS RFC3986 大写百分号编码（百分号本身也编码），拒绝点段与控制符，避免 URL 解析改变对象。AWS 默认及真正的 amazonaws.com DNS 后缀使用 `https://{bucket}.s3.{region}.amazonaws.com/{key}`；其它自定义 HTTP/HTTPS origin 使用 `/{bucket}/{key}`，保留端口。不会通过主机名子串识别 AWS。调用方负责组合 remote_root/profile/对象名称，本模块不增加存储布局。

`sign_request` 接受配置、Method、key、原始 query 键值对、HeaderMap、body Vec 和显式 DateTime<Utc>，返回可发送的 reqwest Request，不访问网络、存储、凭据服务或真实时钟。禁止未启用配置、空凭据及已有 Authorization。secret 字节原样用于 HMAC，不 trim。HeaderMap 中 content-type、range 等均参与签名；host、x-amz-date、x-amz-content-sha256 由签名器覆盖。重复 header 值按逗号合并，值首尾与连续空白规范化。query 先编码再按编码键和值排序，保留重复项及空值，实际 URL 使用同一串。

canonical URI 是发送 URL 的已编码 path；canonical request 包含 method、URI、query、排序 canonical headers、signed headers 和实际 body SHA256。签名链为 AWS4+secret → 日期 → region → s3 → aws4_request，Authorization 标为 sensitive。返回 request 后不得改变 URL、参与签名的 header 或 body；传输层负责授权、目标网络边界及重定向限制。本模块不提供临时 session token 或预签名 URL 的自动支持。

静态审阅参照仓库 upstream/src-tauri/src/services/s3.rs 的地址规则、SigV4 及固定 AWS lifecycle 向量（20130524、us-east-1、签名 fea454ca298b7da1c68078a5d1bdbfbbe0d65c699e0f91ac7a200a0136783543）。该向量和 content-type 行为尚未执行验证，不作为通过证据。
