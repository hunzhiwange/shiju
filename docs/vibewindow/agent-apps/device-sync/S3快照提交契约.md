# S3 快照提交契约

`vw_agent::device_sync::s3_upload::upload_s3_snapshot` 为 macOS 执行侧入口，消费快照所有者的授权选择、作用域、技能根目录，以及新解析的 S3 配置、同目标/profile/兼容版本的基线与预览。调用者必须在 `run_with_sync_lock` 中原地等待整个操作，负责主机、网络和所选数据出站授权；本入口不新增凭据或状态存储。

直接依赖已按生产接口核对：任务16共享操作锁、任务30的 `SyncPreview`/`SyncBaseline` 冲突合同、任务26的 `S3UploadTarget` 签名上传、任务29的 `S3DownloadTarget` 有界下载均已存在。共享快照通过 `export_shared_snapshot` 获取真实过滤后的配置和技能归档；兼容版本由快照所有者提供，不猜测版本。

入口捕获一次快照，使用固定字节及其摘要构造 manifest。读取远端 manifest，核对预览记录的远端身份（包括不存在），重新计算决策并与完整预览比较，拒绝过期本地预览、下载或冲突决策。上传前再次读取并核对远端身份，依序等待 config.json、skills.zip、manifest.json 的签名 PUT；任何前置错误立即返回，不继续发布 manifest。S3 不创建 WebDAV collection。

无变化时不发送 PUT，仍校验远端两份制品的长度和 SHA256，再读取 manifest 确认身份。上传成功后先回读 manifest，再回读两份制品验证精确长度与 SHA256，最后复核 manifest；全部成功才返回 `SyncBaseline`。远端认证、网络、下载和非法 manifest 错误不当作不存在；只有下载接口确认的 404 表示不存在。

调用者只在入口成功后保存基线。后续基线或任务状态写入失败必须单独报告，保留已上传事实，不执行远端回滚或自动重传。任务状态持久化、API 与生命周期接线属于后续任务。

固定对象名和身份复核只提供尽力冲突检测，不提供跨设备事务或分布式互斥。部分 PUT 或超时可能留下远端字节，即使 manifest 尚未发布；发布后的回读失败也不能推断远端未写入。本入口不自动重试或恢复旧对象。

本轮仅完成实现与人工源码审阅，按用户最新指令未执行任何 Cargo 命令、脚本、测试、实机验证或最终回归；未领取槽位，CARGO_TARGET_DIR 不适用。没有编译或行为通过证据。后续统一验证需覆盖签名 loopback 请求顺序、中途失败不发布 manifest、预览变化拒绝、无变化零 PUT、发布及制品回读不符、仅状态保存失败保留上传事实。
