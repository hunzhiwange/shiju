# S3 配置校验

入口 `vw_agent_apps::device_sync::s3_config::S3Config::normalize` 消费执行侧输入，返回规范化配置或不包含输入值的静态错误。原始 secret access key 不 trim、不复制；类型不实现 Debug 或序列化。Gateway 后续负责授权、解析 Keep/Replace/Clear、凭据绑定和持久化，本入口不执行网络或文件操作。

bucket、region、access_key_id、endpoint、remote_root、profile 去除外围空白。root 去除首尾斜线，空 root/profile 分别补 `shiju-sync`/`default`。root 允许多段，profile 与 bucket 仅一段；拒绝空中间段、点段、反斜线、控制符、URL 分隔符、编码分隔符及嵌套百分号编码。bucket 限 ASCII 字母数字、点、连字符和下划线，region 限 ASCII 字母数字和连字符；access key ID 不允许内部空白或控制符。

启用时 bucket、region、access key ID、secret access key 必填；禁用草稿允许缺失，已填写的非秘密字段仍须合法。secret 仅以原始字符串是否为空判定，不改变空白字节；auto_sync 原样保留，执行门控归调度器。

空 endpoint（包括空白字符串）规范化为 None，表示 AWS 默认端点。自定义端点仅接受 HTTP/HTTPS origin，可带端口及单个末尾斜线；拒绝用户信息、路径、查询、fragment 和原始反斜线/控制符。HTTP 只表示格式可接受，不代表授权访问。

预设使用相同字段合同：AWS 使用 None 和实际 region/bucket；MinIO 使用实例 origin、实际 bucket 和配置 region；R2 使用账户 origin 和 `auto` region；OSS 使用地域 origin 和对应地域。不得在此猜测账户、填充 region 或将预设识别当作服务连通验收。
