# WebDAV 连接探测

入口：`device_sync::webdav_transport::test_connection(WebDavConfig)`。

调用者先授权主机网络访问并解析凭据；显式测试允许 enabled=false 的草稿，但地址和用户名不能为空。复用配置校验、安全路径解码和禁止重定向的客户端。凭据按请求附加，不记录 URL、响应正文或底层错误载荷。

先对基地址发送 Depth: 0 的 PROPFIND，再逐级 MKCOL remote_root/profile（每个请求限时 30 秒）。2xx 为成功；405/409 仅在原目录 PROPFIND 成功后视为已存在，否则返回明确错误。认证失败、禁止访问、父目录不存在、远端目录不存在和重定向分别报告；坚果云错误提示第三方应用密码、/dav/ 地址及手工创建顶层目录。

入口仅确保指定目录，不保存配置，不生成快照、不上传文件，不创建协议版本目录。网关 API/调度接入属于后续任务。

本轮仅实现与静态审阅，按用户指令未运行 Cargo、单元测试、实机测试或其它测试；未领取构建槽位，未设置 CARGO_TARGET_DIR。HTTP 行为与编译均未验证，需后续统一验证。
