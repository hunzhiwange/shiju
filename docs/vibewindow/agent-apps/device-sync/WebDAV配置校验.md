# WebDAV 配置校验入口

`vw_agent_apps::device_sync::webdav_config::WebDavConfig::normalize` 消费执行侧输入，返回规范化配置或不包含输入内容的静态错误。该类型不实现 Debug 或序列化；密码原样保留。它不是公开 DTO，不负责凭据保存、原密码保留策略、主机授权或网络访问。

地址和用户名去除首尾空白；remote_root 去除首尾空白和斜杠，空值补 `shiju-sync`；profile 去除首尾空白，空值补 `default`，必须为单一路径段。地址仅允许 HTTP(S)，规范化 URL 并去除尾斜杠，拒绝内嵌凭据、查询、片段、控制字符和反斜杠。解析 URL 前检查原始路径，避免解析器消除点段后绕过校验。

路径拒绝空段、点段、父级段、编码的分隔符、控制字符、无效百分号/UTF-8 编码和嵌套百分号编码。非空草稿字段仍受相同校验；禁用时允许缺地址或用户名，启用时两者必填。调用方须使用返回值，不得绕过校验后直接使用输入构建远端路径。

本入口依据任务3已交付契约独立实现；不消费尚未交付的共享快照或连接秘密存储接口。后续保存与传输任务负责接线，网络权限继续由 Gateway 控制。
