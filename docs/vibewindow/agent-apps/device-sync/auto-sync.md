# 有界自动上传入口

`device_sync::auto_sync::run` 由网关生命周期所有者按已授权 target/transport 唯一运行并回收；启动前初始化 tasks journal，通过 change_events::subscribe 订阅。生命周期接线由任务40负责。

watch 保留一个最新 generation，事务提交无需等待网络。首次通知启动1秒防抖，每次通知延后截止时间，但最晚10秒触发。截止后消费当前 generation；锁等待、配置重读和上传期间的新 generation 保留到下一轮，不在成功或失败后清空。

每轮在 tenant/host 统一锁内重新读取连接与凭据，缺失、disabled 或非 auto_sync 跳过。reload 返回当前配置与绑定凭据；upload 使用该 material 内联完成真实传输、提交及基线持久化，不可再次获取同一锁或分离后台工作。传输适配器必须保留原有冲突检查，不能将自动上传视为强制覆盖。

任务使用 Auto 来源、Upload 方向及唯一 request_id，错误通过统一任务记录保存安全错误码。失败本身不生成通知或立即重试；后续真实变更可以启动下一轮。任务记录写入失败退出并交给生命周期所有者报告。关闭取消等待及防抖；已经开始的上传由其提交边界处理取消，循环等待其返回，不丢弃提交 future。

本轮仅代码审阅，依用户指令未运行编译、单元测试、实机或其它测试；未领取 Cargo 槽位、未设置缓存路径。所有时间、持续写入、关闭及传输行为均未验证，待统一验证。
