# 提交变化通知契约

统一 gateway_settings 写入口在 SQLite/PostgreSQL 成功返回后发布租户 dirty 代数；失败、条件未命中和事务回滚不发布。来源采用 change_events::domain_for_source 显式映射，未知命名空间、用量日志、本机状态及 model_pricing 不触发通知。model_pricing 继续沿用既有 SSOT。

每个传输分别调用 subscribe，先订阅再读取初始快照。watch 合并积压事件；收到变化后重新读取授权快照、执行现有敏感与设备字段过滤并比较摘要，不把原始设置直接上传。upsert 等成功写入允许产生保守 dirty 提示；通知不表示可同步内容必然改变。通知仅存在于当前进程，启动时必须读取初始快照；不替代远端轮询、跨进程提交发现或持久队列。

两传输共用 apply_snapshot，在同步发布与失败回滚期间按租户抑制回声。without_echo 的同步闭包支持嵌套和异常退出，不能跨 await 使用；同线程其它租户及其它线程的正常提交不被抑制。后续领域直接执行事务时，应只在成功提交后调用 committed，不得在 SQL 更新钩子、预览或回滚中调用。

本轮按用户要求仅实现并审阅代码，未运行 Cargo、单元测试、其它测试或实机验证；未领取构建槽位。编译、提交后通知、失败无通知、租户隔离与嵌套抑制行为留待统一验证。
