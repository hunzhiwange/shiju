# 网关同步生命周期契约

每次主网关或 HTTP 运行时启动创建独立 `SyncLifecycle`，通过 Axum Extension 传给授权配置所有者，关闭时停止调度、取消自动任务并等待 worker 返回。桌面窗口不持有 worker。

配置所有者须在启动恢复已授权配置，以及启用配置时调用 `start`；传入真实数据库、完整授权目标、传输类型、锁内配置/凭据重读和内联上传回调。一个目标及传输只注册一次，异常退出不会静默创建重叠 worker。恢复先调用持久任务初始化，将未结束记录标为 Interrupted，不重放上传。禁用或清除配置先持共享业务锁发布，再调用并等待 `stop`；重启启用后重新注册。不得在回调中派生后台传输或持有旧凭据。

当前配置存储尚无授权目标枚举和自动上传选择入口；生命周期提供注册契约，由配置/API 领域所有者接线，不根据默认租户或扫描任意设置推断授权。网关启动尚不会自行恢复连接并执行自动上传。

本轮按用户要求仅代码审阅，未执行 Cargo、测试、实机或最终回归，未领取构建槽位。后续需验证启动恢复、重复注册、禁用清除、跨租户重启及关闭时提交/回滚等待。
