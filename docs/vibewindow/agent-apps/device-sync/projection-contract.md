# 同步提交后的派生刷新

`apply_snapshot` 在配置事务提交并结束技能发布后逐项等待 `ProjectionJob`，返回 `AppliedSnapshot`。投影失败只产生固定领域警告，不回滚已提交数据，不传播原始错误或敏感载荷。提交失败不会执行投影。

执行器必须持有同租户、同主机的同步锁并将 guard 借给入口，直到所有投影结束；不得用取消分支丢弃提交后的 future。物理资源锁的范围由现有所有者决定，避免在投影重入时重复持有同一资源锁。

执行器从本地授权和实际受影响领域构建任务，不能从远端 JSON 构建路径、凭据或权限。提示词使用 `prompt_job`，技能使用 `skill_job`，MCP 将真实 `McpCatalogStore::resync_apps` future 交给 `mcp_job`。供应商使用现有主机原生发布所有者构建 Providers 任务；不得只更新目录并声称原生投影成功。不得遗漏受影响领域或传入成功空操作。所有者报告部分失败或取消时必须映射为失败。

`retry_projections` 只接受警告中的领域，重新获取同步锁、重新授权并读取当前保存状态；成功后移除对应警告，失败或缺失任务继续保留。此路径不接受快照、导入闭包或远程下载，不重放导入。

本编号任务提供提交与投影编排、提示词/技能适配和 MCP 报告适配；未来执行器接线须提供供应商主机上下文和 MCP 授权目标，不能将本契约当作端到端验收证据。

按本轮指令未运行 Cargo、单元测试、实机测试或其它测试；未领取构建槽位，CARGO_TARGET_DIR 未设置。仅完成源码审阅，编译和行为均未验证，后续统一验证。
