## 入口与边界

`crates/vw-agent/src/device_sync/operation_lock.rs::run_with_sync_lock` 是 agent 的进程级共享入口。可信授权提供规范租户与执行主机 ID；空标识拒绝。锁键是两个独立字符串组成的元组，排除传输、方向、主体与连接，因此 WebDAV/S3、手动/自动和上传/下载在同租户同主机串行，不同作用域使用不同锁。弱引用注册表在领取时清理已失活条目，持锁者和等待者保持强引用。

等待锁通过 CancellationToken 可退出；锁与取消同时就绪时优先取消。获得锁后再次检查取消，再调用 reload 闭包。reload 必须从真实连接所有者重读当前配置、身份及绑定的凭据租约，返回 CurrentSyncConnection；不存在返回 None，失败直接返回错误。入口拒绝已删除或禁用配置，自动来源还要求 auto_sync=true。凭据材料不实现 Debug 或序列化。

operation 仅接收本次 reload 的材料，必须原地 await 完整导出/传输或应用/回退/投影/基线保存，不能启动脱离锁的后台工作，也不能捕获排队前的旧凭据。锁在闭包结束或 future 被丢弃时由 RAII 释放，错误同样释放。入口在开始 operation 前复查取消；开始后不按 token 强制丢弃操作，提交临界区的 too_late、回退和真实终态归操作所有者。

连接保存、删除、禁用和身份更新必须通过同模块 crate 内的 acquire_sync_lock 使用同一键；不得在已持锁时嵌套领取。它不读取连接，供这些配置变更路径使用。授权和隔离存储仍是调用者责任，锁本身不是权限校验或存储隔离机制。

## 后续接线与统一验证

任务3允许独立实施锁。当前 agent 没有同步生产调度、传输执行、连接保存与删除入口；本任务只注册协调模块，不声称这些路径已接通。任务13–15、17–19及后续手动/自动执行入口应按上述合同调用，不能另外创建每连接或每传输锁。实际凭据获取仍消费唯一凭据所有者，不新增秘密存储。

该锁只协调同一进程；不能作为多网关进程或远端多设备分布式锁。运行任务所有者必须保证客户端断线不会丢弃正在提交的 future，并在关闭时等待操作收尾；本模块不新增后台任务生命周期。

统一验证待覆盖：两传输和手动/自动同键互斥、投影期间持锁、不同租户或主机并发、排队取消及同时就绪取消、排队期间删除/禁用/换身份、自动开关关闭、reload/operation错误后释放、future丢弃后释放及注册表失活清理。本轮未新增测试代码，未运行任何测试和最终回归。
