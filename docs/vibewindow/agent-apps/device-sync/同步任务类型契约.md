# 同步任务共享类型

任务5交付 `vw_api_types::device_sync_task`，沿用任务3《同步契约》。连接种类复用任务4 `DeviceSyncTransport`，授权目标复用公开导出的 `DataManagementTarget`；没有添加存储、网络入口或服务器调度。

- `SyncRemoteInfo` 区分空远端、兼容和不兼容；读取失败必须返回结构化错误，不能假装空远端。
- `SyncStartRequest` 只接受目标、传输、方向、幂等键和远端前提；闭合反序列化拒绝客户端附加终态、进度、来源或警告。`expectedRemoteSnapshot` 缺省/null 表示未提供前提，`kind=empty` 才断言远端不存在。覆盖写入前由网关要求明确前提并复核 manifest 摘要/ETag，不能只比内容摘要。
- `SyncTaskStatus` 包含完整授权目标（项目作用域、主体、执行主机）、任务身份、manual/auto 来源、阶段、已传输/总字节数和状态。字节单调、总数限制、状态迁移和作用域授权由服务器落实，DTO 不执行这些策略。
- 终态为 succeeded/failed/cancelled/interrupted；`is_terminal` 提供统一判定。提交后投影失败、状态保存失败均保留成功事实并附独立警告；失败/重启中断也携带 committed 事实。提交临界区取消返回 too_late，不能谎报 cancelled。
- `SyncErrorCode` 使用闭合代码，覆盖空远端、不兼容、冲突、取消、完整性、回退等边界；没有原始错误文本、URL、远端载荷或凭据字段。不兼容原因可按格式/协议/数据版本细分。
