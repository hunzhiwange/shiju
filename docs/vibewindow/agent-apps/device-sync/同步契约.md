## 责任和执行主机合同

- api-types 唯一拥有公开 DTO；apps 的 `device_sync/` 负责协议、配置校验、归档、WebDAV/S3 传输，不反向依赖 agent。agent 的 `device_sync/` 持真实存储、凭据、快照应用/投影、共享锁、持久任务和自动调度。client 持 SDK，Iced 仅通过 SDK 操作。
- 所有动作含 test/remote 均先授权。租户来自可信上下文，principal 由服务端认证绑定，内容选择再绑定项目；连接存储隔离租户、授权主体、执行主机与传输连接。客户端不得提供数据库 namespace、SQL、文件根或秘密存储键。
- 本版只在已授权且在线的网关本机执行网络和文件动作。未知主机、离线主机、远端无执行通道分别明确拒绝，不回落桌面。Basic 管理认证或任意公司头不单独构成成员授权；现有启动/安装/账号权限不自动赋予同步权限。
- 资源根从可信主机策略取得；配置、秘密、同步开关、确认、基线、任务均为本机数据。内容严格消费任务2允许表，日志/用量/设备路径/连接/令牌双向排除；远端未知或敏感字段在写入前拒绝。不能将一般迁入过滤结果直接序列化成同步快照。

## 独立线格式与提交合同

| 项目 | 固定合同 | 当前可绑定程度 |
| --- | --- | --- |
| 标识 | format=`shiju-device-sync`，protocol_version=1 | 本领域独立协议，不沿用 CC format/version |
| 数据版本 | data_compat_version 由母任务18版本化共享快照唯一给出 | **未绑定，阻塞发布和应用**；缺失/未知版本拒绝，不猜兼容 |
| 命名空间 | `<remote_root>/<profile>/shiju-device-sync/v1/data-v<兼容版本>/`；默认 remote_root=`shiju-sync`、profile=`default` | 路径段逐段验证和编码；没有真实数据版本不得形成生产 key |
| 固定制品 | config.json、skills.zip、manifest.json | config.json 必须是母任务18类型化共享快照；skills.zip 来自授权资源清单；不接收任意文件名或整库 SQL |
| manifest | format、protocol_version、data_compat_version、device_name、created_at、artifacts、snapshot_id；artifacts 恰为前两制品，各含 sha256 与 size | 闭合 schema；设备名仅为规范化显示信息，不是主机身份或路径 |
| 内容身份 | 按制品名排序，将 `name:sha256` 以 `|` 连接后计算 SHA256，输出小写十六进制 snapshot_id | 保留来源 `sync_protocol.rs::compute_snapshot_id` 思想；制品大小仍须独立校验，manifest 原始字节摘要另作并发版本依据 |
| 上限 | manifest 1MiB、单制品512MiB、归档最多30000条目、总解压512MiB | 下载流逐段计数，超过即停；不能只信 Content-Length |
| 预算 | 传输基础300秒加制品字节/16KiB每秒；空闲120秒 | 后续传输实现有界取消和超时；本轮无运行证据 |

先上传两制品，全部成功后最后发布 manifest；任一步失败不得报告整份上传成功。固定 key 加本机互斥不构成远端分布式事务；中断或异机并发可能使旧 manifest 与新制品不匹配，下载必须明确报完整性/冲突错误，不应用半包。ETag 存在时核对，缺失时核对 manifest 摘要；HEAD 失败不是版本相同。远端不存在与未提供 expected_remote_snapshot 必须分型。

只按内容哈希判定是否变化，变化后整份传输，不引入分块 delta。技能归档保持排序及固定时间元数据，拒绝越根路径、绝对路径、父级穿越和符号链接逃逸，临时资源有失败清理责任。归档安全若由母任务18交付则复用其真实所有者，不能再造长期并存实现。

来源 `cc-switch/src-tauri/src/services/sync_protocol.rs` 的 format=`cc-switch-webdav-sync`、version=2、db兼容6及legacy5是历史事实。收到旧/未知格式明确不兼容，不自动导入、升级、写回旧目录；旧 SQL 只进入母任务18显式迁入链。

## 备份、应用与任务合同

母任务18必须交付同一作用域的版本化类型快照导出、资源允许清单、引用映射和差异预览、执行时版本核对、提交前回退点、应用、投影与恢复接口后，下载应用才可实现。应同时给出真实路径/符号、数据版本、SQLite/PostgreSQL支持边界及跨技能文件的失败语义；当前均不得用局部事务冒充。

下载顺序：授权→有界读取 manifest→校验格式/版本→下载并校验全部制品→闭合分类解码和引用映射预览→锁内复核本地/远端版本→建立回退点→领域应用→领域投影→记录成功基线。两端均变化返回结构化冲突，预览不是写权限。回退仅恢复本次拥有且版本仍匹配的对象，外部改动报告冲突；不得覆盖其它作用域或并发写入。回退失败保留提交事实和可恢复信息。

PortableExport 与 LocalRollback 分型；后者只在原授权主机受控保存，可含回退必要秘密，不进入 config.json/skills.zip 或下载句柄。数据提交后状态保存失败附 warning，不反转成功事实；投影失败单独报告，不能谎称未写入。

WebDAV/S3手动操作、清除配置和自动调度共用本地互斥边界，覆盖下载应用与投影；锁内重读配置和凭据，抑制下载引发自动回声。自动默认关闭，enabled/auto_sync 两开关、开启前确认、有界 dirty 队列、1秒防抖/10秒最长等待；由网关生命周期启动，无窗口仍工作。

启动绑定 request_id 幂等与完整作用域/参数，同键不同参数拒绝；queued→running→succeeded/failed/cancelled/interrupted，进度单调且含阶段及 manual/auto 来源。提交前可取消并清理；进入提交临界区报告 too_late，等待完成或回退后的真实终态。查询/取消再次授权；断线用 GET 恢复，重启中的任务转 interrupted，不自动重放。

## API保留入口与凭据更新

下表基路径 `/v1/agent-apps/device-sync`；transport 仅 webdav/s3，均未由本任务注册。

| 方法和相对路径 | 合同 |
| --- | --- |
| GET/PUT `/{transport}/config` | 脱敏读取；显式 SecretUpdate Keep/Replace/Clear，不靠空串推断；GET 仅 secret_present、脱敏 last_status、active_task_id |
| DELETE `/webdav/config` | 仅清除本机 WebDAV 连接与自有秘密，不删远端；来源没有S3清除命令，不额外扩展 |
| POST `/{transport}/test` | 验证草稿与作用域凭据绑定，不保存；同样执行网络授权 |
| GET `/{transport}/remote` | 已保存连接的有界预览，明确 empty/compatible/incompatible |
| POST `/{transport}/upload`、`/{transport}/download` | request_id、expected_remote_snapshot；202 返回持久任务，执行时复核预览版本 |
| GET/DELETE `/tasks/{id}` | 原作用域的查询/取消；不可仅凭任务ID操作 |

Keep 只适用于同一作用域、同一连接身份已有秘密；改端点/用户名或桶/access key 等身份后不能继承旧秘密。Replace/Clear 在执行主机经凭据所有者提交，与连接记录变更协调失败恢复。草稿测试不允许探测其它连接秘密；错误、URL、日志和任务状态不回传密码、签名、令牌或原始网络载荷。凭据所有者尚缺连接材料类型和入口，这里只固定消费要求，不扩大 AccountCredential 枚举或补建秘密存储。
