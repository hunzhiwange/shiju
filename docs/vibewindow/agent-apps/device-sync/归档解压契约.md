# 同步归档解压

任务11–12代码交付，尚未验证；按本轮指令未运行 Cargo、单元测试、实机测试或其它测试，未领取 Cargo 槽位。

`device_sync::archive_extract::extract_skills_archive(&[u8])` 接收已经通过 manifest 完整性校验的同一份不可变 skills.zip 字节，返回拥有隔离临时目录的 `TempDir`。调用者持有 guard 至预览/应用结束，不得在此之前公开或修改 staging；本接口不写配置库或正式技能目录，不提供恢复、授权或完整性校验证明。

拒绝绝对路径、空组件、`.`、`..`、反斜杠、冒号、NUL、控制字符、尾随空格/点、非 UTF-8 名称、所有链接及特殊文件。重复目录也属于重复条目；允许显式目录位于其子文件之后。每个路径前缀按 Unicode 小写映射检测大小写冲突，底层 create-new/create-dir 同时拒绝当前文件系统的别名和 Unicode 规范化碰撞；不静默跳过危险条目。暂不宣称完整 Unicode case-fold 等价检测覆盖所有文件系统。

中央目录按原始记录计数，拒绝 ZIP 库按名称合并后隐藏的重复项；目录与文件均计入 30,000 条目预算。文件逐块读取时同时约束实际总展开量和单项声明长度，超出预算的探测字节不会写入 staging；读至 EOF 后拒绝实际长度不足。声明为空的目录也读取至 EOF，以检查隐藏载荷和 CRC。

压缩输入和展开文件总量分别上限 512 MiB，最多 30,000 条目；空 ZIP 合法，表示无技能。输出文件使用新建语义，不继承归档权限或创建系统链接。任何解析、CRC、冲突、预算或 I/O 错误均返回失败，由 guard 清理部分输出。

后续统一验证需覆盖正常与空归档、绝对/父目录路径、链接逃逸、重复条目、父级大小写冲突、文件目录冲突、macOS Unicode 别名、损坏内容、目录 CRC、伪造长度、原始重复条目、30,000/30,001 条目及 512 MiB 边界预算，并确认外部哨兵未变。本轮没有行为通过证据。
