# 选定配置和技能的共享快照

任务13新增母任务18所有的数据类型 `vw_agent_apps::data_management::shared_snapshot::SharedSnapshot`，其 `DATA_COMPAT_VERSION = 1` 是本次新格式的版本，由数据管理所有者定义，不复用本机回退或旧库版本。`agent_apps::shared_snapshot::capture_shared_snapshot` 读取现有 gateway_settings，不创建新数据库、设置表或本机归档。设备同步入口为 `device_sync::export::export_shared_snapshot`，返回精确 config.json 和 skills.zip 字节及摘要；源记录摘要仅保留本机，不序列化到制品。

调用者必须在可信执行主机授权 project、principal、host 和所有选定对象，确认选定自由文本与资源允许出站，在同步操作锁内调用。选择不是可反序列化的网络 DTO；空列表表示不选，不自动发现或扩大到整个类别。上限为10000个对象；缺失、非法、重复或无法解析的对象直接失败，不伪造空内容。当前为 macOS 原生接口，未提供其它平台的降级实现。

捕获先对已有技能 SSOT 目录获取共享 flock（忙时失败），与技能安装、更新、卸载现有排他根锁协调，然后在 SQLite 单个只读事务或 PostgreSQL Repeatable Read 只读事务内读取所选记录及资源。锁覆盖 ZIP 完成及事务结束；检查根目录身份，拒绝捕获期间替换根。读路径不初始化数据库或表。合作领域写入按现有事务与技能物理根锁执行；外部程序绕过 flock 任意写文件不在此一致性保证内。

字段策略属于数据管理的闭合结构：供应商只提取逻辑身份、应用、名称及已有顶层 protocol/model；应用专属不透明配置中的模型不猜测、不透传，缺少顶层字段显式为 null。MCP 本次选择当前项目目录元数据，只导出 id/name/description/tags；连接及展示 URL 均不导出。提示词只导出明确选择的正文及名称描述，不导出激活、时间、修订或主机路径。偏好使用现有规范化函数，仅导出 principal 的应用顺序和可见应用。仓库引用经过现有校验，不导出 enabled。用量、价格和连接配置没有出站入口。所有文本的内容确认由授权调用者承担，字段白名单不宣称能扫描任意秘密。

技能必须同时属于该项目/主机的安装记录与显式选择，并匹配可信 SSOT 根。只打包选定一级目录；拒绝符号链接、隐藏条目及 credentials/secrets/logs/cache/backups 资源，复用既有归档大小和条目上限。每个资源记录含逻辑目录和现有技能所有者计算的内容摘要，不含 source 路径或安装实例。新增 `pack_selected_skills_archive` 保留原整根打包调用行为，但同步入口仅调用选定资源入口。

组合四槽保持 None、空集合与空提示词 ID 的语义，非空引用必须指向本次已选对象。技能不透传 installation_id；使用现有组合技能解析合同，由授权主机提供不透明引用到 SSOT 目录的映射，并复核该目录已经选中。缺映射拒绝导出，不按名称或安装实例推断。该映射不是远端可以提供的权限或路径。

本轮仅实现并人工阅读差异。按最新指令未运行任何 Cargo 命令、脚本、测试、实机检查或最终回归；没有编译或行为通过证据，未领取构建槽位，缓存目录不适用。后续统一验证需覆盖 SQLite/PostgreSQL 同时点捕获、两组匿名设备、嵌套秘密排除、精确目录选择、符号链接及私有资源拒绝、组合引用映射、缺失/重复对象、并发技能写入与根替换。
