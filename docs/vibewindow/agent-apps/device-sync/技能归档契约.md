# 确定性技能归档

任务10提供 `device_sync::archive_pack::pack_skills_archive(root)`，返回绑定同一份 ZIP 字节的 `PackedSkillsArchive { bytes, artifact }`。artifact 为 manifest 的 `SyncArtifact`，含小写 SHA256 和完整 ZIP 字节长度；上传方必须使用返回的原始字节。

调用方先授权，并传入专用于可迁移技能内容的根目录。函数不发现默认路径，不读取 ~/.cc-switch，不查询凭据、数据库或设备配置；不能将用户主目录或混合秘密的目录作为技能根。目录中内容的分类归调用方所有，函数不凭文件名猜测秘密。捕获期间调用方须保持内容稳定；本入口不提供跨文件事务快照。

文件条目按规范根相对 UTF-8 路径排序，统一 `/`，固定 ZIP 时间、0644 权限与 Stored 压缩方式；mtime、枚举顺序和原权限不进入摘要。空目录不写入 ZIP，空根产生空 ZIP。反斜杠、冒号、控制字符、超1024字节名称和非UTF-8名称明确拒绝。相同内容和路径布局产生相同摘要，不承诺不同 ZIP 库版本间字节兼容。

根内符号链接按目标规范路径打包，不保留别名；目录规范路径去重可终止返回祖先的环路；无法解析的链接（含纯链接环）、根外链接明确拒绝。硬链接按设备号和 inode 去重，保留字典序最早的路径；不同硬链接布局不承诺相同摘要。仅支持普通文件和目录。

Unix 上根目录锚定为句柄，规范路径各组件用 openat/O_NOFOLLOW 打开，拒绝捕获期间替换为符号链接的路径；非 Unix 平台明确拒绝，不降级为不安全读取。目录枚举仍使用路径，因此并发变动可能导致捕获失败或内容变化；此实现不能替代调用方的快照一致性锁。

最多枚举10000个目录项；使用64KiB读取缓冲区，内容上限为512MiB扣除固定头部预算（10000×1024字节），最终ZIP也不得超过512MiB。完整结果保存在内存中，错误时不返回部分归档，无文件写入副作用。

本轮仅实现与源码审阅，未编译、未运行任何测试、未进行实机或最终回归；未领取 Cargo 槽位，CARGO_TARGET_DIR 未设置。统一验证待覆盖顺序/mtime稳定性、ZIP元数据、空目录、根内别名与祖先环、硬链接去重、根外/断链拒绝、路径替换和大小边界。无通过证据。
