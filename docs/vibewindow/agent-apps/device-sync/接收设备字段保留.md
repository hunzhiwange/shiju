# 接收配置投影合同

任务14：`device_sync/import.rs` 复用数据管理所有者 `agent_apps/shared_snapshot_import.rs` 的 `preview_shared_snapshot` / `apply_shared_snapshot`。不建立第二存储，不接受远端 SQL、namespace 或目标路径。

调用者须先校验制品摘要及授权作用域，并从可信本机上下文提供 SnapshotSelection（包括已解析、已授权且仍存在的目标引用映射）。预览闭合解码 SharedSnapshot，拒绝未知字段、版本错误、重复身份及越权对象；注入连接地址、绝对路径、秘密或安装字段会整包失败。未选择的本地记录不删除。预览含秘密 preimage，不可序列化、展示或记录。

接收连接类记录须先在本机创建。供应商只更新名称，保留本机秘密、端点、原生应用配置；协议或模型不一致明确要求本机配置，避免跨原生格式伪投影。MCP 只合并目录元数据，保留 connection、bindings 和 connection revision；不产生连接或部署。规则仅合并非激活条目的正文及说明，保留创建时间和激活信息；活跃规则须先停用。仓库保留 enabled 等本机授权，只改已配置仓库分支。用户偏好只作用于 principal 域，主机偏好不写入。组合按可信本机映射转换技能安装标识，保留本机选择和应用结果，不执行组合；版本仅在内容变化时递增。

技能摘要和逻辑目录经过形态与选择检查，但本入口仅处理配置，绝不将远端 JSON 变成安装事实，不写技能文件或安装表。资源摘要验证、物化、与配置的跨资源失败回退属于任务15；调用者须先建立回退点并按其资源事务编排，不能把本入口成功当成技能安装成功。新增本机对象尚需领域创建流程，缺少本机对象明确失败，不伪造 configured 状态。

预览不写库。应用在 SQLite Immediate 或 PostgreSQL 行锁事务内先复核全部 preimage，再提交变更；失败回滚数据库事务。作用域绑定 tenant/project/principal/host。相同配置重放不递增业务版本，不写未变记录。此入口不激活原生文件或进程，原生激活仍由领域所有者处理。
