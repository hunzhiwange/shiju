## 分类规则

- 共享字段：只允许下表明确列出的语义，须经过领域校验和授权选择；现有 DTO 可序列化不代表可整体同步。
- 设备字段：路径、连接地址、安装/激活事实、主机配置均留在本设备。出站不包含，入站不能覆盖、清空或重置，包括恶意 null、空串、空集合与删除标记。
- 敏感字段：账号、令牌、密钥、凭据引用及不透明配置默认不出站，入站拒绝。敏感分类优先于共享分类，不靠字段名黑名单判断安全。
- 未知字段：出站排除并返回脱敏字段路径/原因；入站闭合 schema 拒绝未知或禁用字段，整个应用前终止。不得忽略后再将原始 JSON 传给存储或投影。

## 敏感嵌套字段与资源

供应商 headers 中的 Authorization、Cookie、自定义认证头，body 任意深度对象/数组里的 token/key/password，MCP env/args 中的内联认证、McpCredentialRef 的 service/account_id，URL userinfo/query 中的签名和凭据都不能出站。替换名称、大小写或嵌套层级不能绕过：不透明映射整体排除，只有已定义类型的叶子可进入快照。不能用“掩码字符串”写回秘密，也不能从远端解析凭据引用以读取本机秘密。

规则正文、技能文件、名称与描述也可能由用户写入敏感信息。字段允许表不是通用秘密扫描器：未经明确选择及内容确认的正文/资源不进入首次同步；不承诺自动识别任意秘密。技能资源禁止打包整个工作区、账号文件、.env、凭据目录、日志、缓存及本机备份；资源允许清单由技能所有者与母任务18提供，缺失时拒绝打包。根内相对路径校验、拒绝绝对路径/父级穿越/符号链接逃逸以及归档数量/大小限制由后续归档任务落实。

## 同步连接与接收应用

WebDAV/S3 整个连接配置均为设备数据：endpoint/base URL、bucket、region、remote_root/profile、用户名、密码、access key/secret/session token、凭据引用、enabled/auto_sync、确认状态、last_status、成功基线、active_task_id 和任务记录不进入 config.json 或 skills.zip。只允许 manifest 按协议携带经规范化的设备显示名，不接受它作为主机授权或路径。错误、预览和日志只返回脱敏摘要。

接收顺序为身份授权、格式/版本及制品完整性校验、同一分类策略的闭合解码、引用映射与差异预览、执行时版本复核、建立回退点、通过领域接口应用和投影。远端不能指定租户/principal/host/namespace/数据库/文件根；作用域来自可信请求上下文。未知或敏感注入在任何写入前拒绝，保留所有本地设备和秘密字段；缺少连接/凭据报告需要本机配置，不能伪造 configured 成功。接收共享记录不自动获得联网、启动命令、安装或激活权限。
