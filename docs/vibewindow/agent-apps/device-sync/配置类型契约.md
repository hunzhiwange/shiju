# 同步配置共享类型（任务4）

公开入口：`vw_api_types::device_sync_config`。传输枚举仅接受 `webdav`、`s3`，未知值拒绝。所有配置对象拒绝未知字段，采用 snake_case JSON 字段。

`WebDavSyncConfig` 与 `S3SyncConfig` 是读取连接配置的模型，仅以 `secret_present` 表示秘密存在，不含密码或 secret access key。状态与任务信息由后续状态任务定义的响应外壳承接。本任务不提供路由、存储或传输实现。

写入分别使用 `UpdateWebDavSyncConfigRequest` 与 `UpdateS3SyncConfigRequest`，不接受 `secret_present`。必须提供 `secret`，格式为 `{"action":"keep"}`、`{"action":"replace","value":"…"}` 或 `{"action":"clear"}`；省略、null、未知 action 或附加字段均拒绝。空 value 仍为 Replace，由连接校验层决定是否允许，不能转成 Keep。写请求序列化必须携带 Replace 的秘密才能发送给授权主机，禁止复用为 GET 响应或日志。其 Debug 输出整体脱敏，秘密更新的 Debug 不输出 value。

S3 endpoint 为可空字段，None/null（或省略）选择 AWS 默认端点；自定义端点为字符串。access_key_id 为连接身份，不是 secret access key。当前沿用来源的长期凭据范围，不新增 session token 能力。

执行主机负责 URL/连接参数校验（禁止 URL 内嵌凭据）、同作用域及同连接身份的 Keep 核对、自动同步初始关闭及启用确认、与凭据所有者协调提交。DTO 不声明这些生产行为已实现，也不建立第二秘密存储。

本轮仅实现及源码差异审阅；依用户指令未运行 Cargo、测试、实机验证或最终回归，未领取构建槽位，CARGO_TARGET_DIR 未设置。后续统一验证需覆盖读模型无秘密、三种更新意图往返、未知传输/字段拒绝及 Debug 脱敏。
