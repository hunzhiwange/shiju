## 接口

- `McpConnectionDefinition` 区分 `stdio`、`streamable_http`、`sse`，各传输携带对应字段。env 和 headers 支持非秘密字面量或 `McpCredentialRef`，由执行端按授权解析账号引用。原生配置别名和内容校验由任务 4 处理。
- `McpCatalogRecord` 是公开投影，携带租户或项目作用域、记录修订和独立的连接修订。公开记录只投影传输种类与安全元数据，完整连接定义留在写入与执行边界。
- `McpCliBinding` 使用现有应用与安装实例 ID，分开表达期望启用和原生观察。`McpRuntimeSelection` 绑定项目，`McpAcpMount` 绑定会话。三者分别引用目录记录修订。
- `McpAppCapability` 表达逐传输支持性。`McpDistributionResult` 分开表达期望是否提交与实际分发结果。`McpConnectionCheckResult` 关联任务 ID、代次与逐服务连接修订。批次部分成功、逐项未验证和不支持各有独立状态。诊断使用封闭的 `McpFailureCode`。
- `mcp::McpInspectResponse` 及现有网关、SDK 和桌面调用路径保持原样。
