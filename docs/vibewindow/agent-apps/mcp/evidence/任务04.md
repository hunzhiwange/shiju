## 生产入口

- `mcp::validation::parse_native` 使用任务 3 的 DTO 反序列化通用原生 JSON 定义。缺传输默认 stdio，只有 URL 时按 HTTP 处理，兼容 HTTP 别名和 `http_headers`。参数原样保留。错误仅包含固定字段名，不回显输入。
- `validate_connection` 同时用于原生解析结果和直接构造的受管 DTO，验证 stdio 字段、完整 HTTP(S) URL、HTTP 头语法与大小写不敏感的重复键，拒绝 env 或头部的遮罩占位符。凭据引用只校验形状，实际解析留给执行端。
- `validate_new_name` 去除首尾空白，拒绝空名、内部空白、控制字符和授权作用域内的精确重名。调用者必须在条件写中原子检查唯一性，以处理并发提交。
- `validate_resolved_command` 对授权目标主机解析出的绝对程序路径只读取文件元数据，检查常规文件和执行位。校验不查找环境 PATH，也不运行命令。聚焦测试用真实临时文件和 loopback 监听端检查进程、网络均未发生副作用。目录持久化及其唯一性约束归任务 6，受管原生写入归任务 10。
