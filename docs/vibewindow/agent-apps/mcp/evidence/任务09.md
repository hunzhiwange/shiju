## 前置与实现

- 任务 08 提交 `3642f743e` 已交付作用域目录删除、修订及撤销目标。对固定来源 `ca58c0313360eae7c851fbd7553c1614c7af03e7` 的 `mcpDraft.ts`、`mcp_connectivity.rs` 分别以 `git show | cmp` 校验仓内快照，均退出 0。核对了底座的 `authorize_scoped`、`LocalReadEnvironment`、`ProviderTransactions` 和 `AuthAccountStore`。
- `McpCatalogStore::credential_masks` 按作用域和目录修订只返回遮罩。更新时，env 区分大小写，HTTP/SSE 头忽略大小写，遮罩还原同字段的原引用。未知遮罩拒绝，原有省略字段保留引用的语义继续生效。
- 创建、更新和执行校验账号 ID 的格式。目录拒绝标准认证头、常见密钥命名的字段和查询参数中的字面秘密，也拒绝带用户信息的 URL。命令、参数和普通字面量仍遵循非秘密输入合同，历史条目没有迁移。
- `McpCatalogStore::resolve_for_execution` 读取指定修订，执行方须依据可信主机策略对该目的地和精确引用逐项授权。解析前拒绝缺少授权及租户、主机、服务不匹配的引用。复用母任务 6 的 `AuthAccountStore::codex_access_token` 和 `AuthAccountStore::xai_access_token`。缺失作用域账号拒绝，未提供适用令牌解析器的服务返回 `CredentialUnavailable`。HTTP 的 Authorization 引用投影为 Bearer 头，解析出的头值标记敏感。执行配置没有序列化或 Debug 实现，错误只返回稳定码。
- 本任务的生产入口是目录编辑投影和主机执行配置解析。HTTP 管理路由、实际 MCP 握手、原生文件写入和运行时调用在各自后续任务中接入。
