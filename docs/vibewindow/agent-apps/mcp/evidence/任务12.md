## 生产入口

- `vw_agent_apps::mcp::adapters::codex::apply` 固定选择获授权 Codex 目录下的 `config.toml`，经 `NativeFile::commit` 和 `ProviderTransactions::commit_checked` 发布。新增遇同名用户项返回冲突。更新、禁用及删除由调用者复核绑定归属和修订。禁用和删除共享单项移除，重复移除幂等。
- 投影支持 stdio 的 `command`、`args`、`cwd`、`env`，以及 Streamable HTTP 的 `url`、`http_headers`。沿用既有 TOML 编辑器保留其他段落、注释与用户条目。传输变更会清理旧的受管字段。未解析的凭据引用返回 `UnresolvedCredential`。
- `codex::read` 回读标准 `mcp_servers` 和旧 `mcp.servers`，同名以标准段为准。兼容旧 HTTP 头字段并保留 `enabled`。旧段保持只读。有无法由连接 DTO 表达的扩展字段时返回逐项错误，更新也拒绝保留此类设置，避免把旧目标的动态凭据带到新连接。
- 冻结转换器将 SSE 写成与 Streamable HTTP 相同的 TOML。适配器返回 `UnsupportedTransport`，避免在回读时改变传输语义。
