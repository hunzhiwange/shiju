## 生产入口

- `mcp::adapters::grokbuild::{apply, read}` 在 macOS 注册。`apply` 只编辑 `[mcp_servers]` 的目标项，保留模型配置、注释及其他服务。新增时拒绝同名冲突，更新和撤销使用调用方已核实的受管项，提交前复核目录修订和所有权。禁用与删除共用幂等移除。
- Stdio 写入 `command`、`args`、`env`、`cwd`。Streamable HTTP 写入 `url` 和 `headers`，反向读取兼容 `http_headers`。写入省略 `type`。上游会把 SSE 写为同一远程形态，无法还原传输，适配器返回 `UnsupportedTransport`。
- `read` 返回主机私有的逐项导入结果。超出目录 DTO 可表达范围的定义逐项报错，坏 TOML 或坏容器返回固定写入错误。导入调用方仍需应用目录凭据策略。测试使用临时 HOME 和事务存储，配置中的命令与 URL 仅用于编解码。
