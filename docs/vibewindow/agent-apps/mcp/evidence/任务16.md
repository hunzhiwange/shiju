## 投影与回读

- macOS 入口 `mcp::adapters::hermes::{file, ServerPatch, read_servers}` 复用现有 `lib.rs` 的 MCP 导出。`file` 只接受 Hermes 写锁并选择已授权目录的 `config.yaml`。默认路径为 `~/.hermes/config.yaml`，路径所有者处理 `HERMES_HOME` 和配置覆盖。
- 只编辑 `mcp_servers` 的目标项。插入拒绝同名现有项。更新替换连接字段并保留原生选项和启用状态。禁用使用原生 `enabled: false` 保留条目，删除可重试。复用 `NativeFile` 的快照检查、供应商事务与私有文件权限，以及 YAML 编辑器的局部替换和整文档等价校验。含歧义的引用、非空流式服务映射等布局走显式写入错误。
- stdio 回读 command、args、env；远程连接回读 URL 与 headers。CC Switch 冻结转换把两种远程格式写成同形，并将所有 URL 回读为 SSE。为保证等价回读，本实现遵循 Hermes 原生规则，Streamable HTTP 省略 `transport`，SSE 写明 `transport: sse`。未知传输、无法投影的 `cwd` 和未解析的凭据分别返回结构化错误。 [Hermes MCP 配置参考](https://hermes-agent.nousresearch.com/docs/reference/mcp-config-reference)
