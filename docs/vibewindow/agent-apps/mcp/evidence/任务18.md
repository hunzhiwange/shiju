- `mcp::adapters::mcode::{read, apply}` 只接受 Mcode 的执行主机写锁，编辑同目录的 `mcp.json` 中的 `mcpServers`。默认目录为 `~/.minimax`，沿用路径所有者的 `MINIMAX_DATA_DIR`、`MAVIS_DATA_DIR` 优先级。

- 新增拒绝同名条目。更新只替换连接字段并启用条目，保留 timeout 等原生选项。禁用移除条目，后续删除可重试。文件先按 `NativeFile` 提交，目录拒绝后用同一应用锁补偿，恢复原字节或移除本次创建的文件。补偿只对刚发布的快照生效，遇到外部改动时保留新内容并返回结构化冲突。
