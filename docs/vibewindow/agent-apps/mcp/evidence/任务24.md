在 macOS 27.0（26A428）、arm64 上验证。任务 23 已由 `b0c5ec2fd` 交付。用 `git show | cmp` 对比冻结源码与 CC Switch 4.0.25 的 `ca58c0313360eae7c851fbd7553c1614c7af03e7:src-tauri/src/services/mcp.rs`，退出码 0。核对了 `authorize_provider_editor`、`LocalReadEnvironment`、`AppInstallation`、`ProviderTransactions` 和 `McpCatalogStore::resolve_for_execution`。

## 实现

- `McpCatalogStore::set_app_binding` 校验目标与可信主机的安装观察、事务所属主机和 Claude 账号租约。网关调用者负责授权目录作用域及安装，重试时解析同一个目标的原生 profile。HTTP 路由接线由任务 35、36 负责。
- 先以目录修订保存期望启停，再解析启用所需的凭据并写入原生配置。结果分别返回 `desired_committed` 与 `native_outcome`，失败可用返回的修订重试。目录条件写入与原生事务预检共同拦截旧请求。适配器沿用供应商写锁及原生文件事务，处理新增、更新、启停和移除。
- `NativeMcpWrite::apply` 派发至现有的十二种原生适配器。Hermes、Pi 和 OpenCode 在同一原生事务中更新连接并启用。Claude Desktop 和 OpenClaw 显式拒绝写入。首次绑定的同名外部条目返回冲突，已有归属的绑定才允许更新或撤销。
- `McpCatalogStore::revoke_app_binding` 消费删除记录中保留的目标。失败结果保存在删除记录内，成功结果为终态。撤销只使用删除时保存的绑定和目标。
