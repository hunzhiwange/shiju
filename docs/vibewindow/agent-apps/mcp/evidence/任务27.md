`McpCatalogStore::select_for_runtime` 按授权项目保存目录作用域、记录 ID 和精确修订号。同租户目录及当前项目目录可入选，其他项目或租户被拒绝。同名不同目录作用域发生冲突，同一修订可重试。运行时从当前请求的项目上下文取项目标识，并在项目注册表核对工作目录。配置加载复用 `merge_runtime_mcp_servers`，原生工具注册及代理默认能力调用 `load_resolved_runtime_mcp_config_from`，通过原有连接池和 `tools/list` 发现工具。

既有优先级由项目 ACP 声明、全局 ACP 声明回退、全局代理 MCP 配置和插件合并规则决定。受管选择遇到已合并的同名服务器时报告冲突，管理覆盖与会话允许列表在合并后应用。CLI 分发绑定与原生运行时选择各自存储，ACP 配置继续使用独立入口。

三类传输共享目录修订检查与执行配置转换。stdio 工作目录在加载时解析，在启动前复查。项目选择缺少执行主机对精确凭据引用的授权，因此包含凭据引用的记录返回 `PermissionDenied`。旧工具的主动撤销由任务 28 负责。
