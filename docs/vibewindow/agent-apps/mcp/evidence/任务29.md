识矩入站 ACP 会话通过现有 `shiju/session/set_mounts` 替换挂载。可选 `mcpCatalog` 按目录作用域、记录 ID 与精确修订引用管理目录。已有顶层 `sessionId` 和 `expectedRevision` 决定会话归属与挂载修订。服务端使用已验证的会话租户和项目解析选择，拒绝跨项目、跨租户、重复项和缺少执行凭据授权的条目。旧请求可省略 `mcpCatalog`，其行为等同空数组。

`resolve_mounts` 复用目录存储与本机执行配置投影。`MountRecord` 保存受管引用，恢复时重新解析并丢弃失效修订。`AcpMountLeases` 在会话已有连接池中校验当前目录修订与调用会话。工具刷新移除撤销来源，后续提示也从初始快照剔除旧工具。原生运行时受管选择、CLI 绑定和入站 ACP 选择独立。标准 `mcpServers` 的传输配置仍在请求内使用。
