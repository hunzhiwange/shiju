`POST /v1/agent-apps/mcp` 由 `agent_apps::router` 挂载到 Basic 管理入口与 bootstrap skey 客户端入口。请求 DTO 为 `McpCreateRequest`，要求 `targetHostId`、`id` 和 `connection`，接受 `projectId`、`name`、`description`、`homepage`、`documentation` 和 `tags`。租户由网关认证后的上下文提供。访问策略在租户和可信主机的成员授权中检查 `mcp_catalog_write` 或 `mcp_catalog_write_projects` 中的具体项目。缺省策略拒绝写入，项目授权仅适用于列出的项目。

`create_catalog_record` 调用 `McpCatalogStore::create` 验证定义并原子保存到租户或项目命名空间。返回 `201` 和公开的 `McpCatalogRecord`。同一作用域内规范化后的 ID 重复返回 `409 conflict`，非法定义返回 `400 invalid_definition`，存储错误返回 `503 storage_unavailable`。响应沿用目录路由的 `Cache-Control: no-store`，仅返回公开投影。写入只登记期望定义，凭据引用的授权与解析仍由执行入口处理。
