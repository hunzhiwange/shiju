## 接口与边界

- `PUT /v1/agent-apps/mcp/{id}/bindings`：`target`（`appId`、`installationId`、`targetHostId`）、`expectedRevision`、`enabled`、可选 `projectId`。
- `POST /v1/agent-apps/mcp/bulk`：相同目标、`enabled`、`records`（ID/修订数组）、可选 `projectId`；一次 1–256 项。
- 两者返回 `McpDistributionResult`，逐项区分期望提交与原生结果，保留部分失败。请求拒绝未知字段，不接受客户端租户或路径。
- 入口 `mcp_management_bindings::{bind,bulk}` 合入现有 `mcp_management_read::router`，由既有管理路由同时覆盖 Basic 和 bootstrap skey，无需重复注册 bootstrap。
- 先执行目录租户/项目/成员/主机写权限与 provider 写权限校验，然后重新发现可信安装；真实写入复用 `McpCatalogStore::set_app_bindings`、`McpBindingTarget` 和 `ProviderTransactions`，不新增存储或文件写入通道。
- 凭据引用通过底座 `authorize_auth_binding` 按服务授权，使用执行主机凭据根和主体调用已有解析器；不向响应暴露原始连接、凭据或路径。缺少授权则由解析器拒绝。
- 当前绑定没有 Claude 账号/profile 标识，明确返回 `credential_unavailable`，不猜默认账号。非 macOS 明确返回不支持。本任务聚焦 Codex，不声称其它应用实机通过。
