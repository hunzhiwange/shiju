## 入口与边界

`POST /v1/agent-apps/mcp/import` 已接入 `mcp_management_read::router`，复用 `agent_apps::router` 的 Basic 与 bootstrap skey 认证、成员/租户/项目授权和可信执行主机解析；bootstrap 无需重复注册。实现位于 `mcp_management_import::import` / `import_source`，独立测试在 `mcp_management_import_tests`。

请求示意为 `{ "sources": [{ "target": { "appId": "codex", "installationId": "发现得到的ID", "targetHostId": "host" } }] }`，一次1–64个来源。顶层可选 `projectId`，省略则写入租户目录；`sources[].accountId` 仅Claude必填，指向受管官方账号，其他应用不得设置。请求、来源和目标拒绝未知字段，不接收客户端路径或租户覆盖。

响应顶层为 `sources` 数组，每个来源含 `target`；成功读取时带 `entries`。每项含 `id` 和 `status`，成功状态为 `added/merged/unchanged`，并带 `record: { id, revision }`；失败状态为 `failed` 并带封闭 `code`（如 `conflict/invalid_definition`）。非法原生名称的 `id` 为null。整个来源失败返回 `code` 并省略 `entries`，HTTP200保留逐项结果。只有记录引用与封闭错误码，不返回连接定义、秘密、原始解析错误或主机路径。
