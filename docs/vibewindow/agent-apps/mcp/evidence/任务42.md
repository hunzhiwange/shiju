类型对应当前处理器的真实 JSON 合同；由于导入、绑定、批量和重同步输入原本是网关局部类型，SDK 模块公开等价 wire DTO，不依赖 vw-agent 或业务包。复用 API 类型中的应用/安装/项目身份、记录修订、分发结果、失败码和底座任务引用。导入保留来源级失败及 added/merged/unchanged/failed 逐项结果；分发保留期望提交状态与原生事务结果，HTTP200不等同于原生成功。重同步返回已有任务引用，queued不等同于执行成功；使用既有 `agent_apps_operation_authorized` / `agent_apps_operation_cancel_authorized`，以相同主机、成员令牌查询或取消原任务，不建立第二调度器。既有通用任务进度类型不呈现MCP扩展的逐目标报告，本任务仅提供提交返回的底座任务引用。

请求沿用 GatewayClient 的 `dynamic_host_client`（禁止重试/重定向）、`apply_request_context`、skey与租户头；独立成员令牌使用敏感 `x-agent-apps-token` 头。错误沿用 `AgentAppsSettingsError` 的 Transport / Http（状态码与 JSON/文本体）/ Decode。记录 ID 为单个 URL 路径段，空 ID、点路径直接拒绝。SDK不接收原生路径、不解析账号凭据、不本机回退；Wasm明确拒绝要求原生传输的写入。
