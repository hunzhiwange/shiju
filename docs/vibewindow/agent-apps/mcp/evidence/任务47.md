# 任务47：桌面导入确认

## 实现与边界

MCP 设置页提供“从原生应用导入”按钮，进入 `system_settings_mcp_import::panel`。状态和生产请求集中在 `message/settings/mcp_management_import.rs`，消息与状态由既有父模块注册；独立测试使用 `cc_mcp_t47_` 前缀。

原生来源仅接受应用发现结果中当前网关、租户、主机、凭据代次对应的 macOS 安装实例。没有配置文件路径输入或本机文件回退；Claude 使用受管官方账号 ID 引用，由目标执行端解析。Claude Desktop、OpenClaw 显式不支持。SDK `mcp_management_native` 读取目标主机脱敏预览，确认后 `mcp_management_import` 导入当前来源全部定义到租户目录。导入 API 只写目录，不改写原生文件，不连接或启用服务。

**预览限制**：现有 `McpNativePreview` 只枚举目录已有 ID 与原生文件的对比状态，不枚举所有新项，也没有足够信息判断定义冲突。因此界面明确说明“仅对比已有目录 ID；新项、定义差异与冲突由执行端在导入时判定”，并说明确认时重新读取，预览不是文件快照。没有把“同名”伪称为已导入，也没有将预览当成无冲突证明。服务端逐项结果展示新增、合并、已导入无需变更、冲突和失败；来源失败与不完整/目标不匹配响应均显式展示。冲突不会覆盖已有定义。

“粘贴深链草稿”调用 Iced 本机剪贴板读取，接收正式 `McpCreateRequest` 的已解码 JSON，限制256 KiB。真实调用链是按钮→`Paste`→剪贴板 Task→`Pasted`→待确认弹窗→`Confirm`→SDK `mcp_management_create`。这不是 URI 解码器：系统深链路由尚未交付，仍由母任务20接收和解析；不声称支持直接粘贴上游链接或自动导入多资源。草稿主机必须匹配当前连接，确认界面展示 ID、名称、传输与租户/项目作用域，隐藏连接参数和凭据值并提示命令、内网和环境变量风险。同名创建明确报告冲突，仅创建定义、不自动分发或启用。

取消和关闭仅丢弃待确认状态，不发写请求；预览、剪贴板读取及完成响应绑定连接上下文与独立操作代次。关闭、重开、选择来源、修改账号或凭据变化会隔离迟到结果。已发送写请求期间禁止关闭和重复提交，不把本机关闭当成服务端事务取消。完成后保持逐项结果并重新读取目录；运行时和 ACP 的选择保持独立。

UI 复用 `settings_text_input`、`settings_modal_layout` / `settings_modal_overlay` / `settings_close_button`、统一主次按钮和现有 toast。共用弹窗固定标题/操作区、4px滚动条和内容两侧7px留白；中文及动态文本使用默认字体。测试经实际 Iced UserInterface 布局和 tiny-skia draw，而非只构造 Element。
