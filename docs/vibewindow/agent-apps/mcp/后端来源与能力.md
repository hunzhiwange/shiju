## 定义校验、连接与取消

| 来源符号 | 静态核对结果 |
| --- | --- |
| `mcp/validation.rs::validate_server_spec`、`extract_server_spec`、`spec_transport_type` | 共享基础校验检查对象、stdio 的非空 command、HTTP/SSE 的非空 URL。校验缺 type 当 stdio，投影辅助对仅 URL 的缺 type 或误标 stdio 推断 HTTP。包装提取要求 `server` 是对象。统一 upsert 本身直接保存 JSON，目标转换或导入才执行不同程度的校验。任务 4 应在写入前形成一致合同。 |
| `services/mcp_connectivity.rs::start_checks`、`cancel_checks`、`check_server` | 一次性 UUID 批次，用 `AbortHandle` 跟踪。所有批次共享 3 个并发许可，排队不占单项 30 秒超时。回调断开即丢弃剩余检查。结束和显式取消均移除批次。逐项结果仅 `serverId`、`connected`，传输错误不返回或记录。 |
| `connect` 的 stdio 分支、`apply_login_shell_path`、`resolve_windows_command`、`ProbeProcess::drop` | 缺 type 时仅 URL 推断 HTTP，其余 stdio。stdio 使用 command、args、env、cwd，配置 PATH 优先。Unix 有缓存且限时的登录 shell PATH。Windows 有后缀解析。管道握手，丢弃 stderr，结束、超时或取消均终止进程组或作业并回收子进程。 |
