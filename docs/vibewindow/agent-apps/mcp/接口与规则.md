## API 操作表

根资源拟为 `/v1/agent-apps/mcp`，表中的 `/` 表示根资源。表中请求和响应描述数据语义，DTO 和线协议由任务 3、32–39 落定。Iced 通过 `vw-gateway-client` 调用。网关 `agent_apps::router` 负责接线，所有操作验证真实认证及成员权限，按适用范围绑定租户、项目、账号和可信主机。调用者提供的主机或实例标识需由服务端解析并授权。表中的权限是操作要求，具体权限键由接线任务复用既有管理授权。[认证与主机边界](../认证与主机边界.md)

短请求无独立取消资源。用户可在提交前丢弃草稿，请求断开或关闭界面后按实际事务结果回读。下表标记为作业的操作使用同一启动、查询、事件和显式取消合同。

| 操作与任务 | 请求 | 响应与状态 | 权限、执行位置和取消 |
| --- | --- | --- | --- |
| `GET /` 目录和能力，32 | 当前授权范围 | 脱敏目录、记录及连接修订、各应用能力、期望绑定和可得的实际状态；运行时与 ACP 各自独立 | 目录读，网关存储。无连接或文件写入，短请求。 |

目录状态读取、原生预览、预设与草稿渲染均无 MCP 握手、下载、OAuth 或进程启动。原生预览使用字段白名单，脱敏 env/headers、URL 用户信息与凭据参数、命令参数及扩展字段中的敏感信息。错误、事件、日志和列表只返回受控错误码、安全说明和关联 ID；运行时工具授权独立校验。

### 来源 IPC 的等价入口

下列 IPC 名均定义于 `src/lib/api/mcp.ts`，后端命令在 `src-tauri/src/commands/mcp.rs`，由 `src-tauri/src/lib.rs` 注册。旧入口的结果形状用于核对能力，迁移调用经资源 API。

| 来源客户端方法 → 实际 IPC | 等价入口与限制 |
| --- | --- |
| `getAllServers` → `get_mcp_servers`；`getConfig` → `get_mcp_config` | 目录查询和按应用投影，旧全局路径不作客户端访问参数。 |
| `upsertUnifiedServer` → `upsert_mcp_server`；`upsertServerInConfig` → `upsert_mcp_server_in_config` | 新增/带修订更新及明确绑定。旧 `syncOtherSide` 扩散到 Claude、Codex、Gemini、OpenCode 的效果由显式目标集合表达，每个目标独立授权。 |
| `deleteUnifiedServer` → `delete_mcp_server`；`deleteServerInConfig` → `delete_mcp_server_in_config` | 旧分应用删除实际删除统一记录，映射为目录删除与清理；仅关闭指定应用走绑定。 |
| `toggleApp` → `toggle_mcp_app`；`setEnabled` → `set_mcp_enabled` | 单项绑定。批量来源由 hook 组合为顺序调用，迁移使用同应用批量。 |

### 作业、失败恢复与所有权

- 复用[任务事件与错误契约](../任务事件与错误契约.md)的作用域、关联 ID、状态与恢复约定。既有应用生命周期的 `crates/vw-agent/src/gateway/api/handlers/agent_apps/lifecycle.rs` 提供 `/v1/agent-apps/operations/{id}` 的 GET/DELETE 和 `/events`，SDK 见 `crates/vw-gateway-client/src/client/agent_apps_lifecycle_api.rs`。MCP 接线应复用底座相应机制，须先验证 MCP 作业可注册、同域查/取消及重启恢复，现有应用生命周期路由仅是已交付的边界参照。
- 启动与取消竞态保留取消意图直到注册返回 ID，或在启动失败后结束等待；替换及离页时仅取消所属未完成批次。排队、运行、取消中及成功/失败/取消/中断分别呈现。已提交文件效果按实际保留。探测全局限 3 个，单项 30 秒从取得执行许可计时；取消与超时须清理进程及连接，再报告终态。接收重复、迟到或越域事件时以当前查询快照为准；断线先查，重启后未完成作业标为中断，过期明确返回。
- 母 11 的原生绑定仅描述受管应用配置。运行时选择及 ACP 会话外挂分别走自己的选择和权限，母 11 任务 27–29 接入已存在的 `crates/vw-agent/src/tools/mcp_common/mod.rs::load_resolved_acp_config_from` 解析链及动态工具授权/撤销。插件声明与项目原生定义保留原所有者。修改、禁用或删除后按修订撤销旧工具引用，刷新和恢复不得复活。
- 原生文件路径由母 3 的应用注册和已验证实例提供，母 4 负责目标文件写锁、事务及同名外部配置冲突；凭据材料由母 6 的账号授权持有，母 11 只使用引用。执行主机不可达直接返回失败。母 9 持有供应商连通诊断，母 19 持有设备同步；MCP 探测和重同步仍归母 11。
