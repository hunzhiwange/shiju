## 长任务共同合同（领域待实现）

本块只定义交接，不新增无真实调用者的任务 trait、全局调度器或远程控制协议。图标读写是有界短事务：请求内验证和原子提交，返回确定结果；没有后台任务 ID、进度或取消。长任务由下表唯一母任务实现各自类型、存储与 API，SDK 是 Iced 唯一入口。

长任务 ID 必须由服务端产生或验证绑定，身份键包含 TenantScope（platform_id/company_id）、领域、执行主机绑定及 task_id；关联 ID 用于串联一次操作，不授予权限。启动、查询、取消及事件订阅都重新验证真实认证链与同一作用域，不能仅凭 task_id、客户端租户头或事件 payload 认定成员授权。主机不可达明确失败，不回退客户端本机。

领域必须提供启动结果中的任务身份、状态查询及显式取消操作；具体 URL/DTO 由该领域设计。查询返回阶段、已完成数量/已知总量（未知则明确未知）、结果摘要或受控错误码，不能伪造百分比。状态语义为 queued/running/cancelling，终态为 succeeded/failed/cancelled/interrupted。取消请求只表示已受理；资源停止、清理并记录终态后才能报告 cancelled。提交与取消竞争时按实际提交结果终结，已提交成功不能改写为取消。重复取消不重复副作用，终态不可逆，跨作用域不能查询或取消。

领域保存可查询身份与最终结果，并在重启时将未完成记录标为 interrupted；无法证明外部效果的中断不得视为成功或自动重跑。保留期及过期后行为由领域明确，不能把记录过期解释为从未执行。客户端丢失响应或断线后先查询状态/快照，不盲重发启动请求；需要重试时由领域明确幂等键、去重范围和安全检查点。浏览器授权、安装进程或远端上传不会因 HTTP 断开天然撤销。

## 领域事件与恢复

每个新领域事件必须携带完整作用域、领域资源身份、关联 ID；属于长任务时带 task_id，并提供事件类别和状态/版本信息以识别陈旧通知。服务端在发布前按可信认证边界隔离订阅，客户端仍核对当前作用域和关联身份。成功变更事件仅在事务成功提交或对应外部效果被确认后发布；回滚不发成功事件。发布失败不反向伪造事务失败，状态查询仍为真相来源。

事件是刷新提示，断线、滞后、进程重启或作用域切换后，SDK 重新查询状态/快照并替换展示缓存。母 17 负责用量通知，母 19 负责同步通知；母 3/6/9 分别负责自身任务进度事件。图标由母 2 的子任务 83–89 通过 GET 恢复列表，不接入事件流。

若某领域确需增量恢复，由该领域实现有界持久事件/数据游标、保留期和作用域过滤。过期游标必须返回明确的 cursor_expired 错误语义并要求重取快照，不能返回空成功冒充追平；具体 HTTP/DTO 由领域约定，不挤入图标四错误码。重复、乱序、漏收、过期、跨作用域游标及提交失败均须验收；现有 SSE 不提供这些保证。

## 图标错误与日志合同（后续子任务 73/82–88 实现）

| 稳定公共错误码 | HTTP | 判定与公开内容 |
| --- | --- | --- |
| invalid_input | 400 | 名称、图片、ID/DTO 等输入不合法；只给固定安全说明，不回显输入 |
| not_found | 404 | 当前作用域中待改名资源不存在；不泄露其它作用域资源，删除缺失仍按幂等合同成功 |
| conflict | 409 | 容量或无法安全完成的写入冲突；图片去重是成功结果，不伪装冲突 |
| storage_unavailable | 503 | 存储连接、读写或提交无法可靠完成；不把损坏/反序列化失败降为空库成功，亦不把服务内部故障归责输入 |

公共错误只含稳定码、安全说明及关联 ID；底层 SQL、表名、连接串、路径、原始异常链不出现在响应、SDK 展示或事件中。内部原始细节只留受控错误源，不将 error.to_string() 直接打进普通日志。认证层已有 401/权限拒绝不改写为这四种领域错误；未预期编程错误遵守既有受控内部错误路径，不能谎称成功或随意归类为存储故障。

日志仅记录操作类别、结果码、关联 ID。禁止凭据、Authorization、原始请求体、PNG data URI、用户绝对路径，包括嵌套错误链和调试输出。子任务 82 验收四码/HTTP、受控错误源与敏感哨兵不泄露；83–88 验收 API/SDK 同码传递与关联 ID，日志不记录图片和请求载荷。503 或网络丢响应不证明写入未提交，客户端先 GET 核实，再按领域幂等规则重试。
