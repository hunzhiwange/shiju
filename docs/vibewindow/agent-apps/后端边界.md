## 真实入口与图标竖切

`commands/mod.rs:11,59` 无条件声明并重导出 custom_icon；`:96–108` 的 run_db_task 克隆 AppState 后 spawn_blocking，闭包完成后释放克隆。`lib.rs:1889–1892` 在主 generate_handler 无条件注册四个图标命令，未套平台 cfg；这是静态注册证据，不是运行通过证明。

`services/provider/icon.rs:33,41,55` 区分 data URI 与内置名，完整 PNG 解码并约束 URI 64 KiB、尺寸 256、解码 1 MiB；`:234,253,261,267,309,328` 负责名称 trim/64 字符、缺失条目、列表、按图片去重/100 项上限/UUID/毫秒时间、改名、幂等删除。新增置顶，去重保留原名称，改名和删除保留其它条目及未知字段。只删除库条目；providers.icon 存图片副本，不存库 ID。

`:96,134,180` 的 strip_invalid_* 由 `database/backup.rs:226` 在导入暂存库清理三处（供应商列、统一供应商 JSON、图标库）；唯一母 18，图片校验复用母 2 的纯规则；供应商 validate_icon 调用者属于母 4。不能把导入清洗混入普通列表读取。

库服务的 get 与 save 各自加锁，整段读改写并非单事务，会有并发丢更新风险。子 74–78 抽取纯规则，子 79–81 在 agent 适配现有双后端 gateway_settings，实现原子读改写；不得另开 cc-switch.db。子 73/83–88 提供固定 DTO、GET/POST/PATCH/DELETE API 与 SDK，子 89–93 完成 Iced 最小列表/改名、macOS 无窗口与真实桌面验收。图标上传预处理、完整选择器/系统集成唯一母 20；供应商图标引用与保存唯一母 4。本任务只记录这些验收归属。
