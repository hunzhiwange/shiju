## 边界与验收约定

每行只给一个主责母任务。API承担授权、租户/应用/目标主机作用域与业务校验；SDK传递类型化输入、结果和错误；执行端在授权主机执行文件、网络、进程及自主调度；Iced消费SDK、管理本机缓存/展示并复用toast。表内验收为后续迁移的行为要求，本轮只证明与源码逐条核对。缓存失效不是后台业务调度，也不证明写入原子性。

母2共享合同/图标底座，母4供应商配置，母7额度，母8路由，母9故障转移，母10聚合，母13提示词，母14会话，母16组合，母20桌面系统动作。母5模型元数据、母17价格自动同步、母19设备同步在本段没有实现；不能因缓存键含模型或刷新就认领这些能力。配置投影归4，协议执行归8，模型目录知识归5。
