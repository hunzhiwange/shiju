## 跨组闭环与责任

- Profile API与query的定义分别见[共享库02](TS-共享库-02.md)、[共享库05](TS-共享库-05.md)。本组只负责scope镜像、调用条件及展示；后端拍照、应用、warnings和托盘失效沿已有引用，不扩展全调用图。
- `promptsApi`合同见[共享库02](TS-共享库-02.md)；`usePromptActions`的错误通知、缓存与读写竞态见[钩子02](TS-钩子-02.md)。Pi页面notify:false仅抑制hook成功提示，错误仍由hook通知并重抛；页面catch不把异常解释成成功。
