## 跨组引用与责任闭合

- 冲突`parseLiveEditConflict`为`lib/errors/liveEditConflict`的外组错误识别，策略类型来自`lib/api/providers::EditorConflictPolicy`；本组只审拒绝、捕获、重试及取消，不实现后端合并。调用者AddProviderDialog/EditProviderDialog见[组件08](TS-组件-08.md)，其onSubmit成功关闭在submit闭包内部，不能把hook初次冲突后正常返回当保存完成。

- `ProviderList→presentation::{buildSwitchSections,buildLaunchSections,buildAdditiveSections}`、`CardPresentation/CardChip/CardTone/CardButton/CardMenuItem`是外组分区/动作合同；本组不遍历其实现。`useDragSort`、`useStreamCheck`、OpenClaw/Hermes hooks及Pi/OMO queries引用既有钩子/共享库盘点；`getOpencodeDeclaredModels`在`forms/helpers/opencodeFormUtils`，`isHermesReadOnlyProvider`在`config/hermesProviderPresets`，由其来源组承接内部规则。
