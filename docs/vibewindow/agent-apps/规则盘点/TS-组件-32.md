## 引用闭合与责任边界

- W内部run及resize update、R解析/计数、I isAppId/submit、B日期、P两个popover和helper、S三个操作及reportResync均在完整片段内，没有跨段未归属函数。导入/接口仅定义入参和外部调用，剩余JSX均为对应行描述的展示、按钮、提示、滚动和可访问性，无额外业务入口。
- 直接调用者 `skills/UnifiedSkillsPanel.tsx`：674–687 handleImport调用mutation并管理写锁/错误；782–805 handleRestoreFromBackup以installTo恢复后报告部分启用失败；1718–1745挂载I/B并把删除交确认；2097–2117 RepoManagerContainer传入P actions；P与S由同容器挂载。该文件不在本组业务责任片段，留其后续组件组；这里只核对回调落点，不认领其内部实现。InstallRunner为外部useSkillInstallTargets返回值，不能由P类型签名断言完整多应用事务。
