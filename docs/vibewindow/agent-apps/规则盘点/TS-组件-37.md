- ModelsDevAutoSyncPanel/Picker、ChecklistMenu引用[组件36](TS-组件-36.md)；useMoneyFormat引用[钩子02](TS-钩子-02.md)。format.ts（解析、语言、速度阈值、估速及session判定）、providerLabel.ts、requestLogColumns.ts、statsColumns.tsx、usageTable.ts为后续固定组件组的定义责任，本组记录各调用及结果消费，不推测其默认列、阈值或底层公式。types/usage的getFreshInputTokens/isUnpricedUsage/isNonNegativeDecimalString/CACHE_INCLUSIVE_APP_TYPES归后续类型组；本组不从HTML number约束推导其词法正则。extractErrorMessage定义亦外部引用，不据本组件推断脱敏已实现。
- 所有新增业务项唯一母17；模型价格ID不产生母5模型目录能力，计费来源不等于母8协议转换，无母4供应商配置变更、母19设备同步。纯选中/布局/时间格式/分页/列设置归母20。自动价格同步只引用组件36与母17，不在页面新增调度器。
- 本组无浏览器URL打开、剪贴板、远端文件或进程动作。价格/日志持久化由授权执行端完成，不得回退桌面本机。API/SDK共享类型沿用母2底座，不添加任意command通道。
