## 字段规则族与唯一责任

“母”指 CC 能力完整融合母任务。每个行为只有下表一个主责；同一预设的不同字段分别归属。原生服务应提供 API 判断和投影，SDK 只传 DTO，Iced 通过 SDK 展示和提交，授权执行端消费配置或访问端点；这只是迁移边界，不宣称已实现。
