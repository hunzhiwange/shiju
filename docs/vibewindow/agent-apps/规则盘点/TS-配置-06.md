## 异常与跨组闭合

- G:1–25 的默认 500k 上下文只是注释；本工厂实际不输出上下文字段，GROK_BUILD_DEFAULT_MODEL 直接定义在 `utils/grokBuildConfig.ts:3`，值 grok-4.7。上下文原生重建属于后续工具组；不得在本盘点补写功能。
- G 的 AICodeMirror 是 `/api/codex/backend-api/codex`，hao.ai 为 `/x-ai/v1`，Qiniu 为 `/bypass/openai/v1`，SSSAiCode 为 `/api/v1`，RightCode 为 `/codex/v1`；FennoAI/AIGoCode 为无 /v1 根地址，不能统一追加路径。hao.ai、Shengsuanyun、CherryIN、OpenRouter 用 x-ai/，TheRouter 明确 xai/，其余默认或显式无前缀 grok-4.7。AllTokens/BuyToken/V-API/SI 的 Key 分组要求仅注释，未实现校验。
- G:85 目录无运行时收录算法；注释中 grok-4.5 的旧探针不能覆盖配置默认 grok-4.7。xAI (Grok) 是 Key 第三方卡，不等于 G2 官方 OAuth。多处无 category、候选或 apiFormat 是允许的缺省，不擅自填值。
