# 员工任务流程消息

员工任务流程消息定义了任务在系统中的流转方式。

## 消息类型

### 任务创建消息

```rust
pub struct TaskCreated {
    task_id: Uuid,
    task_type: TaskType,
    priority: Priority,
    created_at: DateTime<Utc>,
    metadata: HashMap<String, Value>,
}
```

### 任务分配消息

```rust
pub struct TaskAssigned {
    task_id: Uuid,
    assigned_to: AgentId,
    assigned_at: DateTime<Utc>,
    expected_duration: Duration,
}
```

### 任务执行消息

```rust
pub struct TaskExecution {
    task_id: Uuid,
    status: ExecutionStatus,
    progress: f32,
    logs: Vec<LogEntry>,
}
```

### 任务完成消息

```rust
pub struct TaskCompleted {
    task_id: Uuid,
    result: TaskResult,
    completed_at: DateTime<Utc>,
    metrics: ExecutionMetrics,
}
```

## 消息流程

```
创建 → 排队 → 分配 → 执行 → 完成
 │       │       │       │       │
 └──ERR──┴──ERR──┴──ERR──┴──ERR──┴──超时
```

## 状态机

### 任务状态

- **PENDING**: 等待分配
- **ASSIGNED**: 已分配
- **RUNNING**: 执行中
- **SUCCEEDED**: 成功完成
- **FAILED**: 执行失败
- **CANCELLED**: 已取消
- **TIMEOUT**: 超时
