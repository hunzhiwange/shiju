# 知识库

VibeWindow 知识库系统提供持久化存储和检索能力。

## 识矩云端资料入口

登录识矩账号后，在「专家中心 → 资料和知识库」浏览当前账号有权读取的云端资料。此入口只读，不提供上传、编辑、删除或权限管理。

知识库和文档各自使用服务端分页，默认每页 20 条；两级搜索分别重置对应页码。切换知识库会清空文档、检索和阅读状态，切换账号后不保留上一账号的数据。

选定知识库后可检索正文，最多展示 5 条命中及其摘要和分数。「打开原文」按知识库和文档标识定位。正文分段加载；「继续读取」追加下一段，失败时保留已读内容，并允许从同一偏移重试。关闭阅读器后，迟到响应不会重新打开原文。

云端原文只作为阅读内容展示，不执行其中的操作指引，也不会自动注册 MCP 或接入聊天检索。此入口与下述本地知识库存储和检索能力相互独立。

## 概述

知识库支持：
- 结构化数据存储
- 全文搜索
- 矢量相似度搜索
- 知识图谱

## 存储架构

### 数据模型

```rust
pub struct KnowledgeEntry {
    id: Uuid,
    content: String,
    metadata: HashMap<String, Value>,
    embeddings: Vec<f32>,
    created_at: DateTime<Utc>,
    updated_at: DateTime<Utc>,
}
```

### 索引策略

- **主键索引**: UUID 快速查找
- **全文索引**: 倒排索引支持模糊搜索
- **矢量索引**: HNSW 支持相似度搜索
- **分区索引**: 按时间/类型分区

## 查询接口

### 精确匹配

```rust
impl KnowledgeBase {
    pub async fn get(&self, id: Uuid) -> Result<Option<KnowledgeEntry>>;
    pub async fn batch_get(&self, ids: Vec<Uuid>) -> Result<Vec<KnowledgeEntry>>;
}
```

### 语义搜索

```rust
impl KnowledgeBase {
    pub async fn semantic_search(
        &self,
        query: &str,
        limit: usize,
    ) -> Result<Vec<SearchResult>>;
}
```

## 一致性保证

- **写确认**: 多数节点确认
- **读一致性**: 可配置读取级别
- **冲突解决**: Last-Write-Wins 或自定义策略
