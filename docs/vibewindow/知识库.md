# 知识库

VibeWindow 知识库系统提供持久化存储和检索能力。

## 概述

知识库支持：
- 结构化数据存储
- 全文搜索
- 矢量相似度搜索
- 知识图谱

## 存储架构

### 数据模型

```rust
pub struct KnowledgeEntry {
    id: Uuid,
    content: String,
    metadata: HashMap<String, Value>,
    embeddings: Vec<f32>,
    created_at: DateTime<Utc>,
    updated_at: DateTime<Utc>,
}
```

### 索引策略

- **主键索引**: UUID 快速查找
- **全文索引**: 倒排索引支持模糊搜索
- **矢量索引**: HNSW 支持相似度搜索
- **分区索引**: 按时间/类型分区

## 查询接口

### 精确匹配

```rust
impl KnowledgeBase {
    pub async fn get(&self, id: Uuid) -> Result<Option<KnowledgeEntry>>;
    pub async fn batch_get(&self, ids: Vec<Uuid>) -> Result<Vec<KnowledgeEntry>>;
}
```

### 语义搜索

```rust
impl KnowledgeBase {
    pub async fn semantic_search(
        &self,
        query: &str,
        limit: usize,
    ) -> Result<Vec<SearchResult>>;
}
```

## 一致性保证

- **写确认**: 多数节点确认
- **读一致性**: 可配置读取级别
- **冲突解决**: Last-Write-Wins 或自定义策略
