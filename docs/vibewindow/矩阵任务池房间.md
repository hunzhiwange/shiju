# 矩阵任务池房间

矩阵任务池是 VibeWindow 的核心调度组件，房间是其资源隔离单元。

## 概述

房间（Room）是任务执行的隔离环境：
- 独立的资源配额
- 独立的任务队列
- 独立的监控指标

## 架构设计

```
┌─────────────────────────────────────────────┐
│              Matrix Task Pool                │
├─────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐    │
│  │  Room 1 │  │  Room 2 │  │  Room N │    │
│  │  TaskQ  │  │  TaskQ  │  │  TaskQ  │    │
│  └────┬────┘  └────┬────┘  └────┬────┘    │
│       │            │            │          │
│  ┌────┴────┐  ┌────┴────┐  ┌────┴────┐    │
│  │ Worker1 │  │ Worker2 │  │ WorkerN │    │
│  └─────────┘  └─────────┘  └─────────┘    │
└─────────────────────────────────────────────┘
```

## 房间配置

```yaml
room:
  id: "room-001"
  quota:
    cpu: "2 cores"
    memory: "4GB"
    gpu: "1 unit"
  max_concurrent_tasks: 10
  task_timeout: 300s
```

## 调度策略

### 任务分配

1. **优先级调度**: 高优先级任务优先
2. **公平调度**: 房间间公平分配
3. **负载均衡**: 选择负载最低的房间

### 资源管理

- **预留**: 保证房间最小资源
- **抢占**: 高优先级可抢占低优先级
- **弹性**: 支持动态资源调整
