# 网络代理架构

网络代理是 VibeWindow 的网络通信层，负责处理所有网络相关功能。

## 概述

网络代理提供：
- HTTP/HTTPS 代理
- WebSocket 支持
- TCP/UDP 穿透
- 负载均衡

## 核心组件

### 连接池

```rust
pub struct ConnectionPool {
    max_connections: usize,
    min_connections: usize,
    idle_timeout: Duration,
    connection_lifetime: Duration,
}

impl ConnectionPool {
    pub async fn acquire(&self) -> Result<PooledConnection>;
    pub async fn release(&self, conn: PooledConnection);
}
```

### 路由策略

支持多种路由策略：
- **静态路由**: 固定目标地址
- **动态路由**: 基于配置规则
- **服务发现**: 集成 Consul/Etcd
- **负载均衡**: 多种算法

### 安全特性

- **TLS 终止**: 代理层 TLS 处理
- **证书管理**: 自动续期
- **连接加密**: 端到端加密
- **访问控制**: IP 白名单/黑名单

## 性能优化

### 连接复用

- HTTP Keep-Alive
- WebSocket 长连接
- 连接池复用

### 缓冲策略

- 请求缓冲
- 响应缓冲
- 流式处理
