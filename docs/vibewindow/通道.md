# 通道

VibeWindow 的通道支持分为两层：

- 编译特性按通道类型启用，例如 Matrix 使用 `channel-matrix`，Feishu/Lark
  使用 `channel-lark`。
- 运行时配置按实例 ID 区分账号、房间或应用，例如 `matrix:default`、
  `matrix:planner`、`feishu:support`。

旧的单实例配置仍然可用，并等价于实例 ID `default`。多实例配置、员工绑定
和 Matrix 任务池路由的完整说明见
[`docs/channel-instance-profiles.md`](../channel-instance-profiles.md)。

飞书/Lark 的 `allowed_users` 必须填写事件发送者的 `open_id`，不能填写显示名。
配置方法与拒绝日志排查见[飞书与 Lark 用户白名单配置](飞书与Lark用户白名单配置.md)。

## 编译与启动

只启动 gateway：

```bash
cargo run -p vw-cli --bin vibewindow -- gateway
```

启用 Matrix 与 Feishu/Lark 通道并启动 daemon：

```bash
cargo run -p vw-cli --features "vw-agent/channel-matrix vw-agent/channel-lark" --bin vibewindow -- daemon
```

编译特性只决定通道类型是否可用；具体使用哪个 Matrix、Feishu 或 DingTalk
实例由运行时配置和员工 `channel_bindings` 决定。

## 多实例示例

```toml
[channels.matrix]
homeserver = "https://matrix.example.com"
access_token = "<matrix-access-token-for-default-bot>"
user_id = "@vibewindow-default:matrix.example.com"
device_id = "VIBEWINDOW_DEFAULT"
room_id = "!default-room:matrix.example.com"
allowed_users = ["@alice:matrix.example.com"]
mention_only = false

[[channels.matrix_instances]]
id = "planner"
homeserver = "https://matrix.example.com"
access_token = "<matrix-access-token-for-planner-bot>"
user_id = "@vibewindow-planner:matrix.example.com"
device_id = "VIBEWINDOW_PLANNER"
room_id = "!planner-room:matrix.example.com"
allowed_users = ["@alice:matrix.example.com", "@bob:matrix.example.com"]
mention_only = false

[[channels.feishu_instances]]
id = "support"
app_id = "cli_feishu_support_example"
app_secret = "<feishu-app-secret>"
verification_token = "<feishu-verification-token>"
allowed_users = ["ou_example_support_user"]
receive_mode = "websocket"
draft_update_interval_ms = 3000
max_draft_edits = 20

[[channels.dingtalk_instances]]
id = "ops"
client_id = "ding_ops_example_client"
client_secret = "<dingtalk-client-secret>"
allowed_users = ["ding_example_ops_user"]
```

## 员工绑定示例

```toml
[[staff.members]]
id = "planner"
name = "Planner"
role = "Planning"
level = "senior"

[[staff.members.channel_bindings]]
channel_type = "matrix"
instance_id = "planner"

[[staff.members.channel_bindings]]
channel_type = "feishu"
instance_id = "support"
```

Matrix 的 `access_token` 是 Matrix 账号 token，不是 session key。不同员工如
需使用不同 Matrix 账号，应配置不同 `user_id`、`access_token` 和实例 ID，再
通过 `channel_bindings` 绑定。
