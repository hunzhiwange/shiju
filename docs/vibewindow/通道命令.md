# 通道命令

在飞书或 QQ 发送 `/help` 查看全部支持命令，发送 `/help project` 查看单项用法。群聊的 @机器人触发方式沿用实例现有策略；实例要求 @ 时，先 @机器人再发送命令。

## 可用命令

下列命令已接通公共文本入口，适用于飞书、QQ 等通道。权限检查仍由实例允许发送者、当前租户、项目及会话所有权共同约束。命令名称不区分 ASCII 大小写，支持 `/help@机器人名`；参数按空白分隔，不使用 shell 引号转义。稳定 ID 和消息锚点必须复制完整值。

| 命令及参数 | 解析别名 | 用途 | 示例 | 权限与失败语义 |
|---|---|---|---|---|
| `/stop` | 无 | 停止当前聊天执行，等待处理器和反馈退出；其他聊天不受影响 | `/stop` | 当前通道允许的发送者；无任务时幂等；退出未确认时保留繁忙状态 |
| `/projects` | 无 | 列出当前租户可访问项目的稳定 ID | `/projects` | 当前通道允许的发送者；失效目录不显示 |
| `/project [稳定ID\|default]` | 无 | 查看或切换当前聊天项目；default 恢复实例默认 | `/project default` | 当前通道允许的发送者；未知 ID 或聊天繁忙时不切换 |
| `/new` | /session | 立即创建新会话并返回 ID，保留旧会话及当前项目 | `/new` | 当前通道允许的发送者；项目解析失败不清历史 |
| `/clear` | 无 | 重置当前上下文，下一条消息创建新会话；旧历史保留 | `/clear` | 当前通道允许的发送者；繁忙或项目不可用时拒绝；失败保留历史和绑定 |
| `/sessions` | 无 | 列出当前聊天和项目拥有的非归档会话；/resume <ID> 恢复 | `/sessions` | 当前通道允许的发送者；繁忙、无所有权或状态变化时拒绝；失败保留当前绑定 |
| `/resume [ID]` | 无 | 无参数列出候选，按完整 ID 恢复当前域拥有的会话 | `/resume ses_example` | 当前通道允许的发送者；繁忙、无所有权或状态变化时拒绝；失败保留当前绑定 |
| `/continue` | 无 | 恢复当前聊天和项目最近的非归档会话 | `/continue` | 当前通道允许的发送者；繁忙、无所有权或状态变化时拒绝；失败保留当前绑定 |
| `/rename <标题>` | 无 | 重命名当前会话；标题最多 100 字符 | `/rename 调试记录` | 当前通道允许的发送者；繁忙、无所有权或状态变化时拒绝；失败保留当前绑定 |
| `/archive [confirm <当前会话ID>]` | 无 | 先请求确认，再按当前会话 ID 归档，保留历史 | `/archive` | 当前通道允许的发送者；繁忙、无所有权或状态变化时拒绝；失败保留当前绑定 |
| `/fork [message-id]` | 无 | 按真实消息锚点分叉并切换会话；无参数列出可用锚点 | `/fork` | 当前通道允许的发送者；外部锚点、跨域、繁忙及过期确认被拒绝，失败保留当前绑定 |
| `/compact [message-id \| confirm message-id]` | /summarize | 压缩锚点之前的历史，需显式 confirm 确认；无参数列出可用锚点 | `/compact` | 当前通道允许的发送者；外部锚点、跨域、繁忙及过期确认被拒绝，失败保留当前绑定 |
| `/reset [message-id \| confirm message-id]` | /rewind | 回退聊天历史及生成的文件变更，需 confirm；无参数列出可用锚点 | `/reset` | 当前通道允许的发送者；外部锚点、跨域、繁忙及过期确认被拒绝，失败保留当前绑定 |
| `/settings` | 无 | 只读查看当前会话设置，不提升权限 | `/settings` | 当前通道允许的发送者；参数不合法时保留全部设置 |
| `/models [provider]` | /providers | 查看当前 provider 真实模型目录；可保留旧写法切换 provider | `/models` | 当前通道允许的发送者；provider 不存在或初始化失败不切换 |
| `/model [ID]` | 无 | 查看当前模型或选择当前 provider 目录中的模型 | `/model gpt-5` | 当前通道允许的发送者；目录未声明的模型被拒绝，历史和路由不变 |
| `/effort [level]` | 无 | 查看可用推理强度或切换；default 恢复默认 | `/effort high` | 当前通道允许的发送者；只接受当前模型真实支持的强度，失败保持原状态 |
| `/help [命令名]` | 无 | 查看全部已接通命令或详情，不调用模型 | `/help model` | 当前通道允许的发送者；未知名称会提示返回 /help |
| `/status` | 无 | 查看当前项目、会话、模型、强度与运行状态 | `/status` | 当前通道允许的发送者；项目不可用时报告错误 |
| `/task` | 无 | 重置当前上下文并进入任务模式，后续文本创建任务 | `/task` | 当前通道允许的发送者；项目解析失败不进入任务模式 |
| `/approve-all-once` | 无 | 创建一次性全工具授权请求；随后用 /approve-confirm apr-xxxxxx 确认 | `/approve-all-once` | 授权管理权限，仍受审批人及策略限制；仍遵守授权策略，不能绕过审批人检查 |
| `/approve-request <tool-name>` | 无 | 请求单工具授权；随后用 /approve-confirm apr-xxxxxx 确认 | `/approve-request shell` | 授权管理权限，仍受审批人及策略限制；未知工具或策略拒绝时不会授权 |
| `/approve-confirm <request-id>` | 无 | 确认待授权请求，按现有策略保存结果 | `/approve-confirm apr-xxxxxx` | 授权管理权限，仍受审批人及策略限制；过期、跨聊天或不存在的请求会被拒绝 |
| `/approve-allow <request-id>` | 无 | 批准待审批请求，仅限本次调用 | `/approve-allow apr-xxxxxx` | 授权管理权限，仍受审批人及策略限制；请求必须属于当前授权上下文 |
| `/approve-deny <request-id>` | 无 | 拒绝当前待审批请求 | `/approve-deny apr-xxxxxx` | 授权管理权限，仍受审批人及策略限制；不接受其他聊天的请求 |
| `/approve-pending` | 无 | 查看当前作用域内待处理授权 | `/approve-pending` | 授权管理权限，仍受审批人及策略限制；只列出当前发送者和聊天的请求 |
| `/approve <tool-name>` | 无 | 直接批准单个受监督工具，仍受授权策略限制 | `/approve shell` | 授权管理权限，仍受审批人及策略限制；未知工具和禁止授权的工具均拒绝 |
| `/unapprove <tool-name>` | 无 | 撤销单个工具批准 | `/unapprove shell` | 授权管理权限，仍受审批人及策略限制；参数错误不改变权限 |
| `/approvals` | 无 | 查看现有授权配置与当前运行状态 | `/approvals` | 授权管理权限，仍受审批人及策略限制；发送者无权限时拒绝查询 |

普通控制命令在模型前拦截，参数错误和未知斜杠命令返回提示，不当作问题交给模型。`/compact` 确认后需要调用模型生成摘要；普通聊天仍会执行模型及工具。

## 连续操作

1. 在桌面通道设置中为实例选择默认项目，保存。项目须先在当前租户注册，见[通道实例配置](通道实例配置.md)。
2. 在聊天发送 `/help`、`/help project`、`/project`，确认当前默认项目。
3. 发送普通问题，然后 `/new` 创建新会话，保存返回的完整会话 ID。
4. `/sessions` 查看当前域会话，发送 `/resume ses_实际ID` 恢复。`/resume` 无参数也可列候选。
5. `/projects` 列出项目，复制 ID 发送 `/project 实际项目ID`。新项目使用独立会话与历史。
6. `/project default` 恢复实例默认项目。聊天选择仅在当前进程生效，重启回到实例默认。
7. `/model` 查看模型，`/models` 查看实际目录，再发送 `/model 实际模型ID`；`/effort` 查看当前模型支持的强度，再选择支持值。

示例中的 `ses_实际ID`、`实际项目ID` 和 `实际模型ID` 是占位符，必须换成列表返回的完整值。不能用目录路径或模糊项目名选择项目。

## 确认、忙碌与失败

- 归档：先 `/archive`，再按回复发送 `/archive confirm 当前会话ID`。
- 历史操作：`/fork`、`/compact`、`/reset` 无参数列出持久化消息锚点；`/fork 消息ID` 直接创建分叉。先 `/compact 消息ID` 或 `/reset 消息ID` 请求确认，再发送 `/compact confirm 消息ID` 或 `/reset confirm 消息ID`。会话、消息或确认状态变化后须重新请求；压缩锚点必须为用户消息。
- 授权：`/approve-request shell` 或 `/approve-all-once` 返回请求 ID；复制该 ID 发送 `/approve-confirm apr-实际ID`。审批待执行请求使用 `/approve-allow apr-实际ID` 或 `/approve-deny apr-实际ID`，不可使用其他聊天的请求。授权不绕过现有工具策略。
- 执行繁忙时，项目/会话切换和模型/强度写入等操作被拒绝；可用 `/help`、`/status` 等只读命令查看，或 `/stop` 等待当前处理器和反馈退出后再发送下一条聊天。停止未确认完成时仍保持忙碌，不影响其他聊天。
- 无权限、目录失效、未知 ID、跨域恢复或过期确认均明确失败，保留原绑定与历史；不静默退回其他项目。租户、实例、聊天、主题、发送者与项目共同隔离会话。

自然语言授权还支持“查看授权”、“确认授权 请求ID”、“授权工具 工具名”、“撤销工具 工具名”等受限形式；建议使用上表中的明确斜杠写法。

## CLI 能力边界

对照 [TUI 命令](TUI命令.md)：`/cd`、`/diff`、`/files`、`/hooks`、`/doctor`、`/exit` 为宿主交互能力，不适用于聊天；`/plan`、`/goal`、`/permissions`、`/skills`、`/plugins`、`/mcp`、`/memory`、`/workflows`、`/schedule`、`/agents`、`/tasks` 及动态 Skill/Workflow 命令不在此次通道开放范围。聊天 `/settings` 为只读文本，不能打开 TUI 设置面板。远程创建项目、调整权限体系及 QQ 多机器人实例配置均不支持。

## 命令集合核对与验证边界

上表逐项对应运行时 `runtime_command/catalog.rs` 的全部命令；解析器由同一目录校验参数，`/help` 使用同一目录生成详情并分段。自动帮助链路测试对每条 usage 和解析别名核对目录、实际回复与本表，避免会话创建、历史操作和停止命令从帮助中遗漏。

自动测试替换平台外部传输及模型网络边界；不代表已使用真实线上飞书或 QQ 凭据验收。上线前应在目标实例实测群聊触发、平台回复权限和网络连通性。
