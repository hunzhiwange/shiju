# 通道实例配置

通道是 VibeWindow 中连接不同运行时实例的通信管道。

## 概述

每个通道实例代表一个独立的通信会话，支持：
- 同步/异步消息传递
- 消息队列缓冲
- 连接状态管理

## 配置参数

```yaml
channel:
  instance:
    id: "instance-001"
    type: "bidirectional"
    capacity: 1000
    timeout: 30s
    retry:
      max_attempts: 3
      backoff: "exponential"
```

## 核心属性

### 容量配置

- **buffer_size**: 消息队列容量
- **max_pending**: 最大待处理消息数
- **overflow_policy**: 溢出策略（拒绝/丢弃/阻塞）

### 超时配置

- **connect_timeout**: 连接建立超时
- **read_timeout**: 读取超时
- **write_timeout**: 写入超时
- **idle_timeout**: 空闲超时

### 重试配置

- **max_attempts**: 最大重试次数
- **initial_delay**: 初始重试延迟
- **max_delay**: 最大重试延迟
- **backoff**: 退避算法（线性/指数/抖动）

## 状态管理

通道实例有多种状态：
- **INIT**: 初始化
- **CONNECTING**: 连接中
- **ACTIVE**: 活跃
- **RECONNECTING**: 重连中
- **CLOSED**: 已关闭
- **ERROR**: 错误状态
