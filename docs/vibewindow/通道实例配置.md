# 通道实例配置

通道实例连接飞书、QQ 等聊天平台。飞书和钉钉支持命名实例，QQ 当前使用单实例。聊天命令见[通道命令](通道命令.md)。

## 配置格式

通道配置保存在系统配置的 `channels_config` 字段，使用现有 JSON 配置保存链。以下为片段；项目 ID 须替换为当前租户已注册项目的真实稳定 ID，凭据须使用平台实际值，不要公开配置文件：

```json
{
  "channels_config": {
    "feishu_instances": [
      {
        "id": "support",
        "app_id": "平台应用ID",
        "app_secret": "平台应用密钥",
        "allowed_users": ["允许的用户ID"],
        "receive_mode": "websocket"
      }
    ],
    "qq": {
      "app_id": "QQ应用ID",
      "app_secret": "QQ应用密钥",
      "allowed_users": ["允许的用户ID"],
      "receive_mode": "websocket"
    },
    "instance_default_projects": {
      "feishu:support": "实际项目ID",
      "qq:default": "另一个实际项目ID"
    }
  }
}
```

`instance_default_projects` 的键是 `通道类型:实例ID`。命名飞书使用 `feishu:support`，单实例飞书为 `feishu:default`，QQ 为 `qq:default`。实例 ID 应保持稳定，改名后需同步项目绑定。QQ 的 `receive_mode` 支持 `websocket` 和 `webhook`；Webhook 由 Gateway 入站路径处理，不作为额外机器人实例启动。平台允许用户与群聊触发策略仍按原实例配置生效。

## 桌面选择默认项目

打开通道实例设置，加载当前租户可访问项目并选择默认项目，然后保存；可显式取消绑定。加载失败时保留已有绑定，失效项目不自动替换。候选随当前租户与实例变化，切换后需重新选择，不能复用旧租户的列表。

优先级为：当前聊天临时选择 > 实例默认绑定 > 运行时工作目录。默认绑定指向不存在或无权限的项目时明确失败，不自动退回工作目录。设置会持久化；聊天 `/project ID` 只覆盖当前进程内的聊天作用域，重启回到实例默认。`/project default` 可主动清除聊天覆盖。

## 纯文本选择与隔离

发送 `/projects` 获取稳定 ID，发送 `/project 完整ID` 切换，`/project` 查看当前选择。禁止用路径或模糊名称创建/切换项目；项目需先在宿主注册。

同一发送者在不同实例、群、主题和项目中拥有独立上下文；会话也受当前租户和发送者限制。切换项目保留旧会话，不能跨域 `/resume`。执行繁忙时先 `/stop`，等待停止完成后切换；目录失效时可用 `/projects` 或 `/project default` 修复选择。会话归档和历史压缩/回退需按回复显式确认。
