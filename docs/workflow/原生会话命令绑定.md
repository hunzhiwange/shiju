# 原生会话命令绑定

项目可以把原生会话中的 slash 命令绑定到项目内的 YAML 工作流。命中绑定后，会话直接执行工作流并回传节点事件和最终答案。

在项目根目录新建 `.shiju/workflow_commands.json`，填写当前会话的本地平台 ID 和公司 ID：

```json
{
  "platform_id": "当前本地平台 ID",
  "company_id": "当前本地公司 ID",
  "commands": [
    {
      "command": "/shiju 摘要",
      "workflow_file": ".shiju/workflows/summary.yaml",
      "inputs": {}
    }
  ]
}
```

将对应工作流保存为 `.shiju/workflows/summary.yaml`，然后在该项目的原生会话中输入 `/shiju 摘要`。也可以先选中对应技能，再输入命令中技能名后面的文字。命令按词边界匹配，多个绑定命中时使用最长的命令。

工作流文件必须位于当前项目目录内。运行器注入当前项目路径，绑定中的 `inputs` 可提供其他起始变量。工作流沿用当前会话的模型解析、工具权限和审批，停止会话时会取消正在执行的工作流。
