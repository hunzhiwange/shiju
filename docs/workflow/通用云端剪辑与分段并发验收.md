# 通用云端剪辑与分段并发验收

## 使用边界

在原生项目会话输入 `/shiju 剪辑 "视频绝对路径"`。路径必须由当前原生权限允许；无需为每个项目编写命令绑定。不支持的媒体、缺失模型、未授权技能、多个未选择云端空间和不完整远端回执均明确失败，不自动开启 full_access。

Workflow 应用中的“通用云端视频剪辑”为当前租户正式模板。初始资源来自 `crates/vw-agent/resources/workflows/cloud_video_edit.yaml`；正式记录优先于初始资源。可编辑业务提示词、显式模型和一至五路预算；不能改变执行能力、顺序或交付检查。运行固定模板摘要，编辑影响下一次运行；恢复默认要求明确确认及当前版本。

默认五路、硬上限五路，指同一次逻辑运行共享的模型叶子请求和独立素材作业预算。素材提交后到终态确认前持续占用预算，重试同样受限。工程写入串行。短片不足五段时不保证峰值达到五；429、排队和日志不能证明五路真实并发。

分段只拆转写和计划数据，不在本机切割媒体。效果以原片绝对时间及稳定词索引描述，再依据实际源片至成片映射放置。未知远端写入先对账，不盲目重发；取消和重启不得重复写入已完成效果，未确认取消不得释放远端占用。失败交付不返回虚假预览。

只交预览草稿，不自动最终导出。性能包含准备、规划、素材、串行应用及预览各阶段，不能承诺十分钟与五分钟耗时相同。真实长片必须来自维护者授权并经云端探测；合成 300/600 秒转写只证明调度算法。
