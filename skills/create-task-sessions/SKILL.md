# 创建任务会话

加载本技能后，将用户随后粘贴或拖入的任务描述视为创建会话请求。除非用户明确要求只分析任务，默认将每项任务创建为一个独立的可见会话；用户无需额外说明“创建会话”、“一任务一会话”或“不等待”。

## 工作方式

1. 按用户提供的任务边界拆分：单个任务创建一个会话；多个彼此独立的任务分别创建，不合并。如果任务边界无法从输入中确定，先请用户澄清，不自行改写或拆分。
2. 将每项任务的标题作为 `title`，将该项任务的完整正文原样作为 `prompt`。保留所有约束、验证要求、路径和格式；不删减、摘要、润色，也不添加未获授权的工作。
3. 为每项任务调用 `SessionTool`，且只传入以下字段：

```json
{
  "action": "create",
  "title": "<任务标题>",
  "prompt": "<完整任务正文>"
}
```

4. 记录每次成功返回的 `session_id`。多个独立任务可并行创建；某一项创建失败时，保留已成功的结果，并明确报告失败的任务和错误，不伪造会话标识。
5. 所有创建调用返回后立即结束当前处理。最终回复仅简短列出成功的 `session_id` 和已发生的创建错误。

## 停止条件

所有 `SessionTool.create` 调用返回后必须停止。不调用 `list`、`status`、`read`、`send` 或 `wait`；不等待新会话执行，不读取或轮询其进度，不向新会话续发内容，也不在当前会话执行任务正文。

## 边界

- 会话固定在当前工作区创建，运行时自行继承环境与模型选择。
- 不查找或选择项目，不创建 worktree、分支或自动化，不传入模型或推理强度，不输出任何特定 UI 指令。
- 用户明确限于分析时，不创建会话，仅回答其分析请求。
