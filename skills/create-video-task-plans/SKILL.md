# 创建视频任务计划

开始时说明正在使用 create-video-task-plans。先读取 [视频任务契约](references/video-tasks.md)，它同时约束计划生成和子任务执行。

只创建计划，不执行剪辑、创建任务会话或提交导出；用户同时授权执行时，计划完成后交给兄弟技能 [run-video-codex-task-plan-sessions](../run-video-codex-task-plan-sessions/SKILL.md)。不调用编码计划或 do-task-plans 技能。

## 规划

1. 阅读 cutvideo 技能、用户需求、已有工程和作业记录，只读取当前任务需要的服务端规则。核实视频工作目录、projectId、素材清单、统一风格和用户已确认事项；关键输入缺失时先补齐，不能编造标识。
2. 对预计主动工作超过约 20 分钟或存在多组独立素材分析的任务，在上述输入稳定后拆分。按一个明确产物、约 10–20 分钟主动工作量划分；生成和渲染等待时间不作为重复拆分提交的理由。
3. 按契约检查读写边界、输出目录和依赖关系。只读素材分析可并行；工程写入和外部生成提交串行。批次按真实依赖排序，不能仅靠分轨判定独立。
4. 在视频工作目录创建 `.plans/YYYY-MM-DD-视频任务/`，先写只读架构指南 plan.md，再写编号任务文件，最后写 prompt.md。已有目录不覆盖。
5. plan.md 记录任务类型、工作目录、cutvideo 绝对路径、projectId、目标、约束、依赖和最大并发（默认 3），不承载可变进度。每个任务文件按契约自包含，所有引用使用绝对路径。

## 编号任务模板

```markdown
# 任务 N：<单一产物>

任务类型：视频制作
批次：N
依赖任务：<编号及结果记录绝对路径，或无>
状态：未开始
工作目录：<绝对路径>
cutvideo 技能：<绝对路径>/SKILL.md
projectId：<已核实的标识>
访问模式：只读 / 写入（仅保留一种）
输出目录：<任务专属绝对路径>
结果记录：<计划目录绝对路径>/results/N.md

## 输入与约束

填写素材标识、时间范围、用户已确认约束和所需模板版本引用；不复制服务端规则正文。

## 操作边界

明确允许的操作、禁止操作和真实依赖。任何共享工程写入标为写入；异步提交、续查与结果应用按工具实际契约区分。

## 步骤与验收

填写具体步骤、所需产物、确切检查方式和成功证据。已有作业先续查，不重复提交。结果记录保存非敏感作业标识、续查参数、回执和下一步。

## 完成

产物验收和结果记录完整后标记已完成，保留本文件。无法继续时标记已阻塞，记录证据和下一步。预览未经用户确认不得提交导出。
```

## prompt.md 格式

每个编号任务对应一个完整 text 代码块；按批次、任务编号排序。生成时替换全部占位符，不把所有任务内容重复写进提示。

````markdown
# 视频任务执行提示

# 批次 1

## 任务 1：<任务名>

```text
请执行视频任务 `<编号任务文件绝对路径>`。
先阅读 `<plan.md绝对路径>`、该任务文件、`<视频任务契约绝对路径>` 和 `<cutvideo技能绝对路径>`，确认依赖结果及访问模式。
只执行当前任务，遵守 cutvideo 每会话启动规则，使用专属输出目录。已有异步作业先续查，不重复提交或扩大授权。完成后将产物及验收证据写入指定结果记录，标记已完成并保留任务文件；阻塞时记录具体证据、已有作业和下一步。不要修改 plan.md、其他任务文件或执行 Git/Cargo；预览未经用户确认不得导出。
```
````

## 检查与交接

检查每项用户需求有对应任务、prompt 覆盖全部任务、依赖无环、同批次无共享写入、专属输出不冲突，且长作业有续查记录要求。无法确定读写语义时按写入安排。

简短报告计划目录、任务数量和 prompt.md 路径。是否自动执行取决于用户授权，不宣称已经创建或运行会话。
