# 视频任务契约

用于 cutvideo 长任务的计划和独立会话执行。只记录执行所需的用户需求、资源标识和结果，不复制服务端模板正文、方法说明或密钥。

## 计划与批次

- 在用户的视频工作目录创建 `.plans/YYYY-MM-DD-视频任务/`；目录已存在时使用新的明确名称，避免覆盖或误选其他工程。使用绝对路径引用所有任务、输入与输出。
- `plan.md` 只读，注明 `任务类型：视频制作`、工作目录、cutvideo 技能绝对路径、projectId、用户目标、已确认约束、批次依赖、`最大并发：3`。并发 3 是初始上限，用户另有要求时按实际服务限额调整。
- `prompt.md` 沿用 `# 批次 N`、`## 任务 N`、`text` 代码块结构；每段完整提示要求直接按视频任务契约执行，读取 plan.md、对应任务文件和 cutvideo 技能，不调用 do-task-plans，不带编码测试、Git 提交或 Cargo 槽位指令。
- 在需求、工程标识、素材清单和统一约束明确后拆分。首批按独立素材或片段安排只读分析、检索与候选准备；依赖它们的后续批次安排单一工程写入、预览修正与确认后导出。
- 同一工程的所有写入串行；project_notes、worksheet、素材导入、轨道、字幕和导出都属于共享写入。不同轨道不能作为并行写入依据。初版并行任务只调用服务端明确标记为只读的工具；不确定的调用按写入处理。
- 外部生成提交也按写入串行安排；生成成功后的独立状态查询可并行。不得以并行提速为由重复提交付费任务或创建重复工程。
- 每个任务只处理一个明确产物，按约 10–20 分钟的主动工作量拆分；这不是超时中断承诺。耗时作业异步提交并保存续查信息，不为凑时长重复提交。

## 编号任务文件

每个任务自包含，至少包含：

- 批次、依赖任务及其结果记录绝对路径；初始 `状态：未开始`。
- `任务类型：视频制作`、工作目录、cutvideo 技能路径、projectId、素材标识和时间范围、必要的已确认用户约束。
- `访问模式：只读` 或 `访问模式：写入`；允许的操作、禁止操作、产物验收条件和确切的检查方式。写入任务只能在前一写入任务结束后启动。
- 专属输出目录和 `结果记录：<绝对路径>/results/N.md`。不同任务不得共写一个结果文件或共用默认 occ-out；CLI 调用显式设置任务专属的 OCC_STATE_DIR、--save-dir 和 --out 回执路径，三者都位于该任务输出目录。
- 需要的服务端模板 id@version（已知时），新会话自行读取；不得复制模板正文。不能读取必要规则时保留阻塞。
- 异步操作：提交回执取得后立即记录 projectId、jobId/taskId/exportId、原工具与必要的非敏感续查参数、pollWith、当前状态和下一步；未知标识不得编造。CLI 长作业优先 --no-wait，按回执续查。完成后需要再次取结果的操作遵循原工具契约，不能盲目重放写操作。

## 执行与完成

- 结果记录是独立会话间的交接依据，不依赖对话摘要。已有作业先续查；写入回执不明确时先核实远端状态，不重提。超时不等于失败。
- 仅已取得明确产物、通过本任务验收、结果记录完整后，标记 `状态：已完成`。保留编号任务和结果文件，视频任务不使用“删除任务文件代表完成”或“已完成，待回归”。待运行作业尚未满足验收，不能提前标为完成。
- 无法继续时标记 `状态：已阻塞`，记录作业当前状态、阻塞证据和下一步。调度器可先继续不依赖它的任务；恢复时使用原会话。不得超出访问模式或原用户授权扩大范围、增加付费生成或重新建工程。
- 预览确认是导出的前置依赖。缺少用户确认时保留阻塞并交付预览链接，不默认获得确认。导出只由指定写入任务提交一次；恢复必须查询既有导出状态。
- 最终验收检查所有任务的结果证据、共享工程状态和用户所需交付；不机械套用代码回归，不额外触发整片渲染。按 cutvideo 规则交付 shareUrl。
