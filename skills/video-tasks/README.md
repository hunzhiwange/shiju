# 视频剪辑

说出你想要的视频，就可以开始做，也可以改已经有的片子。

## 它能帮你做什么

- 把口播剪顺，加字幕、标题和背景音乐
- 做探店、带货、种草、团购短视频
- 做品牌故事片：开头用动画讲一段品牌或门店的故事，再接上实拍画面
- 照着一条参考片的节奏和包装改一版
- 换一段画面、改几句字幕、调整已经做好的片子

## 怎么使用

先用识矩账号登录，然后直接告诉 AI 你想要什么视频，并补充需要的信息。

例如：

- “把这段口播剪顺，加上字幕和背景音乐”
- “给这家火锅店做一条 30 秒的探店视频”
- “给我们品牌做一条故事片，开头用动画讲讲这家店是怎么来的”

先看给出的预览，确认后再导出。成片用对话里的链接查看。

## 使用时请注意

- 如果提示尚未开通、已停用或已到期，请联系识矩引擎开通或续期，开通后再继续使用。
